# KISSsoft 2025 中英双语帮助文档 (Help-ZH)

本项目为 **KISSsoft 2025 官方帮助文档（Help）的完整中英双语汉化版本**。包含 1608 个 HTML 页面（1601 个双语核心内容页 + 中文导航目录与资源），采用**中文在上、英文原文在下**的对照版式，兼顾阅读流畅性与原版严谨性。

---

## 🚀 使用方法（替换即用）

1. 下载本仓库中的 `e` 文件夹（或直接 Clone / 下载仓库 ZIP）。
2. 找到你的 KISSsoft 2025 安装目录，定位到 `help` 路径：
   ```text
   C:\Program Files\KISSsoft AG\KISSsoft 2025\help\e
   ```
3. **备份原 `e` 文件夹**（建议重命名为 `e_backup`）。
4. 将本仓库中的 `e` 文件夹直接复制并替换该路径下的同名文件夹即可。
5. 打开 KISSsoft 软件按 `F1` 或点击菜单栏帮助，即可查看完整的中英双语帮助文档。

## 📖 项目内容与特色

- **全覆盖**：完整覆盖齿轮（圆柱齿轮、锥齿轮、蜗杆蜗轮、行星齿轮等）、轴与轴承、联接件、弹簧等所有计算与分析模块。
- **专业术语规范**：严格参考国家标准（GB/T）与齿轮行业专业词典，对机械设计、修形公差、疲劳强度、接触斑点等专业名词进行统一规范。
- **中英双语对照**：正文段落上方为地道精准的中文译文，下方保留原始英文，方便随时比对。
- **零破坏集成**：完美保留 KISSsoft 原版 HTML/CSS 样式、表格结构、公式与 900+ 示意图资源，不影响软件原生帮助系统的跳转与检索。
