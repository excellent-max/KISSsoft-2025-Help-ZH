中文翻译

齿宽与法向模数之比

锥齿轮和准双曲面齿轮的标准尺寸特征值为“齿宽与法向模数之比”。小值会导致模数较大，尺寸针对齿根强度进行优化。若此标志位被设置，则超出此范围的解将被拒绝。

注意

在计算螺旋齿锥齿轮时，应使这个范围相对较小。对于差速锥齿轮，应选择较大的范围。

English Original

Ratio of facewidth to normal module

A standard sizing characteristic value for bevel and hypoid gears is "Ratio of facewidth to normal module". Small values result in modules that tend to be large and sizings that are optimized for root strength. If this flag is set, solutions which lie outside this range are rejected.

Note

Make this range relatively small when calculating bevel gears with spiral teeth. Select a larger range for differential bevel gears
