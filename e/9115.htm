中文翻译

添加和删除文件

文件可以通过项目属性（参见"项目属性"章）或上下文菜单（参见"菜单、上下文菜单和工具栏"章）添加和删除。除了 KISSsoft 的计算文件外，您还可以在项目中插入任何外部文件。

English Original

Adding and deleting files

Files can be added and deleted either via the Project properties (see chapter Project properties) or the context menu (see chapter Menus, context menus and the tool bar). As well as calculation files from KISSsoft, you can insert any external files in a project.
