停靠窗口

除菜单栏、工具栏和状态栏外，停靠窗口是 KISSsoft 用户界面的重要元素。停靠窗口是可以在桌面上像对话框一样自由移动、也可以按您喜欢的任何排列方式停靠在程序页面上的窗口。多个停靠窗口可以叠放在一起，并以选项卡形式显示。

您可以通过双击标题栏来释放停靠窗口。要移动停靠窗口，请在标题栏中单击鼠标左键，并在按住鼠标按钮的同时移动鼠标。如果将鼠标移到主窗口边缘附近，将显示停靠窗口的新位置。停靠窗口可以围绕主窗口排列成多行多列。松开鼠标按钮即可放置窗口。如果在移动停靠窗口时按下并按住 Ctrl 按钮，停靠窗口将变为自由浮动。

停靠窗口可以通过“视图”菜单显示和隐藏 （参见"菜单、上下文菜单和工具栏"章） 。

每个计算模块中停靠窗口的单独排列保存在用户自定义设置中。因此，每个计算模块始终从上次使用时的同一位置启动。

English Original

Docking window

Beside the menu bar, tool bar and status bar, the docking windows are important elements in the KISSsoft user interface. Docking windows are windows that can either be moved freely on the desktop, like a dialog, or docked on the program pages in any arrangement that suits you. Several docking windows can be placed on top of each other and be displayed as tabs.

You can release a docking window by double-clicking in its title bar. To move a docking window, click the left-hand mouse button in the title bar and move the mouse while holding down the mouse button. If you move the mouse close to the edge of the main window, a new position for the docking window will be displayed. Docking windows can be arranged in several lines and columns around the main window. Release the mouse button to place the window.If you press and then hold down the Ctrl button while moving a docking window, the docking window then becomes free-floating.

Docking windows can be displayed and hidden via the View menu (see chapter Menus, context menus and the tool bar) .

The individual arrangement of docking windows in each calculation module is saved in the user-defined settings. As a result, every calculation module always starts in the same place as when it was last used.
