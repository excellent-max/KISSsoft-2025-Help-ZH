中文翻译

带保护键的单用户版

  1. 将许可证文件复制到您的许可证目录（参见"下载许可证文件"章）（参见"[SETUP] 中的定义"章））
  2. 现在，只需将随系统提供的保护键插入即可。

注意

KISSsoft的单用户版也可以安装在中央服务器上。本地客户端（工作站计算机）然后可以直接从此服务器运行软件。请注意，在这种情况下，保护键必须始终插入需要使用KISSsoft的特定客户端上。

English Original

Single user version with dongle (protection key)

  1. Copy your license file (see chapter Downloading a license file) to your License directory (see chapter Definitions in [SETUP]))
  2. Now, simply plug in the dongle supplied with the system.

Note

The single user version of KISSsoft can also be installed on a central server. Local clients (workstation computers) can then run the software directly from this server. Please note that, in this case, the dongle must always be plugged into the particular client on which you want to use KISSsoft.
