中文翻译

影响因素

在计算单个连接时，您必须考虑一系列取决于载荷、应力、类型等的影响因素：

  • 工况系数 KA
  • 动态系数：
    固定载荷：Cd = 1；脉动载荷：Cd = 0.7；交变载荷：Cd = 0.5；
    对于开槽弹性销和螺旋销（套筒）
    固定载荷：Cd = 1；脉动载荷：Cd = 0.75；交变载荷：Cd = 0.375；
  • 全销/槽销的折减系数
    全销：Ck = 1；槽销（弯曲、剪切）：Ck = 0.7；槽销压力：Ckp = 0.8；

由于文献中的许用应力值非常低，因此添加了其他材料系数（许用表面压力/剪切应力和弯曲应力的系数）以获得表中的值。您可以通过选择 计算 → 设置 来定义这些系数。

English Original

Influence factors

When calculating individual connections you must include a number of influencing factors which are defined depending on the load, stress, type, etc.:

  • Application factor KA
  • Dynamic factor:
    Fixed load: Cd = 1; pulsating load: Cd = 0.7; alternating load: Cd = 0.5;
    for slotted spring pins and spiral pins (bushes)
    Fixed load: Cd = 1; pulsating load: Cd = 0.75; alternating load: Cd = 0.375;
  • Reduction factors for full/grooved pin
    Full pin: Ck = 1; grooved pin (bending, shear): Ck = 0.7; grooved pin pressure: Ckp = 0.8;

Since the permissible stress values in the literature are very low, other material factors (the factors for permissible surface pressure/shear stress and bending stress) have been added to obtain the values in the table. You can define these factors by selecting Calculation → Settings.
