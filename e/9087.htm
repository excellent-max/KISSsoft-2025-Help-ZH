中文翻译

计算报告

选择报告 > 生成以生成有关计算的报告。此外，工具栏和F6功能键可让您快速便捷地执行此操作。报告内容取决于当前处于活动状态的选项卡（参见标准选项卡和特殊选项卡）。标准报告的长度（参见报告的范围）和外观（参见格式）可受用户自定义的报告模板（参见报告模板）影响。

计算模块可以包含更多报告，您可以通过报告菜单访问这些报告。

报告通常在 KISSsoft 报告查看器中显示（参见报告查看器）。重要：当您从报告查看器返回输入窗口时，报告不会保存。若要使其永久可用，必须使用新名称保存它！

注意

一般来说，只有在计算一致的情况下才应生成报告（参见计算并生成报告）。如果不是这种情况，您仍然可以生成报告，但计算状态将随后在报告中注明。

注意

生成标准报告时，系统会生成一个以模块标签为文件名的报告文件。该文件保存在定义为 TEMPDIR 的目录中（参见全局设置 - KISS.ini），该目录在 KISS.ini 文件中定义（参见"[PATH] 中的定义"章）。

English Original

Calculation reports

Select Report > Generate to generate reports about your calculations. In addition, the tool bar and the F6 function key give you quick, convenient access to this action. The report contents depend on which tab is currently active (see chapter Standard and special tabs). The Length (see chapter Scope of a report) and Appearance (see chapter Formatting) of standard reports can be influenced by user-defined report templates (see chapter Report templates).

A calculation module can contain further reports which you can access via the Report menu.

Reports are usually displayed in the KISSsoft Report Viewer (see chapter Report Viewer). Important: The report is not saved when you return from the report viewer to the input window. To make it permanently available, you must save it with a new name!

Note

In general, a report should only be created if the calculation is consistent (see chapter Calculating and generating a report). If this is not the case, you can still generate the report, but the status of the calculation will then be noted in the report.

Note

When you generate a standard report, the system generates a report file with the module's label as its file name. The file is saved in the directory defined as the TEMPDIR (see chapter Global settings - KISS.ini) in the KISS.ini file (see chapter Definitions in [PATH]).
