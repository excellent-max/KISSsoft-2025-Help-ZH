中文翻译

新建螺栓类型

在添加新的螺栓类型之前，您必须已经熟悉表结构。您必须知道哪个值放在哪一列（使用表头说明中的变量名）。

然后，按以下步骤操作：

  • 在数据库中，打开与新螺栓类型最相似的数据集。
  • 通过单击新螺栓类型名称下方的 (+) 按钮复制此数据集。
  • 然后，单击 编辑 按钮打开新数据集。
  • 单击 编辑 按钮（位于文件名输入行末尾）。这会打开一个仍包含"旧"值的文件。
  • 用新值覆盖这些值。注意变量结构（即特定变量根据其出现位置被分配到一个编号）以及行的顺序。
  • 将更新后的文件以新名称保存在"KISSsoft 20xx/ext/dat"目录中，然后关闭编辑器。
  • 将新文件名添加到数据库中的新数据集。
  • 然后，保存新数据集。

English Original

Creating a new bolt type

You must already be familiar with the table structure before you can add a new bolt type. You must know which value goes in which column (use the variable names from the descriptions in the table header).

Then, proceed as follows:

  • In the database, open the dataset that is most similar to the new bolt type.
  • Copy this dataset by clicking on the (+) button under the name of the new bolt type.
  • Then, click the Edit button to open the new dataset.
  • Click the Edit button at the end of the file name input line. This opens a file which still contains the "old" values.
  • Overwrite these values with the new values. Note the variables structure (i.e. a specific variable is assigned to a number, depending on where the number appears) and the sequence of the lines.
  • Save the updated file in the "KISSsoft 20xx/ext/dat" directory, with a new name, and close the Editor.
  • Add the new file name to the new dataset in the database.
  • Then, save the new dataset.
