中文翻译

表格视图

表格格式在隐藏的 definition 变量中定义。有不同类型的表格：

  • 计算用表格：此表格最适合显示同一类型的多个元素的数据。定义格式为：

    [[typ,rows,columns],['variable1','variable2',..],
    [element1,element2,..]]

    对于类型 1，您可以编辑每个显示的值。对于类型 2，您可以编辑所有没有表达式的值；对于类型 3，您可以编辑所有已设置 KISSsys → KISSsoft 标志的值。行数或列数未被使用。
  • 数组或变体用表格：在此表格中，数组或变体变量分别显示在单独的列中。定义格式为：

    [[typ,rows,columns],['variable1','variable2',..]]

    对于类型 21，您可以编辑每个显示的值。对于类型 22，您可以编辑所有没有表达式的值；对于类型 23，您可以编辑所有已激活 KISSsys → KISSsoft 选项的值。列数未被使用。
  • 用户界面用表格：您可以根据需要配置此表格。定义为 [[type,rows,columns],[[A1,B1],[A2,B2]]]。内容可以通过表格中的上下文菜单插入，并且不应在定义中更改。由于定义是以交互方式更改的，因此您不能在此处设置表达式。行数或列数也应仅在对话框中更改。否则，关于参考元素的信息将会丢失。
English Original

Table view

The table format is defined in the hidden definition variable. There are different types of tables:

  • Table for calculations: This table is best suited for displaying the data for several elements of the same type. The definition format is:

    [[typ,rows,columns],['variable1','variable2',..],
    [element1,element2,..]]

    In the case of type 1, you can edit each displayed value. In the case of type 2, you can edit all values that have no expression, and in the case of type 3 you can edit all values for which the KISSsys → KISSsoft flag has been set. The Number of Rows or Columns is not used.
  • Table for arrays or variants: In this table, the arrays or variant variables are each displayed in a separate column. The definition format is:

    [[typ,rows,columns],['variable1','variable2',..]]

    In the case of type 21, you can edit each displayed value. In the case of type 22, you can edit all values that have no expression, and in the case of type 23, you can edit all values for which the KISSsys → KISSsoft option is activated. The Number of Columns is not used.
  • Table for user interface: You can configure this table to suit your needs. The definition is [[type,rows,columns],[[A1,B1],[A2,B2]]]. The contents can be inserted via a context menu in the table, and should not be changed in the definition. Since the definition is changed interactively, you must not set an expression here. The number of rows or columns should also only be changed in a dialog. Otherwise information about reference elements will be lost.
