中文翻译

设置

报告会给出测量所用最合适跨齿数的公法线长度和跨球/跨滚子测量值，或滚子直径。如果要在现有图纸中使用不同的跨齿数，或不同的球/销直径，可在此处覆盖软件所选的值。

但是，如果输入的值无法进行测量，则不输出任何结果。如果选中发生几何错误时不取消（参见"发生几何错误时不中止"章）选项，则对于无法测量的情况也会输出测量值，例如高于齿顶圆的接触点。

注意

建议的球/滚子直径取自 Z0ROLLEN.dat 文件。这些值取自 Z0ROLLENANSI.dat 文件，用于符合 ANSI 92.1 的花键。该文件对应于 DIN 3977 中规定的推荐直径。然后您可以使用编辑器修改现有的球/销。有关如何处理外部数据集的更详细信息，请参见“外部表格”一节（参见"外部表格"章）。

English Original

Settings

The base tangent length and the mass across balls and rollers for the most suitable number of teeth over which the measurement is to be taken, or the roller diameters, are specified in the report. If you want to use a different number of teeth spanned, or a different diameter of ball/pin in an existing drawing, this is where you can overwrite the values selected by the software.

However, no results are output if you enter values for which a measurement cannot be performed. If the do not cancel when geometry errors occur (see chapter Don’t abort if geometry errors occur)option is selected, test masses are also output for cases in which they could not be measured, for example, for points of contact above the tip circle.

Note

The proposed ball/roller diameters are taken from the Z0ROLLEN.dat file. These values are taken from the Z0ROLLENANSI.dat file for splines as defined in ANSI 92.1. This file corresponds to the recommended diameters specified in DIN 3977. You can then use an Editor to modify the existing ball/pin. You will find more detailed information about how to handle external datasets in the External tables section (see chapter External tables).
