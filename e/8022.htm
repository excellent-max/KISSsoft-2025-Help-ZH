设置

选择 计算 -> 设置 以输入连接各部分所需的安全系数。根据 Niemann 第 I 卷，第 5 版（2019 年），韧性材料的最小安全系数设置在 1.0…1.3 范围内，脆性材料的最小安全系数设置在 1.3…2.0 范围内。所需安全系数定义了系统在尺寸计算过程中搜索的值。

轴、轮毂和半圆键的 支撑系数 在 DIN 6892 中根据所涉及的材料和零件而不同。这些系数在特定范围内变化。KISSsoft 中使用最小值。这些值可以覆盖。

如果设置了 考虑键上压力 标志，则半圆键的值将包含在尺寸计算中。否则，将使用轴和轮毂的值执行尺寸计算过程。

如果选择了 以壁厚作为毛坯直径计算材料强度，则轮毂材料的强度使用壁厚而不是毛坯直径计算。

English Original

Settings

Select Calculations -> Settings to enter the required safeties for the individual parts of the connection. According to Niemann, Volume I, 5th Edition (2019), the minimum safety for ductile materials is set in the range 1.0…1.3 and the minimum safety for brittle materials is set in the range 1.3…2.0. The required safeties define the values the system searches for during sizing.

The support factors for the shaft, hub and Woodruff key in DIN 6892 differ according to the materials and parts involved. The factors vary within a specific range. The minimum values are used in KISSsoft. These values can be overwritten.

If the Take pressure on key into account flag is set, the values of the Woodruff key are included in sizings. Otherwise, the sizing procedure will be carried out using the values for shaft and hub.

If you have selected Calculate material strength with wall thickness as raw diameter, the strength of the hub material is calculated using the wall thickness instead of the raw diameter.
