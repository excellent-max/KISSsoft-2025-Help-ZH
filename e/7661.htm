中文翻译

函数

函数编程的不同选项最好通过示例来说明。函数头如下所示：

//由调用程序传递的变量

PAR Parameter1,Parameter2;

//常量声明

CONST PI=3.1415926,E=2.71828;

//局部变量的声明

VAR a,b,c,d;

在这里，以//开头的行是注释。这三行中的每一行只能出现一次，并且声明的变量必须用逗号分隔。未初始化的参数或变量为VOID。可以用ISVOID(variable)来检查。

受限语句有两种形式：IF 或 SWITCH 语句：

//带可选 ELSIF 和 ELSE 块的 IF 语句

IF Parameter1>5 THEN

a=sin(PI*Parameter1);

ELSIF Parameter1<0 THEN

a=Parameter1; ELSE

a=0;

ENDIF

//通过数字或文本进行选择的 SWITCH 语句

SWITCH Parameter2

CASE 'Null':b=0;

CASE 'Eins':b=1;

DEFAULT :b=5;

ENDSWITCH

循环有四种程序变体：

//带可选步长的 FOR 循环

FOR a=1 TO 8 STEP 2 DO

b=b+a;

IF b>100 THEN

BREAK;//结束循环

ENDIF

NEXT

//WHILE 循环

WHILE b<100 DO

b=b*10;

WHEND

//DO 循环

DO

b=b*10;

UNTIL b>100;

//FORALL 循环针对数组的所有元素执行

c=[1,2,3,4,5,6,7,8,9];

a=0;

FORALL c d DO//d 分别获得 c 中一个元素的值

a=a+d;

NEXT

调用属于对象的函数有一种特殊语法。标准方法是指定对象名称，后跟一个点和函数名称。但是，对象名称也可以包含在局部变量中。这使您可以在运行时更改函数调用的对象。

//针对 Objekt1 调用函数 OBJ_GetMember。

Objekt1.OBJ_GetMember('variablenname');

//a 是类型为 String 的局部变量，保存对象的名称

a='Objekt1';

//针对名称为 a 的对象调用服务函数

b=a.OBJ_GetMember('variablenname');

//调用用户为 Objekt1 创建的函数。

a.Benutzerfunktion();

//用户创建的函数将针对

//当前对象调用。

Benutzerfunktion();

//用户创建的函数将针对

//上级对象调用。

^.Benutzerfunktion();

系统相对于当前对象搜索变量名称。如果在表达式中使用object.z，系统将首先尝试在当前对象下方查找此变量。如果不存在，则搜索将在层次结构中的上级对象中继续（按照^.object.z），依此类推。

English Original

Functions

The different options for programming in functions are best described with the help of examples. A function's header looks like this:

//Übergebene Variablen vom aufrufenden Programm

PAR Parameter1,Parameter2;

//Deklaration von Konstanten

CONST PI=3.1415926,E=2.71828;

//Deklaration von lokalen Variablen

VAR a,b,c,d;

Here, the lines that begin with // are comments. Each of these three lines must only occur once, and the declared variables must be separated with a comma. A non-initialized parameter or variable is VOID. This can be checked with ISVOID(variable).

Limited statements have two variants: IF or SWITCH statements:

//IF-Anweisung mit optionalem ELSIF und ELSE Block

IF Parameter1>5 THEN

a=sin(PI*Parameter1);

ELSIF Parameter1<0 THEN

a=Parameter1; ELSE

a=0;

ENDIF

//SWITCH Anweisung mit Auswahl über Zahlen oder Texte

SWITCH Parameter2

CASE 'Null':b=0;

CASE 'Eins':b=1;

DEFAULT :b=5;

ENDSWITCH

There are four program variants for loops:

//FOR Schleife mit optionaler Schrittweite

FOR a=1 TO 8 STEP 2 DO

b=b+a;

IF b>100 THEN

BREAK;//beendet die Schleife

ENDIF

NEXT

//WHILE Schleife

WHILE b<100 DO

b=b*10;

WHEND

//DO Schleife

DO

b=b*10;

UNTIL b>100;

//FORALL Schleife wird für alle Elemente eines Arrays ausgeführt

c=[1,2,3,4,5,6,7,8,9];

a=0;

FORALL c d DO//d bekommt jeweils den Wert eines Elementes von c

a=a+d;

NEXT

There is a special syntax for calling up functions that belong to objects. The standard method is to specify the object name followed by a point and the name of the function. However, the name of an object can also be contained in a local variable. This enables you to change the object for the function call at runtime.

//Die Funktion OBJ_GetMember wird für Objekt1 aufgerufen.

Objekt1.OBJ_GetMember('variablenname');

//a ist lokale Variable vom Typ String mit dem Namen eines Objektes

a='Objekt1';

//Es wird eine Servicefunktion für das Objekt mit Namen a aufgerufen

b=a.OBJ_GetMember('variablenname');

//ruft vom Benutzer angelegte Funktion für Objekt1 auf.

a.Benutzerfunktion();

//die vom Benutzer angelegte Funktion wird für das

//aktuelle Objekt aufgerufen.

Benutzerfunktion();

//die vom Benutzer angelegte Funktion wird für das

//übergeordnete Objekt aufgerufen.

^.Benutzerfunktion();

The system searches for variable names relative to the current object. If object.z is used in an expression, the system will first attempt to find this variable below the current object. If it is not present, the search will continue in the hierarchically superior object (in accordance with ^.object.z) and so on.
