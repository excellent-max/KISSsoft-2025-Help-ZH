中文翻译

定义选项

如果您为齿轮轮缘定义选择了选项 (A) 或 (B)，则有两种选项可用于定义齿轮体几何。

  1. 手动定义： 您使用手动定义 选项和提供的输入表，在齿轮体截面中定义一些点。可为每个点定义圆角半径。
  2. 导入 STEP 文件： 您从 STEP 文件导入齿轮体几何。请使用提供的信息草图，确保导入的数据正确定位和对齐。

English Original

Definition option

If you selected option (A) or (B) for the gear rim definition, there are two options available for defining the gear body geometry.

  1. Manual definition: You define some points in the gear body cross section, using the option Manual definition and the provided input table. Fillet radii may be defined for each point.
  2. Import STEP file: You import the gear body geometry from a STEP file. Make sure that the imported data are being correctly positioned and aligned using the provided information sketch.
