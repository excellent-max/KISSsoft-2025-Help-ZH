中文翻译

元素助手

元素框可通过选择 插入 -> 元素 调出，它基于经典方法。使用此助手时，无需再拖放或剪切粘贴数据。要插入元素，只需单击它，系统即会自动将其插入到导航树中先前选定的层级。可使用元素框来创建所有可能的变体。

English Original

Element Assistant

The Elements box, which you call by selecting Insert -> Elements, is based on the classical method. If you use this assistant, you no longer have to drag and drop or cut and paste data. To insert an element, simply click on it. The system then automatically inserts it at the previously selected level in the navigation tree. You can use the Elements box to create all possible kinds of variants.
