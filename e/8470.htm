中文翻译

齿廓变位系数

在 包络蜗轮蜗杆 计算模块中，蜗杆/齿轮 1 的变位系数设置为零（按 ISO 14521 标准定义）。您只能在 齿厚变位系数 xs 输入窗口中修改蜗杆的齿厚。

注意

应使用 交错轴斜齿轮 计算模块，如果您需要变位系数 x1*≠ 0 的蜗杆。

English Original

Profile shift coefficient

In the Worms with enveloping worm wheel calculation module, the profile shift for worm/gear 1 is set to zero (as defined in the ISO 14521 standard). You can only modify the tooth thickness of the worm in the input window for the Tooth thickness modification coefficient xs.

Note

You should use the Crossed helical gears calculation module if you require a worm whose profile shift coefficient is x1*≠ 0.
