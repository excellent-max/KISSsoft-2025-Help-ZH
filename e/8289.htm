中文翻译

杂质污染

如 ISO 281 中所定义，污染系数 ec 取决于滤油器类型、轴承尺寸和润滑剂粘度。该值在 0（污染程度高）到 1 （理想）之间变化。选择 自定义输入 选项，然后点击“加号”按钮以指定您自己的 ec 值。

注意

点击“加号”按钮输入您自己的值。您可以为 箱体 和 润滑 定义新值，这些值 基于现有数据。但是，这些值只是计算文件中使用的数据，不会永久存储在数据库中。

English Original

Contamination

As defined in ISO 281, contamination coefficient ec depends on the type of oil filter, the bearing size, and the viscosity of the lubricant. This value varies within the range 0 (high level of contamination) and 1 (ideal). Select the Own input option and then click the Plus button to specify your own ec values.

Note

Click the Plus button to enter your own values. You can define new values for the Housing and Lubrication that are based on existing data. However, these values are only data used in the calculation file and are not stored permanently in the database.
