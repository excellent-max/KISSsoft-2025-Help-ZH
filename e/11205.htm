中文翻译

保存到 PTC Windchill 工作目录

要将生成的接口文件保存到 PTC Windchill 工作目录（位于 PLM 系统中），请将 SETUP.txt 文件中的 WORK_IN_CURRENT_FOLDER 参数设置从 NO 改为 YES。该 SETUP.txt 文件位于 ...\ProEngineer\EditGear\SETUP.txt 子文件夹中，位于 KISSsoft 安装目录内。

如果在服务器上安装了 Creo Parametric 并从客户端启动，临时文件将写入服务器，而不是客户端。为了避免这种情况，请在 Setup.txt 文件中按此路径设置以下变量。

APSF_WORK_DIR C:\temp

English Original

Saving the files to the PTC Windchill working directory

To save the generated interface files to the PTC Windchill working directory in the PLM system, change the WORK_IN_CURRENT_FOLDER parameter setting in the SETUP.txt file from NO to YES. The SETUP.txt file is located in the ...\ProEngineer\EditGear\SETUP.txt sub-folder, in the KISSsoft installation.

If you have installed Creo Parametric on the server and started it from the client, temporary files are written to the server, not to the client. To prevent this, set the variables listed below in the Setup.txt file with this path.

APSF_WORK_DIR C:\temp
