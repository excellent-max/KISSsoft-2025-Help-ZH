输入窗口

KISSsoft 系统提供各种不同的输入窗口，您可以在其中计算轴。轴编辑器（参见"轴编辑器"章）以图形方式显示轴系统。元素树（参见"元素树"章）以树结构说明轴系统的结构。元素编辑器（参见"元素编辑器"章）用于输入元素的参数。

English Original

Input window

The KISSsoft system offers a range of different input windows in which you can calculate shafts. The Shaft Editor (see chapter Shaft editor) displays the shaft system as a graphic. The Element Tree (see chapter Element Tree) illustrates the structure of the shaft system in a tree structure. The Element editor (see chapter Element Editor) is where you input parameters for an element.
