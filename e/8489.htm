中文翻译

轴承功率损失

如果使用滚动轴承，则使用 ISO 14521 中定义的经验公式计算功率损失。如果使用滑动轴承，则必须手动指定功率损失。

ISO 14521 中定义的经验公式只能在特定的有效范围内使用。

KISSsoft 检查总功率损失是否过高。

(PV0 + PVLP + PVD) > 0.2*P

如果功率损失大于 0.2*P，则各个功率损失 PV0、PVLP 和 PVD 分别设置为 0。

English Original

Bearing power loss

If roller bearings are used, the power loss is calculated using the empirical formulae defined in ISO 14521. If plain bearings are used, you must specify the power loss manually.

The empirical formulae defined in ISO 14521 can only be used in a specific range of validity.

KISSsoft checks whether the total power losses are too high.

(PV0 + PVLP + PVD) > 0.2*P

If the power losses are greater than 0.2*P, the individual power losses PV0, PVLP and PVD are each set to 0.
