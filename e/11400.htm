中文翻译

从计算文件读取用户自定义滚动轴承

如果同时启用此选项，则将使用计算文件中存储的所有用户自定义滚动轴承的数据，并优先于数据库中的数据。如果数据库包含具有相同 ID 的轴承，则忽略这些数据。

English Original

Read user-defined rolling bearings from calculation file

If this option is also enabled, the data from all user-defined rolling bearings stored in the calculation file is used and given priority over the data in the database. If the database contains bearings with identical IDs, this data is ignored.
