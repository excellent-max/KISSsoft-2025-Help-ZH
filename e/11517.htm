中文翻译

生成 GAMA 代码

单击"生成 GAMA 代码"可以 GAMA 格式导出齿轮几何数据。单击"文件 -> 导出… -> GAMA"。随后会生成一个可导入 Gleason GAMA 软件的 GAMA 文件。
GAMA 代码当前支持 KISSsoft 中存在的以下参数：

  • 法向模数
  • 齿数
  • 螺旋角
  • 齿宽
  • 齿廓变位量
  • 齿根圆直径
  • 渐开线起点
  • 分度圆直径
  • 法向齿厚，弧长
English Original

Generate GAMA code

Click on "Generate GAMA code" to export gear geometry data in GAMA format. Click on File -> Export… -> GAMA. A GAMA file which can be imported into the Gleason GAMA software is then generated.
The GAMA code currently supports the following parameters, which are present in KISSsoft:

  • Normal module
  • Number of teeth
  • Helix angle
  • Facewidth
  • Profile shift
  • Root diameter
  • Start of the involute
  • Reference diameter
  • Normal tooth thickness, arc
