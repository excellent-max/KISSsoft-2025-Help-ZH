中文翻译

惯性矩

如果需要，您可以输入齿轮的惯性矩。此值用于计算动载系数。如果输入无效值（与预期值的偏差大于 100%），系统将显示警告。通常，此类情况是因为输入时使用了错误的单位。

English Original

Moments of inertia

If required, you can enter the moment of inertia of the gears. This value is used when calculating the dynamic factor. If you enter an invalid value (deviation > 100% from the expected value), the system displays a warning. Usually, in such cases, the incorrect unit has been used for the input.
