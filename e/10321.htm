3D Geometry

The gears are displayed in the 3D Parasolid viewer.

You can select a number of different output options from the drop-down list in the Tool bar in the Geometry 3D graphics window. You can store the Parasolid viewer graphics in different file formats such as:

  • Windows Bitmap (.bmp)
  • Joint Photographic Experts Group (.jpg, .jpeg)
  • Portable Network Graphics (.png)
  • Standard for the Exchange of Product Model Data (.stp, .step)
  • Parasolid Text File Format (.x_t)
  • Parasolid Binary File Format (.x_b)
