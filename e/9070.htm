中文翻译

[SETUP] 中的定义

变量名

描述

值

USCUSTOMARYUNITS

设置单位系统

0: 公制, 1: 美国惯用单位制

MATERIALSSTANDARD

指定材料定义所依据的标准（配置工具）

0: DIN, 1: BS, 2: AISI, 3: UNI, 4: AFNOR, 5: JIS, 6: CN

REPORTLANGUAGE

设置报告显示的语言

0: 德语, 1: 英语, 2: 法语, 3: 意大利语, 4: 西班牙语, 5: 俄语, 6: 葡萄牙语, 7: 中文, 8: 日语, 11: 带美国惯用单位制的英语

SHOWCALCTIME

显示计算所花费的时间

0: 否, 1: 是

SHOWPROGRESSBAR

显示耗时计算的进度条

0: 否, 1: 是

DISPLAYLANGUAGE

设置用户界面显示的语言

0: 德语, 1: 英语, 2: 法语, 3: 意大利语, 4: 西班牙语, 5: 俄语, 6: 葡萄牙语, 7: 中文, 8: 日语

DISPLAYFONTSIZE

设置 KISSsoft 的字号（FONT）

0：使用系统字号；其他值：直接指定字号

MESSAGESINREPORTLANGUAGE

设置显示消息的语言

0：与用户界面一致；1：与报告一致

MESSAGESSHOWSTATE

定义在消息框中显示哪些消息

0: 全部, 1: 仅在消息窗口显示信息, 2: 仅在消息窗口显示信息和警告

EDITOR

外部编辑器的路径

USEEXTERNALEDITOR

定义是否使用外部编辑器

0: 否, 1: 是

DATEFORMAT

日期格式，例如 DD.MM.YYYY

TIMEFORMAT

时间格式，例如 hh.mm.ss

ENABLENETWORKING

定义是否允许访问网络/互联网（例如用于显示产品新闻）。

0: 否, 1: 是

CHECKFORUPDATES

定义系统在程序启动时是否搜索更新

0: 否, 1: 是

USETEMPORARYDATABASE

定义程序启动时是否将数据库复制到临时目录

0: 否, 1: 是

RECENTFILESCOUNT

设置文件菜单中显示的最近使用文件数量

FORCEEXCLUSIVEOPEN

定义文件是否只能以独占方式打开

0: 否, 1: 是

CALCONOPEN

定义在加载文件时是否立即执行计算

0: 否， 1: 是， 2: 如果 KISSsoft 从 KISSsys 启动，则为否，否则为是

CALCINTERFACEOUT

定义是否在计算过程中写入制造数据的临时报告。

0: 否, 1: 是

STORELICENSELOCATION

定义是否从注册表读取许可证文件的路径，并在注册表中存储该路径。

0: 否, 1: 是（默认）

ENABLEUSERSETTINGS

定义 kiss.ini 中的设置是否可以被本地设置覆盖

0: 否, 1: 是

USEFILEEXPLORER

定义是否在“视图”菜单中显示文件资源管理器。启用后会显著降低 KISSsoft 的运行速度。

0: 否, 1: 是

USEHIGHDPIICONS

使用适用于高分辨率屏幕的缩放图标

0: 否, 1: 是

English Original

Definitions in [SETUP]

Variable name

Description

Values

USCUSTOMARYUNITS

Sets the system of units

0: Metric, 1: US Customary Units

MATERIALSSTANDARD

Specifies the standard according to which the materials are defined (configuration tool)

0: DIN, 1: BS, 2: AISI, 3: UNI, 4: AFNOR, 5: JIS, 6: CN

REPORTLANGUAGE

Sets the language in which reports are displayed

0: German, 1: English, 2: French, 3: Italian, 4: Spanish, 5: Russian, 6: Portuguese, 7: Chinese, 8: Japanese, 11: English with US Customary Units

SHOWCALCTIME

Displays the amount of time taken to perform a calculation

0: No, 1: Yes

SHOWPROGRESSBAR

Shows the progress bar for time-intensive calculations

0: No, 1: Yes

DISPLAYLANGUAGE

Sets the language in which the user interface is displayed

0: German, 1: English, 2: French, 3: Italian, 4: Spanish, 5: Russian, 6: Portuguese, 7: Chinese, 8: Japanese

DISPLAYFONTSIZE

Sets the font size in KISSsoft (FONT)

0: System size or else the direct font size

MESSAGESINREPORTLANGUAGE

Sets the language in which messages are displayed

0: as interface, 1: as reports

MESSAGESSHOWSTATE

Defines which messages are to be displayed in a message box.

0: all, 1: Information only in message window, 2: Information and warnings only in message window

EDITOR

Path to the external editor

USEEXTERNALEDITOR

Defines whether the external editor is to be used.

0: No, 1: Yes

DATEFORMAT

Date format, e.g. DD.MM.YYYY

TIMEFORMAT

Time format, e.g. hh.mm.ss

ENABLENETWORKING

Defines whether the network/internet can be accessed (for example, to display product news).

0: No, 1: Yes

CHECKFORUPDATES

Defines whether the system is to search for updates when the program starts.

0: No, 1: Yes

USETEMPORARYDATABASE

Defines whether the databases are to be copied to a temporary directory when the program starts

0: No, 1: Yes

RECENTFILESCOUNT

Set number of most recently used files in the File menu displayed.

FORCEEXCLUSIVEOPEN

Defines whether files can only be opened exclusively.

0: No, 1: Yes

CALCONOPEN

Defines whether calculations are to be performed on a file immediately, when it is loaded.

0: No, 1: Yes, 2: no if KISSsoft is started from KISSsys, otherwise yes

CALCINTERFACEOUT

Defines whether temporary reports for manufacturing data are to be written during a calculation.

0: No, 1: Yes

STORELICENSELOCATION

Defines whether the path to the license file is to be read from the registry, and also stores this path to the license file in the registry.

0: No, 1: Yes (default)

ENABLEUSERSETTINGS

Defines whether the settings in kiss.ini can be overwritten by local settings.

0: No, 1: Yes

USEFILEEXPLORER

Defines whether the Explorer is to be displayed in the "View" menu list. This process will slow down KISSsoft considerably.

0: No, 1: Yes

USEHIGHDPIICONS

Uses scaled icons for high-resolution screens

0: No, 1: Yes
