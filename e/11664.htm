中文翻译

使用 FEM 计算 3D 齿根应力

此特殊计算可用于使用 FEM 方法计算齿轮齿根处的应力。为此创建了一个三维 (3D) 模型。由于此计算从接触分析结果中获取总啮合线长度及相关的载荷分布，因此在执行此特殊计算之前，必须已成功完成接触分析。

提供以下输入字段：

  • 选择齿轮副/选择齿轮，用于要分析的齿轮/齿轮副。齿轮副选择选项仅在具有多个齿轮副的模块中可用（例如三齿轮传动）。
  • 齿数，包含在 FE 模型中的齿数。
  • 轴直径，用于手动输入模型的内径。对于轴直径较小的大型齿轮，这是减少有限元数量的有效方法（通过定义较大的轴直径）。
  • FE 尺寸，用于直接输入平均单元边长。它对应于位于 XZ 层上的所有单元边长的平均值。默认值由齿轮尺寸确定。随着 FE 值减小，FE 模型中的齿形表示得更精确。这对所得应力有显著影响。
  • 每个周节的啮合位置数 定义了要进行接触分析的啮合位置数。在接触分析中，使用相同的 每个周节的啮合位置数 设置（位于 分辨率 选项下）。它对应于接触分析计算完成后可用于 FE 计算的载荷工况数。
  • 切片数 定义了沿齿宽的有限元数量以及接触分析的切片数。在接触分析中，使用相同的 切片数 设置（位于 分辨率 选项下）。如果直接输入切片数，接触分析中的相应字段将设置为 自定义输入 选项。
  • 旋转角（接触分析载荷工况），用于计算。此选项仅在接触分析已成功完成后显示。用户现在可以选择用于计算的载荷工况。默认载荷工况是导致中间齿弯曲力矩最大的工况。用户也可以选择接触分析中计算的任意位置。可用旋转角的数量与 每个周节的啮合位置数 一致。

用于计算的 FE 网格始终显示在右侧。当接触分析成功完成后，所得接触力以红线显示在 FE 网格上。这些始终对应当前选择的载荷工况。软件会自动在缺口周围和中间齿根区域生成更细的网格，以便更精确地计算这些区域周围的应力。

齿的固定条件（FEM 分析所需的边界条件）定义在齿轮的内径和侧面上。如果内径为零，软件会自动定义内径为齿顶圆直径的 20% 以便进行计算。内径也可以通过单击 轴直径 变量手动调整。

FEM 结果在 KISSsoft 结果窗口和报告中提供。报告中提供了所有建模齿沿齿形的每个切片的应力结果。单击 图形 > FEM > FEM 结果 可显示更多结果，例如 3D 位移和主应力。将显示内径与有效直径之间的所有结果。

English Original

Calculate 3D tooth root stress with FEM

This special calculation can be used to calculate the stresses at the root of a gear tooth using the FEM method. A three dimensional (3D) model is created for this purpose. As this calculation takes the total length of path of contact and the associated load distribution from the contact analysis results, it is essential that the contact analysis has been performed successfully before this special calculation can be performed.

The following input fields are available:

  • Select gear pair/Select gear for the gear/gear pair to be analyzed. The gear pair selection option is only available in modules with multiple gear pairs (e.g. three gears train).
  • Number of teeth to be included in the FE model.
  • Shaft diameter to enter the inner diameter of the model manually. For large gears with a small shaft diameter, this is a useful way of reducing the number of finite elements (by defining a larger shaft diameter).
  • FE size to input the average element edge directly. This corresponds to the average value for all the edges of the elements that lie on the XZ layer. A default value is determined from the gear dimensions. The tooth form in the FE model is represented more accurately as the FE value decreases. This has a significant impact on the resulting stresses.
  • Number of meshing positions per pitch defines the number of meshing positions for which the contact analysis is to be performed. In the contact analysis, the same Number of meshing positions per pitch setting is used under the Resolution option. It corresponds to the number of load cases that are available for the FE calculation, after the contact analysis calculation has been performed.
  • Number of slices defines the number of finite elements along the facewidth and also the number of slices for the contact analysis. In the contact analysis, the same Number of slices setting is used under the Resolution option. If you enter the number of slices directly, the corresponding field in the contact analysis is set to the Own input option.
  • Angle of rotation (contact analysis load case) for the calculation. This option is only displayed if the contact analysis has been performed successfully. The user can now select the load case for the calculation. The default load case is the one which leads to maximum bending moment at the middle tooth. The user can also select any of the positions calculated in the contact analysis. The number of available angles of rotation matches the Number of meshing positions per pitch.

The FE mesh used for the calculation is always displayed on the right-hand side. When the contact analysis has been performed successfully, the resulting contact forces are displayed as red lines on the FE mesh. These always correspond to the currently selected load case. The software automatically generates a finer mesh around notches and at the root area of the middle tooth, to provide a more accurate calculation of the stresses around these areas.

The tooth's fixation condition (required boundary condition for the FEM analysis) is defined at the inside diameter and the sides of the gear. If the inside diameter is zero, the software automatically defines an inside diameter of 20% of the tip diameter so that the calculation can be performed. The inner diameter can also be adjusted manually by clicking the Shaft diameter variable.

The FEM results are provided at the KISSsoft result window and in the report. The stress results for every slice along the tooth form of all the modeled teeth are provided in the report. Click on Graphics > FEM > FEM Results to display more results, such as displacements and principle stresses, in 3D. All the results in the range between the inside diameter and the active diameter are displayed.
