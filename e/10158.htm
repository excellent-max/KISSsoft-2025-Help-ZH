中文翻译

肩部标准半径

为了计算肩部的凹口效应，需要一个半径。此半径可以作为辅助单元输入。如果未定义半径，系统将使用用于计算凹口效应的标准半径。

通常，我们建议为每个肩部定义半径。

English Original

Standard radius at shoulders

To calculate the notch effect on shoulders, you require a radius. This can be input as an auxiliary element. If no radius has been defined, the system uses the standard radius defined for calculating the notch effect.

Generally, we recommend you define radii for each shoulder.
