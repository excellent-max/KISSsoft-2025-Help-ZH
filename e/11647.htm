中文翻译

特征频率

此特殊计算能够收集所建模系统的滚动轴承和齿轮副（圆柱齿轮、三齿轮和四齿轮轮系、行星齿轮和锥齿轮）的特征频率。这些值显示在结果窗口的两幅图中以及特殊报告中。此外，还提供了多种详细分析工具，以及供用户输入来自其他组件的频率。

此特殊计算的用户界面分为两部分：常规和附加数据。

常规区域包含基本设置：

参考转速：用于选择参考转速。您可以从边界条件或轴中选择。

参考轴或参考边界：显示现有模型中所有其他频率所参照的轴/边界。参考转速显示在报告和结果窗口中。它也可以在频域图中的图形 > 特征频率下显示。如果单位选择字段设置为阶次 – 按参考转速归一化，也会使用参考转速。如果分析中存在恒定频率（模态分析结果、齿轮临界转速、来自其他组件的频率），报告将输出以红色标记的临界频率。这些临界频率等于参考转速。如果选择了考虑参考转速容差范围选项，则在输出临界频率时将考虑参考转速容差范围。

转速范围（最小/最大）n：用于频域图中 X 轴的绘制，以及定义输出临界或相似频率的区间。

谐波数量：在报告和两幅图中均予以考虑。

单位选择：使用此选项，您可以将默认单位（Hertz – Hz）更改为每分钟循环次数（cpm）。每分钟循环次数相当于 60 Hz。第三个选项是按参考转速归一化的阶次。如果选择此选项，所有频率都按参考转速归一化。参考转速可以来自轴或来自边界条件。

您还可以在计算过程中考虑齿轮特征频率。在此，您可以指定是计算所有齿轮特征频率还是仅计算其中一部分。此外，可以选择不同齿轮级的齿轮特征频率。有关齿轮特征频率的更多信息（参见"齿轮啮合频率"章）。

轴承特征频率也提供相同的计算选项。此外，可以考虑特定轴承的频率。

轴频率选项仅表示轴的旋转频率。可以选择考虑单个轴的频率。

以下分析选项在附加数据中可用：

输出相似频率： 如果激活此选项，则会输出位于用户自定义的相似频率公差范围内的频率。结果在报告的相似频率章节中给出。此选项考虑的频率包括齿轮和轴承的特征频率、轴的旋转频率，以及来自包含来自其他组件的频率选项的用户自定义频率。此外，还考虑谐波数量中定义的更高谐波处的频率。

考虑参考转速容差范围：此选项考虑参考转速容差范围，可以作为参考转速的百分比或作为绝对值。这可以在频域图中启用容差范围绘制，并在结果窗口和报告中输出该范围。容差范围也用于标记报告中显示的临界频率。

包含模态分析的结果：考虑模态分析 特殊计算的结果（参见"模态分析"章）。模态分析的频率在频域图中显示为水平线。这些值也显示在报告中。在报告中，显示特定特征频率与固有频率相交处的参考转速值。如果该值接近参考转速，则标记为红色，因为这可能是一个临界点。

包含根据 ISO 6336-1/ISO 10300-1 的齿轮临界转速：如果激活此选项，则该值作为水平线包含在频域图中。该值也显示在报告中，并进行共振分析，显示特定特征频率与临界转速频率相交处的参考转速值。如果该值接近参考转速，则标记为红色。

包含来自其他组件的频率：通过选择此选项，您可以输入附加频率。该输入可以作为对特定轴或边界条件的参考值。在这种情况下，输入阶次或倍率，并在参考转速下自动计算频率。作为参考值频率输入的频率取决于轴转速或边界条件。这些值显示在图中和结果中。输出相似频率选项也考虑这些值。例如，电动机的极数或槽数可以作为对输入–电机轴的参考输入。这些值也可以作为绝对频率值输入，该值不随参考转速变化。绝对值在频域图中显示为水平线，并且在输出相似频率中不予考虑。

English Original

Characteristic frequencies

This special calculation enables the collection of the characteristic frequencies of rolling bearings and gear pairs (cylindrical gears, three and four gear trains, planetary gears, and bevel gears) of a modeled system. The values are shown in two diagrams in the results window and in the special report. In addition, several tools for detailed analysis are available as well as the user input of the frequencies from other components.

The user interface of this special calculation is divided into two parts: General and Additional data.

The General area contains the basic settings:

Reference speed: For selecting the reference speed. You can choose from boundary conditions or from shafts.

Reference shaft or Reference boundary: Presents the shaft/boundary from the existing model to which all other frequencies are referenced. The reference speed is displayed in the report and in the results window. It can also be displayed in the Frequency domain diagram under Graphic > Characteristic Frequencies. The reference speed is also used if the Unit selection field is set to Order – normalized by the reference speed. If constant frequencies are present in the analysis (results from the modal analysis, gear critical speed, frequencies from other components) the report will output the critical frequencies which are marked in red color. These critical frequencies are equal to the reference speed. If the Consider reference speed tolerance range option is selected, the reference speed tolerance range will be taken into account for outputting the critical frequencies.

Speed range (min/max) n: Is used in the plot of the X-axis in the Frequency domain diagram, and for defining the interval in which the critical or similar frequencies are output.

Number of harmonics: Is considered in the report and in both diagrams.

Unit selection: With this option you can change the default unit (Hertz – Hz) to cycles per minute (cpm). Cycles per minute is equivalent to 60 Hz. The third option is, Order normalized by the reference speed. If you select this option, all the frequencies are normalized by the reference speed. The Reference speed can be from shaft or from boundary condition.

You can also consider Gear characteristics frequencies during the calculation. Here, you can specify whether all gear characteristics frequencies to be are calculated or only a selection of them. Additionally, gear characteristic frequencies for different gear stages can be selected. For more information about characteristic gear frequencies (see chapter Gear mesh frequencies).

The same calculation options are available for Bearing characteristic frequencies. Also, frequencies for specific bearings can be considered.

The Shaft frequencies option represents only the rotational frequency of a shaft. The consideration of the frequency of an individual shaft can be selected.

The following analysis options are available in Additional data:

Output similar frequencies: If this option is activated, frequencies are output that are inside the user-defined similar frequencies tolerance range. The results are given in the Similar frequencies chapter in the report. The frequencies considered in this option are the characteristic frequencies of gears, bearings, rotational frequencies of shafts, and user-defined frequencies from the Include frequencies from other components option. The frequencies at higher harmonics defined in Number of harmonics taken into account.

Consider reference speed tolerance range: This option considers the reference speed tolerance range, either as a percentage of the reference speed or as an absolute value. This enables the tolerance range plot in the Frequencies domain diagram and outputs the range in the result window and in the report. The tolerance range is also used to mark the critical frequencies shown in the report.

Include results from modal analysis: Takes into account the results of the Modal analysis special calculation (see chapter Modal analysis). The frequencies from the modal analysis are shown as horizontal lines in the Frequencies domain diagram. The values are also shown in the report. In the report, the values of the reference speed at which the specific characteristic frequencies intersect the eigenfrequencies are shown. If this value is close to the reference speed, it is marked red, as this might be a critical point.

Include gear critical speed according to ISO 6336-1/ISO 10300-1: If this option is activated, this value is included as horizontal line in the Frequencies domain diagram. The value is also shown in the report and the resonance analysis is conducted, showing the reference speed value at which the specific characteristic frequencies intersect the critical speed frequency. If this value is close to the reference speed, it is marked red.

Include frequencies from other components: By choosing this option, you have the possibility to input additional frequencies. This input can be as a reference value to specific shaft or boundary conditions. In this case, the order or multiplier is input and the frequency is automatically calculated at the reference speed. The frequencies input as Reference value frequencies are dependent on the shaft speed or the boundary condition. The values are shown in the diagrams and in the results. The Output similar frequencies option also takes these values into account. For example, the input of the pole or slot number of an electric motor can be entered as a reference to an input–motor shaft. The values can also be input as absolute value frequencies which are constant with the reference speed. The absolute values are shown as a horizontal line in the Frequency domain diagram and are not considered in Output similar frequencies.
