计算过程

要调用不平衡响应分析，请在 KISSsys 中点击「kSoftSystem 计算单元」。右键单击该单元，然后选择「ForcedResponse」选项。下一个对话框包含执行计算所需的全部输入。可以从系统中包含带已定义边界条件联轴器的轴列表中选择用于计算的参考轴。然后可以选择计算用不平衡响应图的 X 轴（由此也定义了要运行的计算类型）。此处有两个选项：

  • 参考轴速： 参考轴速度在用户指定的范围内（最小/最大速度）被修改，使用预定义的步数。对整个轴系统中的每个速度进行运动学计算，并计算所有轴的速度。这些速度随后用于计算动态载荷，然后施加到模型上。结果是在指定的参考位置上轴的不平衡响应。
  • 参考轴的Y坐标： 在这种情况下，参考轴的长度被划分为预定义的若干段，并针对指定速度进行不平衡响应计算。这样便可得到该速度下参考轴的精确形状。

然后，还可以选择用于计算接触刚度的计算方法，这与模态分析计算类似。

还可以考虑速度对滚动轴承刚度的影响（但仅适用于具有内部几何参数的轴承）。如果选择此选项，则对每个速度进行静力计算，并相应调整动态分析中使用的轴承刚度。

最后，还可以在此对话框中定义扭转、轴向和弯曲振动的阻尼。请注意，轴承的黏性阻尼必须在轴计算中为每个轴承单独定义（单位可自由定义），或在 KISSsys 的轴承属性中定义（SI 单位）。

English Original

Calculation procedure

To call the unbalance response analysis, click on a kSoftSystem calculation element in KISSsys. Right-click on the element, and then select the ForcedResponse option. The next dialog contains all the inputs required to perform the calculation. You can select the reference shaft for the calculation from a list of shafts in the system that include a coupling with a defined boundary condition. You can then select the X-axis of the unbalance response diagram for the calculation (and therefore also define the type of calculation to run). Two options are available here:

  • Reference shaft speed: The reference shaft speed is modified within the range you specified (min/max speed) with the predefined number of steps. A kinematic calculation is performed for each speed in the entire shaft system and the speed of all the shafts is calculated. These speeds are then used to calculate the dynamic loads, which are then applied to the model. The result is the unbalance response in the specified reference position on the shaft.
  • Y-coordinate of the reference shaft: In this case, the length of the reference shaft is subdivided into the predefined number of sections, and the unbalance response calculation is performed for the specified speed. This results in the exact shape of the reference shaft at this speed.

You can then also select the calculation method you want to use to calculate contact stiffness, which is similar to the modal analysis calculation.

The effect of speed on the stiffness of rolling bearings can also be taken into account (but only for bearings with internal geometry). If this option is selected, a static calculation is performed for each speed, and the bearing stiffness used in the dynamic analysis is adjusted accordingly.

Finally, you can also define the damping for torsion, axial and bending vibration in this dialog. Note that the viscous damping of bearings must be defined separately for each bearing in the shaft calculation (freely definable units) or in the bearing's properties in KISSsys (SI units).
