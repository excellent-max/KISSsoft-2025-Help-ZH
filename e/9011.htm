中文翻译

CATIA 3D 接口

制造商：SWMS (DE)

在 KISSsoft 中计算的圆柱齿轮或锥齿轮可直接在 CATIA 中生成具有真实齿形的 3D 零件（参见 3D 齿轮的生成）。您可以创建直齿或斜齿的圆柱齿轮（外齿轮或内齿轮），或按 DIN 3971 图 1 定义的直齿锥齿轮。
您也可以为现有轴添加轮齿。
您会找到一个 *.pdf 文件，其中包含该接口的更详细说明；该文件位于 CATIA 文件夹内，该文件夹位于 KISSsoft 安装目录下。

English Original

3D interface to CATIA

Manufacturer: SWMS (DE)

Cylindrical or bevel gears calculated in KISSsoft can be generated directly in CATIA as a 3D part (see chapter Generation of 3D gears) with a real tooth form. You can create cylindrical gears with straight or helical teeth, which are external or internal, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1.
You can also add gear teeth to existing shafts.
You will find a more detailed description of the interface in a *.pdf file in the CATIA folder in the KISSsoft installation directory.
