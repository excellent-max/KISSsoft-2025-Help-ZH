前言

  • 在本描述中，始终以 KISSsoft 程序作为参考，即 KISSsoft 的输入文件成为第三方程序的输出文件，反之亦然。
  • 为了与其他程序自动交换数据，您需要名为 MMMMUSER.RPT 的文件。您可以根据自己的要求调整这些文件。但是，如果您购买了 KISSsoft 接口，则应谨慎操作，因为这些文件也是这些接口所必需的。

English Original

Preamble

  • In this description the KISSsoft program is always taken as a reference, i.e. an input file for KISSsoft becomes an output file for the third party program and vice versa.
  • For automatic data exchange with other programs you will require files with the name MMMMUSER.RPT . You can adapt these files to your own requirements. However, if you have purchased KISSsoft interfaces, you should act with caution, since these files are also required for these interfaces.
