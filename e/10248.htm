中文翻译

确定等效扭矩（用于载荷谱）

一些计算指南要求您确定载荷谱的等效扭矩，并使用它进行尺寸设计。如何在 KISSsoft 中确定等效扭矩？

这里的基本问题在于，用等效扭矩进行齿形验证必须与用实际载荷谱进行验证给出相同的安全系数。为此，你可以遵循以下步骤：

1. 输入载荷谱并计算齿形。

2. 记下每个齿轮的最低齿根安全系数和最低齿面安全系数。

3. 在 计算设置 窗口中（通过选择 计算 > 设置 访问），在 安全系数 选项卡中使用 安全系数根据尺寸 配置选项，输入用户已记录的所需安全系数。

4. 通过将载荷谱设置为 单级载荷 来将其删除。

5. 点击扭矩输入旁边的尺寸按钮。等效扭矩写入扭矩输入字段。

6. 现在运行计算以检查数据。你现在为特定齿轮的根或齿面定义的安全系数必须恰好等于上一步骤中最小的值（如步骤2）。所有齿轮的安全系数都不能低于你在步骤2中记录的安全系数。

English Original

Determine the equivalent torque (for load spectra)

Some calculation guidelines require you to determine the equivalent torque of a load spectrum and use it to perform sizing. How can I determine the equivalent torque in KISSsoft?

The fundamental issue here is that the verification of a toothing with equivalent torque must give the same safeties as the verification with the actual load spectrum. For this reason, you can follow this procedure:

1. Input the load spectrum and calculate the toothing.

2. Make a note of the lowest root safety and the lowest flank safety for each gear.

3. In the Calculation settings window, which you access by selecting Calculation > Settings , input the safeties you have noted as required safeties in the Safety factors tab using the Safety factors depending on size configuration option.

4. Delete the load spectrum by setting it to Single stage load.

5. Click the Sizing button next to the input for the torque. The equivalent torque is written to the torque input field.

6. Now run the calculation to check the data. The safeties you have now defined for the root or flank of a particular gear must be exactly equal to the previous smallest value (as in step 2). None of the gears can have a safety that is less than the safeties you recorded in step 2.
