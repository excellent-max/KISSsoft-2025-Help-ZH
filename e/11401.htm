中文翻译

齿厚变位系数

圆柱齿轮通常不使用齿厚变位系数 xs。因此您无法在用户界面中输入该系数。但在特殊情况下，您可以使用齿厚变位系数，例如通过 DLL 接口、在 KISSsys 中或通过编辑保存的 .Z12 文件。必须先设置 RechSt.xs_Active = 1 和 RechSt.xs_OwnInput = 1 变量，然后才能设置 xs。然后可将 xs 应用于齿轮 1 等的 ZkegR[0].XS 变量中。有关齿厚变位系数的更多信息，请参见"齿厚变位系数"章。

English Original

Tooth thickness modification coefficient

A tooth thickness modification coefficient xs is not usually used for cylindrical gears. This is why you cannot enter this factor in the user interface. However, in exceptional situations, you can use a tooth thickness modification coefficient, e.g. via the DLL interface, in KISSsys or by editing the saved .Z12 file. The RechSt.xs_Active = 1 and RechSt.xs_OwnInput = 1 variables must be set before you can set xs. Then xs can be applied in the ZkegR[0].XS variables for gear 1 etc. More information about the tooth thickness modification coefficient is provided (see chapter Tooth thickness modification coefficient).
