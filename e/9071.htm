中文翻译

[REPORT] 中的定义

变量名

描述

SIZE

一个数字 0-9，用于指定报告的范围。

INCLUDEWARNINGS

0/1：报告中包含警告

FONTSIZE

设置报告中字体大小的数字。

PAPERFORMAT

图纸幅面：A3, A4, A5, Letter, Legal

PAPERORIENTATION

0/1: 纵向/横向

PAPERMARGINLEFT

距左侧页边距的距离 [mm]。

PAPERMARGINRIGHT

距右侧页边距的距离 [mm]。

PAPERMARGINTOP

距顶部页边距的距离 [mm]。

PAPERMARGINBOTTOM

距底部页边距的距离 [mm]。

COMPARE

0/1：在比较模式下为报告添加日期/时间。

LOGO

设置页眉和页脚中显示的图片文件。

HEADER

包含页眉使用定义。

USEHEADERFORALLPAGES

0/1：页眉仅在第一页/在所有页面上

FOOTER

包含页脚使用定义。

USEFOOTERFORALLPAGES

0/1：页脚仅在第一页/在所有页面上

READONLY

0：报告可编辑并保存为可编辑的文本文件

1：报告不可编辑，只能导出为 PDF 文件

English Original

Definitions in [REPORT]

Variable name

Description

SIZE

A number, 0-9, that specifies the scope of the report.

INCLUDEWARNINGS

0/1: Warnings are contained in the report

FONTSIZE

Number that sets the font size in the report.

PAPERFORMAT

Paper format: A3, A4, A5, Letter, Legal

PAPERORIENTATION

0/1: Portrait/Landscape

PAPERMARGINLEFT

Distance from the left-hand page margin [mm].

PAPERMARGINRIGHT

Distance from the right-hand page margin [mm].

PAPERMARGINTOP

Distance from the top page margin [mm].

PAPERMARGINBOTTOM

Distance from the bottom page margin [mm].

COMPARE

0/1: Adds date/time to the report in comparison mode.

LOGO

Sets the picture file displayed in the header and footer.

HEADER

Contains the header usage definition.

USEHEADERFORALLPAGES

0/1: Header only on first page/on all pages

FOOTER

Contains the footer usage definition.

USEFOOTERFORALLPAGES

0/1: Footer only on first page/on all pages

READONLY

0: Reports can be edited and saved as editable text documents

1: Reports cannot be edited and can only be exported as PDF documents
