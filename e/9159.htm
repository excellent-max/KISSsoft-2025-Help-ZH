中文翻译

数值输入字段

通常，一个数值输入字段包含变量标签、公式符号、编辑字段和单位。如果编辑字段呈灰色显示，则无法预定义该变量，而是在计算过程中确定。一个数值输入字段后面可以跟以下一个或多个按钮：

单击检查按钮，可保留一个值。

可设置单选按钮，以指定一组值中哪些值需要计算，哪些值需要保留。

单击尺寸按钮以使用计算方法计算该值。

单击转换按钮以使用转换公式计算该值。

单击"加号"按钮可显示某个值的附加数据。

单击设置按钮以显示一个值的附加设置选项。

单击"信息"按钮可在信息窗口中显示信息（参见信息窗口）。

English Original

Value input fields

In general, a value input field always includes the variable label, a formula character, the edit field and a unit. If the edit field is grayed out, this variable cannot be predefined. Instead it will be determined during the calculation. One or more of the following buttons can follow a value input field:

You can retain a value by selecting the Check button.

You can set a radio button to specify which values in a group should be calculated and which should be retained.

Click the Sizing button to calculate the value using calculation methods.

Click the Convert button to calculate the value using conversion formulae.

Click the Plus button to display additional data for a value.

Click the Settings button to display additional setting options for a value.

Click the Info button to display information in the Info window (see chapter The info window).
