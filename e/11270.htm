案例 II，试验齿轮几何形状不同时的试验结果

要启用此选项，请停用 基于一个文件的试验齿轮几何形状 选项，可在 计算设置 中停用。试验数据 选项卡中“试验齿轮测量”表内的所需输入字段会根据所做选择进行调整。

在“试验齿轮测量”表中，为每个试验文件选择失效齿轮、失效原因和配对齿轮。.Z12 文件的齿轮编号为 [1, 2]，“*.Z15” 的齿轮编号为 [1, 2, 3]，“*.Z16” 的齿轮编号为 [1, 2, 3, 4]，“*.Z14” 的齿轮编号为 [1=太阳轮, 2=行星轮, 3=内齿轮]。在试验中各齿轮文件内输入扭矩、转速、失效循环次数和温度值。

控制允许的齿根和/或齿面强度计算的其他设置位于试验数据选项卡和计算设置中。第 1.2 节和第 1.3 节对各个参数有更详细的说明。

English Original

Case II. Test results with different gear geometry

To enable this option, deactivate the Test gear geometry based on one file option, in the Calculation settings. The required input fields in the "Test gear measurements" table in the Test data tab are modified to suit the selection you make.

In the "Test gear measurements" table, select the failed gear, the failure cause and the mating gear for every test file. The gear numbers for the .Z12 file are [1, 2], for "*.Z15" they are [1, 2, 3], for "*.Z16" they are [1, 2, 3, 4] and for "*.Z14" they are [1=sun, 2=planets, 3=internal gear]. Enter values for torque, speed, cycles to failure and temperatures in the individual gear files in the test.

Additional settings that control the calculation of permissible root and/or flank strength are available in the Test data tab and in Calculation settings. Sections 1.2 and 1.3 have more detailed explanations of the individual parameters.
