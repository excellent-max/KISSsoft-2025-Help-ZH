中文翻译

语言设置

KISSsoft 有九种语言可用：德语、英语、法语、意大利语、西班牙语、俄语、葡萄牙语、中文和日语。当用户选择一种语言时，程序会区分用户界面使用的语言和报告使用的语言。这样便可以在一种语言下操作 KISSsoft，同时以另一种语言显示报告。消息将以与用户界面相同的语言或与报告相同的语言显示。

在程序中，选择 附加 > 语言 可在许可证中可用的语言之间切换。要进行全局语言设置，您需要编辑 KISS.ini（参见"[SETUP] 中的定义"章）文件。用户可以通过选择 报告 > 设置 来更改报告使用的语言。

English Original

Language settings

KISSsoft is available in nine languages: German, English, French, Italian, Spanish, Russian, Portuguese, Chinese and Japanese. When you select a language, the program differentiates between the language used for the user interface and the language used for the reports. This makes it possible to operate KISSsoft in one language and simultaneously display reports in a different language. Messages will be displayed either in the same language as the user interface or as the reports.

In the program, select Extras > Language to change between the languages available in your license. To make global language settings, you need to edit the KISS.ini (see chapter Definitions in [SETUP]) file. The user can change the language used for reports by selecting Report > Settings.
