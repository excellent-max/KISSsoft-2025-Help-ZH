中文翻译

单位切换

在 KISSsoft 中，您可以在数值输入字段（参见数值输入字段）和表格（参见数值输入字段）中切换所有单位。为此，请右键单击某个单位。这会打开一个上下文菜单，其中会显示该值所有可能的单位。如果您选择了与当前所用单位不同的单位，KISSsoft 会将数值输入字段中的当前值转换为新单位。

要在全局范围内在公制单位和美制惯用单位之间切换，请选择附加 > 单位系统。

English Original

Unit switch

In KISSsoft, you can switch all the units in the value input fields (see chapter Value input fields) and in the tables (see chapter Value input fields). To do this, right-click on a unit. This opens a context menu in which you see all the possible units for the value. If you select a different unit from the one that is currently in use, KISSsoft converts the current value in the value input field to the new unit.

To switch between metric and US customary units globally, select Extras > Systems of units.
