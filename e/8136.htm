中文翻译

Sommerfeld 数

您必须计算 Sommerfeld 数，因为它是滑动轴承的重要特征值。

Sommerfeld 数 > 1 出现在重载轴承中，此时
b/d 的极限为：0 < b/d ≤ 2

Sommerfeld 数 < 1 出现在高速旋转轴承中，此时
b/d 的极限为：0.5 < d/b ≤ 2

d：轴承直径
b：轴承宽度

English Original

Sommerfeld number

You must calculate the Sommerfeld number because it is an important characteristic value for plain bearings.

A Sommerfeld number > 1 occurs in heavily loaded bearings at the
limit for b/d: 0 < b/d ≤ 2

A Sommerfeld number < 1 occurs in quickly rotating bearings at
the limit for b/d: 0.5 < d/b ≤ 2

d: Bearing diameter
b: Bearing width
