螺栓连接类型

要定义螺栓连接的类型，请选择 螺母 或 盲孔。这对应于 VDI 中定义的贯穿螺栓连接与单螺栓攻丝螺纹连接之间的区别。单击相应的 Define... 按钮以显示一个对话框，在其中输入有关螺母或盲孔的其他数据。

盲孔

沉孔深度 ts 描述了一个 无螺纹的铣削槽， 主要用于延长夹紧长度（参见图 42.8）。

螺母

在螺母定义界面中，您可以选择几何标准，也可以通过选择 自定义输入 来自行定义尺寸。

例如，在计算旋合长度时，您可以根据强度等级（按 DIN EN ISO 898-2 规定）定义硬度，也可以直接从材料定义剪切强度。

自定义输入 选项在两种变体中也都提供。但是，当您输入强度等级时，还必须定义剪切强度与拉伸强度之比（τBM/Rm）。

然后，系统会将您在此处输入的硬度值转换为拉伸强度，作为硬度转换过程的一部分。随后，拉伸强度 Rm 乘以比值（τBM/Rm）以计算剪切强度（τBM）。

带标准螺纹（包括 UNC）的螺母的最小硬度值取自 DIN EN ISO 898-2 中表 6 的强度等级。带细牙螺纹（包括 UNF）的螺母的最小硬度值取自同一标准表 7 的强度等级。

注意

如果界面区域 DA 的尺寸仅略大于螺栓头承载区域直径 dw，则必须按贯穿螺栓连接计算（注意变形锥）。

(DA 至 ~1.4*dw)

English Original

Type of bolted joint

To define the type of bolting, select either Nut or Blind hole. This corresponds to the difference between through-bolt and single-bolted tapped thread connections as defined in VDI. Click on the appropriate Define... button to display a dialog in which you input additional data about the nut or blind hole.

Blind hole

The counter bore depth ts describes a milled groove without thread, which is primarily used to elongate the clamp length (see Figure 42.8).

Nut

In the nut definition screen, you can either select a standard for the geometry or define the dimensions yourself by selecting Own Input.

For example, when calculating the length of engagement, you can either define the hardness from the strength class (as specified in DIN EN ISO 898-2) or define the shearing strength directly from the material.

The Own Input option is also available in both variants. However, when you input the strength class, you must also define the ratio of the shearing strength to tensile strength (τBM/Rm).

The system then converts the hardness value you enter here into tensile strength as part of the hardness conversion process. The tensile strength Rm is then multiplied with the ratio (τBM/Rm) to calculate the shearing strength (τBM).

The minimum hardness value for nuts with a standard thread (including UNC) is taken from the strength class in Table 6 in DIN EN ISO 898-2. The minimum hardness value for fine threaded nuts (including UNF) is taken from the strength class in Table 7 of the same standard.

Note

If the dimension of the interface area DA is only slightly larger than the bearing area diameter of the bolt head dw, it must be calculated as a through-bolt connection (note the deformation cone).

(DA to ~1.4*dw)
