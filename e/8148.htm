中文翻译

热安全工作转速

定义热安全工作转速的方法在 DIN 732 [65] 中描述，基于轴承中的热量水平。热安全工作转速由热参考转速使用速度比推导得出。该计算的结果是轴承在实际情况下以允许温度运行时所达到的速度。该热安全工作转速可能与其他运行速度极限有很大差异，具体取决于润滑类型，因为参考条件只适用于非常特定的情况。在确定热安全工作转速之前，您必须先为每种情况定义热参考转速。

注意：

对于球面滚子轴承（单列调心滚子轴承）、角接触推力滚子轴承、交叉滚子轴承以及所有混合轴承，无法进行计算，因为相关标准中没有这些轴承的数值。

English Original

Thermally safe operating speed

The method for defining the thermally safe operating speed is described in DIN 732 [65], based on the heat levels in the bearing. The thermally safe operating speed is derived from the thermal reference speed, using the speed ratio. The result of this calculation is the speed that will be reached by the bearing running at the permitted temperature in an actual situation. This thermally safe operating speed may differ greatly from other operating speed limits, depending on lubrication type, because the reference conditions only apply to quite specific cases. Before you can determine the thermally safe operating speed, you must first define the thermal reference speed for each case.

Note:

Calculations cannot be performed for barrel roller bearings (single row self-aligning roller bearings), angular contact thrust roller bearings, cross roller bearings, and all hybrid bearings, because none of the relevant standards have values for them.
