动态用户界面

KISSsoft 界面由可编辑的文本文件（描述数据）定义。它包含的元素是软件的固定组成部分。然而，任何用户都可以决定这些元素如何划分和排列。常用条目可以在选项卡和对话框中优先显示，不常用条目可以被隐藏或设为只读。KISSsoft 因此可以很容易地适应个别用户的需要。

English Original

Dynamic User Interface

The KISSsoft interface is defined by its editable text files (descriptive data). The elements it contains are fixed components of the software. However, any user can decide how these elements are divided up and arranged. Frequently used entries can be given priority in the tabs and dialog and less commonly used entries can be either hidden or write-protected. KISSsoft can therefore easily be adapted to suit the requirements of individual users.
