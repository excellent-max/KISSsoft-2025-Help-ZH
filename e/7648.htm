中文翻译

变量

可以使用以下变量：

  • Real：一个数值。
  • String：一个字符串。输入需用引号括起，例如 "Text"。
  • Point：具有 3 个分量的坐标或向量。以 {1,2,3} 格式输入。
  • Array：一维或多维字段。例如输入为 ["text",1.23,{1,2,3},[1,2]]。
  • Function：可执行函数。最好通过专用输入屏幕输入。
  • Element ID：Classcad 对象的 ID。输出为 $31，输入为不带引号的对象名称。
  • List：以列表框显示，在 Interpreter 中作为数字使用（列表索引，从 0 开始）。列表框通过 编辑列表 菜单选项定义为数组，例如 ["one","two","three"]。
  • Database List：KISSsoft 数据库中的名称显示在列表框中。在 Interpreter 中，此类型也根据数据库 ID 作为数字使用。要将数据库分配定义为数组，请选择 编辑列表 菜单选项：["database","table"]

每个变量都有一个名称、一个值、一个表达式和不同的标志。如果存在表达式，则变量的值由该表达式定义。因此，表达式特别适合输入公式。相反，如果在值的位置输入公式，则该公式将被求值，结果将被赋值，而实际公式将丢失。KISSsoft -> KISSsys 和 KISSsys-> KISSsoft 选项决定了两个程序之间如何交换数据。只有激活了相应选项的变量才会被交换。

对于 Real、String、Point、List 和 Database List 数据类型，还有额外的引用元素和变体元素。

English Original

Variables

The following variables can be used:

  • Real: A numerical value.
  • String: A character string. Input in quotation marks e.g. "Text".
  • Point: A coordinate or vector with 3 components. Input in {1,2,3} format.
  • Array: A one-dimensional or multidimensional field. Input as e.g ["text",1.23,{1,2,3},[1,2]].
  • Function: An executable function. Input best entered via the special input screen.
  • Element ID: The ID of a Classcad object. Output as $31, input as name of the object with no quotation marks.
  • List: Displayed as a selection list and acts as a number in the Interpreter (list index, beginning with 0). The selection list is defined as an array via the Edit list menu option, e.g. ["one","two","three"].
  • Database List: The name from the KISSsoft database is displayed in a selection list. In the Interpreter, this type also acts as a number according to the database ID. To define the database assignment as an array, select the Edit the list menu option: ["database","table"]

Each of the variables has a name, a value, an expression and different flags. If an expression is present, the value of the variables is defined via this expression. The expression is therefore particularly well suited for inputting formulae. If, in contrast, a formula is entered in place of the value, this formula will be evaluated and the result will be assigned. The actual formula will be lost. The KISSsoft -> KISSsys and KISSsys-> KISSsoft options determine how data is exchanged between the two programs. Only variables with the appropriate option activated are exchanged.

There are additional reference elements and variant elements for the Real, String, Point, List and Database List data types.
