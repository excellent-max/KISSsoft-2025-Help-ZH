编辑控制文件

你可以通过修改控制文件来调整制造图样以满足自己的要求。用于控制制造图样的命令在下表中描述。

纸张大小：A4

纸张大小：A4 纵向

纸张大小: 297, 210

指定所需纸张格式。此术语指用于描述常用纸张尺寸（A3、A4、A5、B4、B5、Letter、Legal 和 Ledger）的标准术语，同时也允许您输入自定义的宽度和高度尺寸。

默认设置为横向图纸幅面。然而，您可以通过输入关键字"portrait"切换为纵向图纸幅面。

字体大小: 5

指定所需字体大小。字体大小会影响报告和简图标题的尺寸。

单位：英寸

默认设置是假设输入值以mm为单位。系统可处理的单位有英寸、mm和cm。


现在可以添加具有特定属性的图形。下表给出了正确的输入方式概览。

绘制2DDiaProfileChart1

“Draw”是用于指定要添加一个图形的关键字。它后面跟着要插入的图形的ID。最后的数字是ID的一部分，并标识齿轮。

窗口：160, 285, 0, 85

“Window”标识图形显示的窗口。值显示左右上下的限制。

适应缩放

此可选指令迫使图形变形，以便在所有方向上填满窗口。我们建议用于示意图，但不建议用于几何展示。

如果未使用此术语，则保留图形的原始大小和形状。

固定比例 2

此可选指令生成图形的缩放输出。数字对应比例（例如，M 2:1 为 2，M 1:10 为 0.1 等）。

最后，你现在可以将报告显示在所需位置：

写报告1

“Write”是用于创建齿轮数据报告的关键字。输入report1以选择齿轮1的数据，输入report2以选择齿轮2的数据，依此类推。

右上角：297, 218

与图形不同，此处必须指定对齐方式，该对齐方式由第一个词定义。正确的命令是 topright:、topleft:、bottomright: 和 bottomleft:。它们表示对齐方式（右上、左上、右下和左下）。接下来的两个值表示特定的参考点。

English Original

Editing the control file

You can modify the manufacturing drawing to suit your own requirements by making changes to the control file. The commands used to control the manufacturing drawing are described in the following table.

Papersize: A4

Papersize: A4 portrait

Papersize: 297, 210

Specifies the required paper format. This refers to the standard terms used to describe commonly used paper sizes (A3, A4, A5, B4, B5, Letter, Legal and Ledger), and also enables you to input your own dimensions for width and height.

The default setting is for landscape format. However, you can switch to portrait format by entering the key word "portrait".

Fontsize: 5

Specifies the required font size. The font size influences the size of the report and the diagram titles.

Units: inch

The default setting is that input values are assumed to be in mm. The system can handle these units: inch, mm and cm.


You can now add graphics that have specific properties. The table below gives an overview of the correct inputs.

Draw 2DDiaProfileChart1

“Draw" is the key word used to specify that a graphic is to be added. It is followed by the ID of the graphic you want to insert. The number at the end is part of the ID, and identifies the gear.

Window: 160, 285, 0, 85

“Window" identifies the window in which the graphic is displayed. The values show the limits on the left, right, bottom and top.

Scaletofit

This optional command forces the graphic to distort so that it fills the window in every direction. We recommend this for diagrams, but not for geometric presentations.

If this term is not used, the original size and shape of the graphic is retained.

Fixedscale 2

This optional command generates a scaled output of the graphic. The number corresponds to the scale (in this case, 2 for M 2:1, 0.1 for M 1:10, etc.).


You can insert these graphics:

Tooth form

2DGeoToothDrawing

Drawing

2DGeoGearDrawing

Assembly

2DGeoAssemblyDrawing

Tool

2DGeoToolDrawing

Profile diagram

2DDiaProfileChart

Flank line diagram

2DDiaFlankLineChart

Angle of flank normal

2DDiaNormal


Finally, you can now display the report in the required location:

Write report1

“Write" is the key word used to create a gear data report. Enter report1 to select the gear data of gear 1, report2 to select the gear data from gear 2, etc.

Topright: 297, 218

Unlike graphics, you must specify an alignment here, which is defined with the first word. The correct commands are topright:, topleft:, bottomright: and bottomleft:. They represent the alignment (top right, top left, bottom right and bottom left). The next two values represent the particular reference point.
