中文翻译

材料

选择列表包含标准中的材料。
如果设置了 自定义输入 标志，将显示一个新对话框。其中包含计算中使用的材料数据，您可以根据自己的需要指定。您还可以直接在数据库中定义您自己的材料（参见"数据库工具和外部表"章），以便在后续计算中使用。

English Original

Materials

The selection list contains materials from the standard.
If you have set the Own input flag, a new dialog is displayed. This contains the material data used in the calculation, which you can specify to suit your own purposes. You can also define your own materials directly in the database (see chapter Database Tool and External Tables), so that they can also be used in subsequent calculations.
