f0r and f1r coefficients

The coefficients f0r and f1r used to define the thermal reference speed are different, depending on which bearing type/series (also lubrication type for f0r) is used. They are shown in Table A.1 of the standard. Not all bearing variants are listed in the table.

The following values have been assumed for bearings and bearing types for which no data has been defined in the standard:
