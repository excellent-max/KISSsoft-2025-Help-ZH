中文翻译

尺寸计算

在 端面最小和最大压力角 αt,min/max 输入字段中输入的值定义了面齿轮齿面压力角沿齿宽方向所包含的范围。例如，这些值在计算面齿轮的齿宽 b2 和轴向偏置 bv 时使用。

English Original

Sizings

The values entered in the Minimum and Maximum pressure angle in transverse section αt,min/max input fields define the range that contains the values for the face gear tooth flank pressure angle across the width. These values are used, for example, when sizing the facewidth of face gear b2 and axial offset bv.
