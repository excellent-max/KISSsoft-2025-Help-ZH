在"载荷"选项卡中输入的值

螺栓连接配置（带载荷）在此选项卡中定义。此外，还可以定义载荷施加、偏心载荷/预紧、温度以及"带 FEM 结果的螺栓校核"选项。这些值适用于工作条件。

Values input in the "Load" tab

The bolted joint configuration, with loads, is defined in this tab. In addition, a load application, eccentric load/pretension, temperatures and a "Proof for bolts with FEM results", if selected, can be entered in this tab. The values apply for the working conditions.
