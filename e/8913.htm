中文翻译

定义载荷谱

在此组中，您还可以访问已存储在数据库中的载荷谱。您也可以直接定义载荷谱。

如果选择读取，您可以导入包含载荷谱的文件（.txt 或 .dat 格式）。

'Example_DutyCycle.dat' 文件位于 dat 子文件夹（KISSsoft 安装目录）中，是展示如何定义载荷谱的示例文件。对于载体上的载荷谱，必须应用 'Example_Carrier_DutyCycle.dat' 中所示的特殊格式并带有标题。

如果希望在使用载荷谱计算时为每个载荷级考虑单独的系数（KHβ、Kγ 等），请打开系数选项卡。在其中，对载荷分布系数 Kγ（参见"啮合载荷系数"章）、交变弯曲系数 YM（参见"交变弯曲系数"章）和齿向载荷系数 KHβ（参见"齿向载荷系数"章）进行相应设置。系数（KHβ、Kγ 等）定义载荷谱的示例可在 'Example_DutyCycleWithFactors.dat' 文件中查看，该文件位于 dat 子目录（KISSsoft 安装目录）中。

如果选择扭矩测量 选项，还可以从一系列扭矩/转速/时间测量值生成载荷谱。单击载荷谱表格下方的 Convert 按钮以调用此选项（参见"扭矩测量"章）。

English Original

Define load spectrum

In this group, you can also access load spectra that have been stored in the database. You can also define the load spectra directly.

If you select Read, you can import a file (in either .txt or .dat format) with a load spectrum.

The 'Example_DutyCycle.dat' file in the dat sub-folder in the KISSsoft installation directory is an example of a file that shows how a load spectrum can be defined. For load spectra on carriers, the special format shown in 'Example_Carrier_DutyCycle.dat' must be applied with a header.

If you want separate factors (KHβ, Kγ, etc.) to be taken into account in the calculation with load spectra for each load bin, open the Factors tab. In it, make the appropriate settings for the load distribution coefficient Kγ (see chapter Mesh load factor), the alternating bending factor YM (see chapter Alternating bending factor) and the face load factor KHβ (see chapter Face load factor). An example of how a load spectrum can be defined with factors (KHβ, Kγ, etc.), can be seen in the 'Example_DutyCycleWithFactors.dat' file in the dat sub-directory in the KISSsoft installation directory.

A load spectrum can also be generated from a series of measurements with torque/speed/time if you select the torque measurement option. Click the Convert button below the Load spectrum table to call this option, (see chapter Torque measurement).
