常规

在强迫响应中运行基本计算后，可以在此选择齿轮副、轴承和文档点来计算输出结果。对于每个组，既可以一起选择所有元素，也可以选择性地定义每个元素。除了在 图形 中生成输出数据外，结果还可以保存为 .txt 文件并导出以供进一步使用。因此，需要通过勾选相应的复选框来选择所需的输出。要导出这些文件，请选择 文件 > 导出 > 强迫响应 > 常规。

动态系数： 动态系数描述了每个齿轮副在不同运行转速下因传动误差激励而产生的整体动态响应。必须特别注意那些具有高动态系数值的转速。如果选择 齿轮啮合力 选项作为计算类型，则可以生成动态系数。因此，如果选择 不平衡质量 选项，则不可用。要计算齿轮副的动态系数，需要建立并求解系统方程，以在频域中计算每个齿轮副的动态接触力。然后将这些力转换到时域：

频域和时域输出： 基于基本计算步骤计算出的动态啮合力，在频域中计算轴承和轴的结果。与动态系数计算相比，它需要更高的计算量，因此建议选择所需的输出。

对于在时域和转速域中计算的结果，首先在频域中对所选输出进行后处理。然后，在后续步骤中，将其在时间上表示出来。由于时域输出数据的生成是在时间范围内的所有时间步上进行的，因此它比仅需要频域输出的情况更耗时。

English Original

General

After running the basic calculation in the forced response, the gear pairs, bearings, and documentation points can be selected here to calculate the output results. For each group, selection of all elements together as well as selective definition of each element is available. In addition to generating the output data in Graphics, the results can be saved as .txt files and exported for further use. Therefore, it is required to select the demanded outputs by checking the corresponding boxes. To export these files, select File > Export > Forced response > General.

Dynamic factor: The dynamic factor characterizes the overall dynamic response of each gear pair at different running speeds as the result of transmission error excitation. Special attention must be paid to those speeds that have high dynamic factor values. The dynamic factor can be generated if the Gear meshing forces option was selected as the type of calculation. Consequently, it is not available if the Unbalance mass option was selected. To calculate the dynamic factor of gear pairs, system equations are generated and solved, to calculate the dynamic contact forces of each gear pair in the frequency domain. These forces are then converted to the time domain:

The maximum dynamic force F(t) is determined and divided by the corresponding static force Fs to determine the dynamic factor:

Frequency and time domain outputs: Calculating the results of the bearings and shafts in the frequency domain is carried out based on the dynamic meshing forces calculated from the basic calculation step. Compared to dynamic factor calculation, it requires higher computational effort and therefore, it is recommended to select the demanded outputs.

For calculating the results in the time and speed domains, first the postprocessing is done for the selected outputs in the frequency domain. Then, in subsequent steps, they are represented in time. Since generating the output data in the time domain is carried out at all time steps in the time range, it is more time consuming than the case when only the frequency domain outputs are required.
