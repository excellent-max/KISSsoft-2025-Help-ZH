中文翻译

项目树

项目树显示打开的项目的概览以及属于这些项目的文件，并以粗体突出显示当前工作项目（参见"当前工作项目"章）。您可以通过项目管理功能（参见"项目管理"章），从 项目 菜单或上下文菜单（参见"菜单、上下文菜单和工具栏"章）使用。

English Original

The project tree

The Project Tree gives you an overview of the open projects, and the files belonging to these projects, and highlights the active working project (see chapter The active working project) in bold. You use project management functions (see chapter Project Management) via the Project menu or from a context menu (see chapter Menus, context menus and the tool bar).
