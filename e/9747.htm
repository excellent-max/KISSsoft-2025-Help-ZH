中文翻译

注册服务器

现在在本地计算机上注册 KISSsoft COM 服务器。有两种不同的方法可以完成此操作：

  • 右键单击以显示上下文菜单，然后选择 以管理员身份运行 以显示 Windows 提示符。然后，转到 "... /bin" 子文件夹并运行 "KISSsoftCOM_Register.bat" 文件。
  • 为此，请在 Windows 命令提示符中，在 KISSsoft 安装目录的 bin 目录中输入以下命令行：

KISSsoftCOM.exe /regserver

regsvr32 KISSsoftCOMPS.dll

regsvr32 KISSsoftCOMPS.dll

为了让您无论发布级别如何都能使用 COM 服务器，提供了一个带相关发布号的版本特定 COM 接口。

要使用此变体，请运行 KISSsoftCOM_RegisterXXXX.bat 文件或下面列出的文件。（此处，XXXX 代表版本号，例如 2021）：

KISSsoftCOMXXXX.exe /regserver

regsvr32 KISSsoftCOMXXXXPS32.dll

regsvr32 KISSsoftCOMXXXXPS64.dll

需要管理员权限才能注册每个程序。

English Original

Registering the server

Now register the KISSsoft COM server on your local computer. There are two different ways of doing this:

  • Right-click to display the context menu and then select As administrator to display the Windows prompt. Then, go to the "... /bin" subfolder and run the "KISSsoftCOM_Register.bat" file.
  • To do this, enter these command lines in a Windows command prompt, in the KISSsoft installation bin directory:

KISSsoftCOM.exe /regserver

regsvr32 KISSsoftCOMPS.dll

regsvr32 KISSsoftCOMPS.dll

To enable you to use the COM server regardless of release level, there is a version-specific COM interface that has the relevant release number.

To use this variant, run the KISSsoftCOM_RegisterXXXX.bat file or the files listed below. (Here, XXXX represents the version number, e.g. 2021):

KISSsoftCOMXXXX.exe /regserver

regsvr32 KISSsoftCOMXXXXPS32.dll

regsvr32 KISSsoftCOMXXXXPS64.dll

You will need administrator rights to register each program.
