中文翻译

滚刀公差

滚刀公差使用内部标准预定义，可从下拉列表中选择。输入字段锁定，无法输入数据。

从下拉列表中选择 自定义输入，即可手动定义公差。

注意：

  • 滚刀参数的基本值必须在 参考齿廓 选项卡中配置。
  • 只有公差可以在 展开 选项卡中管理。
  • 展开 选项卡中的所有标准滚刀参数与 参考齿廓 选项卡中的参数一致。
  • 软件中引入了范围限制，以确保公差相对于其他值而言是合理的。
English Original

Hobbing cutter tolerances

Tolerances for the hobbing cutter are predefined using internal standards and can be selected from a dropdown list. Input fields are locked for data entry.

By selecting Own Input from the dropdown list, tolerances can be defined manually.

Note:

  • Base values of hob parameters must be configured in the Reference profile tab.
  • Only the tolerances can be managed in the Rollout tab.
  • All standard hob parameters in the Rollout tab are consistent with those found in the Reference profile tab.
  • Range limits are introduced in the software to ensure that the tolerances make sense relatively to other values.
