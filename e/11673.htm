轴计算模块中的设置

在执行强制响应分析之前，轴计算模块中有一些重要的设置必须详细考虑。这些设置会对结果产生显著影响。这里简要提及其中一些。

轴上的齿轮： 在基本数据选项卡中提供了四种轴上的齿轮定义类型：

  1. 仅作为载荷施加的齿轮
  2. 作为质量的齿轮
  3. 作为质量和刚度的齿轮
  4. 根据 ISO 6336-1 作为质量和刚度的齿轮

根据所选齿轮定义类型，在强制响应分析中会在内部考虑相应的设置来定义齿轮。

在第一种情况下，轴计算分析中忽略齿轮质量。但是，在系统动力学方程中，它必须作为点质量考虑（以所谓的傅里叶矩阵形式，它将轴的响应与齿轮体动力学联系起来）。在第二种情况下，齿轮在轴计算响应中作为点质量考虑，但在傅里叶矩阵中忽略。在最后一种情况下，齿轮作为质量和刚度，齿轮单元被视为轴的一部分，其效应集成到轴中。因此，它在傅里叶矩阵中被忽略。

如果任何轴计算中的齿轮定义与其他轴计算中的定义不同，则在强制响应计算结束时显示警告消息。该定义也可以在系统模块的系统数据 选项卡中设置一次，以确保其对所有齿轮一致。

滚动轴承计算： 在轴计算模块的滚动轴承选项卡中，您可以为计算方法选择以下设置之一：

  1. 刚度：不计算
  2. 刚度：ISO/TS 16281

该定义也可以在系统模块的系统数据选项卡中设置一次，以确保其对所有滚动轴承一致。如果选择刚度：不计算，则在 KISSsoft 中考虑非常大的刚度系数。强制响应计算结束时显示带有此信息的警告消息。此外，某个轴计算中滚动轴承刚度的选择与其他轴计算不同，会导致另一条警告消息。

常规： 以下选项对强制响应分析的结果有贡献：

  1. 考虑重量
  2. 考虑陀螺效应
  3. 考虑剪切引起的变形（Timoshenko 梁）

前两个项目也可以在系统模块的系统数据 选项卡中设置，以确保它们对所有轴计算一致。

支承和轴承： 定义轴承时，刚度系数、阻尼系数和施加的边界条件会对强制响应分析结果产生显著影响。此外，在轴承中，阻尼系数可以由用户手动指定。

文档点： 强制响应分析的某些输出类型需要在轴上有一个文档点。实际上，文档点指定了轴上要求某些轴输出的规定测量点。这一事实将在图形章节图形中更详细地解释。如果文档点位于轴外，则会显示错误消息。同样的规则也适用于轴上的耦合位置。

English Original

Settings in the shaft calculation module

There are some important settings in the shaft calculation module which must be taken into account in detail before performing a forced response analysis. These settings can have a significant effect on the results. Some of them are briefly mentioned here.

Gear on shaft: Four types of definition for gears on a shaft are available in the Basic data tab:

  1. Gears as load applications only
  2. Gears as mass
  3. Gears as mass and stiffness
  4. Gears as mass and stiffness acc. to ISO 6336-1

According to the selected type of gear definition, the corresponding settings are considered internally in the forced response analysis to define the gears.

In the first case, the gear mass is neglected in the shaft calculation analysis. However, in the system dynamic equations, it is to be taken into account as a point mass (in the form of a so-called Fourier matrix, which relates the response of the shafts to the gear body dynamics). In the second case, the gear is taken into account as a point mass in the shaft calculation response, but neglected in the Fourier matrix. In the last case, Gear as mass and stiffness, the gear element is considered as part of the shaft and its effect is integrated into the shaft. For this reason, it is neglected in the Fourier matrix.

If the definition of the gear in any shaft calculation differs from the definition in other shaft calculations, a warning message is displayed at the end of the forced response calculation. This definition can also be set once in the System data tab in the system module to ensure it is consistent for all gears.

Rolling bearings calculation: In the Rolling bearing tab in the shaft calculation module, you can select one of the following settings for the calculation method:

  1. Stiffness: Not calculated
  2. Stiffness: ISO/TS 16281

This definition can also be set once, in the System data tab in the system module, to ensure it is consistent for all rolling bearings. If Stiffness: Not calculated is selected, a very large stiffness coefficient is considered in KISSsoft. A warning message with this information is displayed at the end of the forced response calculation. In addition, selections of the stiffness of the rolling bearings in a shaft calculation different from other shaft calculations results in another warning message.

General: The following options contribute to the results of the forced response analysis:

  1. Consider weight
  2. Consider gyroscopic effect
  3. Consider deformation due to shearing (Timoshenko beam)

The first two items can also be set in System data tab in the system module to ensure they are consistent for all shaft calculations.

Supports and Bearings: When defining bearings, the stiffness coefficients, the damping coefficients and the imposed boundary conditions can have significant effect on the forced response analysis results. In addition, in the bearings, the damping coefficients can be manually specified by the user.

Documentation points: Some output types of the forced response analysis require a documentation point on a shaft. In fact, documentation points specify prescribed measuring points on the shafts where certain shaft outputs are demanded. This fact will be explained in greater detail in the Graphics section Graphics. If a documentation point is located outside of a shaft, an error message is shown. The same rule holds also for the coupling locations on the shafts.
