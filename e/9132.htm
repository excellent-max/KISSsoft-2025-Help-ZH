中文翻译

从网络断开许可证

如果 KISSsoft 未正常关闭，且正在使用网络版本，则用户可能仍保持注册状态。这可能导致即使某些用户已不再使用 KISSsoft，许可证仍被占用。您可以通过选择所需的许可证（同时也会显示用户和启动时间）从网络断开许可证。为此，请选择附加功能 > 许可证工具选项（位于网络选项卡中）。然后系统还会删除相应的 cookie 文件，并再次在网络中激活被占用的许可证。

未使用的许可证将在一定时间后、下一位用户登录时立即被激活。该时间间隔可通过 TIMEOUT（参见"[LICENSE] 中的定义"章）变量来预定义，该变量位于 KISS.ini（参见"全局设置 - KISS.ini"章）文件中。

注意

已与 KISSsoft 断开连接的用户无法再在当前会话中进行计算。该用户必须重新启动 KISSsoft。但是，他们仍然可以保存数据。

English Original

Disconnect license from the network

If KISSsoft has not been properly shut down, users may remain registered if a network version is in use. This may lead to licenses being blocked even though some users are no longer working with KISSsoft. You can disconnect a license from the network by selecting the required license (the user and start time are also displayed). To do so, select the Extras > License tool option in the Network tab. The system then also deletes the appropriate cookie file and activates the blocked license on the network again.

Unused licenses will be activated after a certain time, as soon as the next user logs on. This time-span can be predefined via the TIMEOUT (see chapter Definitions in [LICENSE]) variable in the KISS.ini (see chapter Global settings - KISS.ini) file.

Note

A user who has been disconnected from KISSsoft can no longer carry out calculations in the current session. The user must restart KISSsoft. However, they can still save data.
