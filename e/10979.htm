中文翻译

组

设置 <group> 标签以添加一个组。描述文件中的组按其在界面中出现的顺序排列。组也可以包含列。组不能嵌套。


设置<title> 标签以定义组的标题。该标签可以包含实际文本或来自 KISSsoft 术语表（wpoolUi_.txt）的文本 ID（数字）。


组示例：

<group>

<title>145</title>

<element>Element1</element>

<element>Element2</element>

</group>

English Original

Groups

Set the <group> tag to add a group. The groups in the description file appear in the same sequence as they appear in the interface. Groups can also contain columns. Groups cannot be nested.


Set the <title> tag to define a group's title. The tag can contain either an actual text or the ID (number) of a text from the KISSsoft Glossary (wpoolUi_.txt).


Example of a group:

<group>

<title>145</title>

<element>Element1</element>

<element>Element2</element>

</group>
