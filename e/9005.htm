中文翻译

打开计算文件

选择打开计算文件菜单选项可启动 KISSsoft。这将加载轮齿计算文件，并将信息直接保存到轮齿特征（齿槽）中。选择此菜单选项后，会显示一个窗口，供您选择所需对象：

  • 直齿圆柱齿轮：INSTANCE[0](4)TOOTH(4)
  • 斜齿圆柱齿轮/蜗杆/直齿锥齿轮：TOOTH

单击"确定"按钮后，KISSsoft 会在相应模块中打开已加载的轮齿计算文件。

English Original

Opening the calculation file

Select the Open calculation file menu option to start KISSsoft. This loads the gear teeth calculation file and the information is saved directly to the gear teeth feature (tooth space). After you select this menu option, a window in which you select the required object is displayed:

  • Straight-toothed cylindrical gears: INSTANCE[0](4)TOOTH(4)
  • Helical cylindrical gears/worms/Straight-toothed bevel gears: TOOTH

When you click on the OK button, KISSsoft opens in the appropriate module with a loaded gear teeth calculation file.
