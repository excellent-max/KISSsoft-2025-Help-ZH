中文翻译

改变变位系数时保持齿根圆不变

在 KISSsoft 中，通常保持参考齿廓不变，并相应地修改齿顶圆和齿根圆。如果选择此选项，则保持齿根圆不变，并在改变变位系数时相应地修改参考齿廓。只要齿数和端面模数保持不变，齿根圆值就保持不变。只有选中"中心距"复选框时，此选项才可用。

English Original

Maintain root circle when changing profile shift

In KISSsoft, the reference profile is usually maintained and the tip and root circle are modified to suit. If you select this option, the root circle is maintained and the reference profile is modified to match it when the profile shift is changed. The root circle value is maintained as long as the number of teeth and the transverse module stay the same. This option is only available if the Center distance checkbox is selected.
