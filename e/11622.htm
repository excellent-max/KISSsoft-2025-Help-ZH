中文翻译

使用专有轴承内部几何数据

当根据标准 ISO/ TS16281 计算轴承刚度和额定寿命时，需要轴承内部几何参数，如滚动体数量、滚动体直径、滚动体节圆直径、密合度等（另请参见"滚动轴承（内部几何）"章）。如果数据库中缺少这些数据，KISSsoft 将对其进行估算。但是，一些轴承制造商确实提供这些数据，但不愿将其公开给最终用户。在这种情况下，KISSsoft 中的轴承内部几何数据保存在一个不向最终用户公开的隐藏数据库中。由于这些数据具有专有性，除滚动体数量外，它们不会显示在报告或图形中。如果激活此设置，KISSsoft 将使用隐藏数据库中提供的专有轴承内部几何数据（如果可用）；否则，它将使用常规 KISSsoft 数据库中存储的数据（如果存储在那里）。请注意，对于常规数据库或隐藏数据库中均不可用的数据，KISSsoft 始终会进行估算。

English Original

Using proprietary bearing internal geometry data

When calculating bearing stiffness and rating life according to standard ISO/ TS16281 an internal bearing geometry, such as number of rolling elements, rolling body diameter, rolling body pitch diameter, osculation, etc., is needed (see also (see chapter Rolling Bearings (Internal Geometry)). If these data are not available in the database, KISSsoft will estimate them. However, some bearing manufacturers do provide these data but are not willing to expose them to the end users. In such case the bearing internal geometry data in KISSsoft are kept in a hidden database which is not exposed to an end user. Since these data are proprietary, they are not shown in the reports or graphics, except number of rolling elements. If this setting is activated, KISSsoft will use - if available - proprietary bearing internal geometry data given in a hidden database, otherwise it will use data provided in a regular KISSsoft database - if stored there. Note that KISSsoft always estimates data that are not available in the regular database or in the hidden database.
