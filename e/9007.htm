与 Creo Parametric (ProEngineer) 的 3D 接口

制造商：Applisoft Europe (Italy)

在 KISSsoft 中计算的圆柱齿轮或锥齿轮，可以在 Creo Parametric 中直接生成为具有真实齿形的 3D 零件（参见3D 齿轮生成一章）。您可以创建直齿或斜齿的圆柱齿轮（外齿轮或内齿轮），或直齿锥齿轮，如 DIN 3971 图 1 所定义。

除零件外，系统还会打开一张图纸，齿轮的制造数据以表格形式显示在其中。在开始通过 3D 接口在 Creo Parametric 中生成零件之前，请先打开 CAD 系统。

在 Creo Parametric 的接口中，您可以为特定齿轮的文件（例如 Z10GEAR1CAD.rpt）输入附加变量，这些文件位于 CAD 目录中。这些附加变量随后将被定义为参数并保存在 Creo Parametric 中。
生成过程中所用的参数已在 Creo Parametric 中定义，不能再使用。预定义参数：

  • pz, z, b, da, d, df, di, elica, USUnit

如果要以美制单位（非公制）创建零件模型，请打开 kiss.ini 文件（参见[PROENGINEER] 中的定义一章），并将 USCUSTOMARYUNITS 参数设置为 1。

您也可以更改现有轮齿而不实际影响零件（参见修改选定的 3D 模型一章）。您还可以在现有轴上切削轮齿（参见在现有轴上切削轮齿一章）。

一旦开始生成过程，就会打开一个新的对话框。此对话框包含这三个选项：

  1. 在新文件中生成齿轮
  2. 在轴上生成齿轮
  3. 退出

如果选择 在新文件中生成齿轮，齿轮将生成在一个新的零件文件中。

注意：

如果希望阻止选择菜单或消息出现，可以在接口的基本设置中指定（参见更改接口中的基本设置一章）。

3D interface to Creo Parametric (ProEngineer)

Manufacturer: Applisoft Europe (Italy)

Cylindrical or bevel gears calculated in KISSsoft can be generated directly in Creo Parametric as a 3D part (see chapter Generation of 3D gears) with a real tooth form. You can create cylindrical gears with straight or helical teeth, which are external or internal, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1.

In addition to the part, the system opens a drawing in which the gear manufacturing data appear in a table. Open the CAD system before you start generating a part with the 3D interface to Creo Parametric.

In the interface to Creo Parametric, you can enter additional variables in the files for the particular gear (e.g. Z10GEAR1CAD.rpt) in the CAD directory. These additional variables will later be defined as parameters and saved in Creo Parametric.
The parameters used for the generating process are already defined in Creo Parametric and can no longer be used. Predefined parameters:

  • pz, z, b, da, d, df, di, elica, USUnit

If you want to create a model of a part in US customary units (not metric), open the kiss.ini file (see chapter Definitions in [PROENGINEER]) and set the USCUSTOMARYUNITS parameter to 1.

You can also change an existing toothing without actually affecting the part (see chapter Modifying the selected 3D model). You can also cut gear teeth on an existing shaft (see chapter Cutting gear teeth on an existing shaft).

A new dialog opens as soon as you start the generating process. This dialog has these three options:

  1. Generate gear in new file
  2. Generate gear on shaft
  3. Exit

If you select Generate gear in new file, the gear is generated in a new part file.

Note:

If you want to prevent the selection menu or message from appearing, you can specify this in (see chapter Changing base settings in the interface).
