中文翻译

随系统提供的可修改选项卡和对话框

系统提供的选项卡和对话框的描述文件存储在kui（kisssoft用户界面）目录中。这些文件在任何情况下都不得由用户修改。这是因为通过补丁提供的界面升级总是会覆盖任何用户修改。要修改界面以满足用户的需求，请将相应的描述文件复制到ext/kui目录并在此处进行更改。KISSsoft 首先评估此目录中的文件。描述文件通过文件名和文件扩展名.kui分配给相应的计算模块。这就是为什么文件名不能更改。

English Original

Modified tabs and dialogs supplied with the system

The description files for the tabs and dialogs supplied with the system are stored in the kui (kisssoft user interface) directory. These files should never, under any circumstances, be modified by the user. This is because interface upgrades, which are supplied with a patch, always overwrite any user modifications. To modify the interface to suit your own requirements, copy the appropriate description file to the ext/kui directory and change it there. KISSsoft evaluates the files in this directory first. The description files are assigned to the appropriate calculation module by their file name and the file extension .kui. This is why the file name must not be changed.
