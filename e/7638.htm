中文翻译

表格视图

要显示表格，请在树视图的上下文菜单中选择显示功能。表格的内容在系统设置时定义。虽然以黑色显示的值不能更改，但您可以编辑以红色显示的数字或文本。用于用户界面的特殊表格具有灰色背景的字段。用鼠标左键双击这些功能即可启动它们。

您可以打印表格内容，或按Ctrl-C复制它，然后例如将其粘贴到电子表格中。

English Original

Table view

To display the tables, select the Show function in the context menu in tree view. The contents of the tables are defined when the system is set up. Although the values displayed in black cannot be changed, you can edit numbers or texts shown in red. A special table for user interfaces has fields with a gray background. Start these functions by double-clicking on them with the left-hand mouse button.

You can print the contents of the table, or press Ctrl-C to copy it and then, for example, paste it into a spreadsheet.
