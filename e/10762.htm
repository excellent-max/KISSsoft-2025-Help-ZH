中文翻译

系统助手

创建齿轮单元时，可在 KISSsys 中选择 插入 -> 助手，以显示用于创建模型的助手。该助手会在创建模型时逐步引导用户完成各步骤。其使用方式与元素框相同。

使用 平行轴 助手，可在 KISSsys 中创建以下齿轮单元组合：

  • 圆柱齿轮
  • 锥齿轮
  • 蜗轮
  • 端面齿轮

使用 行星齿轮级 助手创建单级行星齿轮单元。

English Original

System Assistant

When you create gear units, you can select Insert -> Assistant in KISSsys, to display an Assistant for creating the model. This Assistant leads you through the model step by step when you are creating it. You use it in the same way as the Elements Box.

Using the Parallel Shafts Assistant, you can create the following gear unit combinations in KISSsys:

  • Cylindrical gear
  • Bevel gear
  • Worm wheel
  • Face gear

Use the Planetary Gear Stage Assistant to create a single stage planetary gear unit.
