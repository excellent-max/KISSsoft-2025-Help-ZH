条件

条件

在 条件 选项卡中定义适用于每个解的一般条件。

选择 考虑载荷频谱 选项，以考虑强度计算模块中先前定义的载荷频谱。

如果启用了 排除接触分析，仅按 ISO 6336-1 附录 E 使用 KHβ 进行使用寿命计算 选项，则求解范围仅使用使用寿命和 KHβ 计算来执行。

选择 交叉变化值，因子1，因子2 选项，以运行带修改值的系数的额外变化。

选择 计算解决方案无需修改 选项，可跳过不含任何修改的方案的计算。

选择 计算每个部分载荷的轴变形一次（仅使用基本修正进行计算） 选项，可对每个部分载荷仅计算一次轴的弯曲图，而不是对每个修改配置都计算。此选项会使计算精度略有下降。但是，如果只需计算少量载荷情况，却有大量修改配置，选择此选项可显著加快尺寸确定过程。

每次修改都可以在更大的部分载荷范围内进行计算。可在 部分载荷范围 部分中进行必要设置。用于接触分析的扭矩范围以及端面载荷因子计算结果也在此输出。

修改

修改 选项卡是精细尺寸修改的主要选项卡。在其中可定义新的修改类型，例如修缘、修根等（完整的列表见"修改"章）。如果 同步ID 列中的值与特定行号（ID）不同，则该修改会与所选修改同步，且所有变体以相同的步数执行。在 齿轮 列中可选择要应用修改的齿轮。使用 齿面 选项可指定修改所应用的齿面。如果 活动 在 状态 列中被选中，则在尺寸设定过程中该修改将发生变化；如果 静态 已选定，则使用预定义值进行修改且不作任何更改；如果选择了 非活动，则忽略该修改，仅显示在图形窗口中。可输入每次修改的步数，设置从最小值到最大值之间的步数（从最小值开始）。可输入 值，因子1 和 值，因子2 的最小值与最大值，从而限制修改尺寸设定的输入。

Conditions

Conditions

The Conditions tab is where you define general conditions that are valid for every solution.

Select the Take load spectrum into account option to take into account the load spectrum previously defined in the strength calculation module.

If the Excluding contact analysis, only service life calculation using KHβ according to ISO 6336-1, Annex E option is enabled, the solution range is only performed using the service life and KHβ calculation.

Select the Cross-vary value, Factor 1, Factor 2 option to run an additional variation of the coefficients with the modification value.

Select the Calculate solution without modifications option to skip the calculation of the solution without any modifications.

Select the Calculate shaft deformation just once for each partial load (calculation with basic modification only) option to calculate the diagrams of bending once for the shafts, for each partial load, and not for every modification configuration. This option makes the calculation slightly less accurate. However, if you are performing calculations with just a few load cases, but a large number of modification configurations, selecting this option can significantly speed up the sizing process.

Every modification can be calculated for a larger partial load range. You can set the necessary settings in the Partial load range section. The torque range used for contact analysis and the face load factor calculation result is also output here.

Modifications

The Modifications tab is the main tab for fine sizing modifications. In it, you define new Modification types, such as tip relief, root relief, etc. for the sizing. (You will find a complete list at (see chapter Modifications)). If the Synchro ID column contains a different value than for the specific line number (ID), the modification is synchronized with the modification you have selected, and all the variants are performed with the same number of steps. In the Gear column, you select a gear to which the modification is to be applied. Use the Flank option to specify the flank on which the modification is to be applied. If active is selected in the Status column, the modification will be varied while it is being sized. If static is set, a predefined value will be used for the modification without being changed in any way. If inactive is selected, the modification will be ignored and only displayed in the Graphic window. You can enter the Number of steps per modification to set the number of steps between the minimum and maximum value, starting from the minimum value. You can enter the minimum and maximum value for the Value, Factor 1 and Value, Factor 2, limiting the inputs for the modification sizing.
