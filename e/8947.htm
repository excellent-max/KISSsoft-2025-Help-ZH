中文翻译

添加制造数据

添加制造数据菜单选项仅在零件视图中有效。向图纸添加齿轮戳记的步骤：

  1. 打开零件并选择一个齿的 切口。
  2. 选择 添加制造数据 菜单选项。

这将创建一个新的草稿文档，所选轮齿切口的齿轮戳记将插入到该文档中。

English Original

Adding manufacturing data

The Add manufacturing data menu option only works in the Part view. Procedure for adding a gear stamp to a drawing:

  1. Open the part and select a tooth's Cutout.
  2. Select the Adding manufacturing data menu option.

This creates a new draft document into which the gear stamp of the selected cutout for the gear teeth will be inserted.
