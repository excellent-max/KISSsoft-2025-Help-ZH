中文翻译

转速

轴绕其纵轴的转速 [rpm]。如果单击输入字段右侧的复选框，可以独立于其他轴更改转速。但是，如果此复选框未激活，则该值取自基本数据输入窗口中的"转速"输入字段 （参见"转速"章） 输入字段，位于基本数据输入窗口中。

English Original

Speed

Shaft speed around its longitudinal axis [rpm]. If you click the checkbox to the right of the input field, you can change the speed independently of the other shafts. However, if this checkbox is not active, the value is taken from the Speed input field (see chapter Speed) in the Basic data input window.
