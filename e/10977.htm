中文翻译

元素

设置 <element>元素名</element> 以添加元素。描述文件中的元素按其在界面中出现的顺序排列。

可用的元素类型如下：

数值输入字段

用于输入整数或浮点数值

选择列表（下拉列表）

用于选择列表项、数据库项、材料、润滑剂或载荷谱

复选框

用于选择/取消选择计算选项

标题和正文

用于界面结构化

点击帮助目录中的 kui 以显示可用元素列表。

English Original

Elements

Set the <element>element name</element> to add an element. The elements in the description file appear in the same sequence as they appear in the interface.

The following element types are available:

Value input fields

For entering whole number values or floating values

Selection lists (drop-down lists)

For selecting list entries, database entries, materials, lubricants or load spectra

Checkboxes

For selecting/deselecting calculation options

Titles and texts

For structuring the interface

Click on kui in the Help directory to display lists of available elements.
