中文翻译

润滑因子

润滑因子用于计算摩擦系数、损失、微点蚀和胶合。可通过相应的设置按钮进行设置。

如 ISO/TS 6336-22 所规定：

  • 矿物油为 1.0
  • 水溶性聚甘油为 0.6
  • 非水溶性聚甘油为 0.7
  • 聚α-烯烃为 0.8
  • 磷酸酯类为 1.3
  • 牵引流体为 1.5
English Original

Lubricant factor

The lubricant factor is needed to calculate the coefficient of friction, loss, micropitting and scuffing. It can be set using the appropriate Settings button.

As specified in ISO/TS 6336-22:

  • 1.0 for mineral oils
  • 0.6 for water-soluble polyglycols
  • 0.7 for non-water-soluble polyglycols
  • 0.8 for polyalphaolefins
  • 1.3 for phosphate esters
  • 1.5 for traction fluids
