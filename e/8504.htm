中文翻译

用法向模数代替轴向模数进行计算

蜗杆副的几何尺寸通常用轴向模数（或蜗轮的端面模数）计算。如果单击此复选框，则参考齿廓所用的所有数值都将用法向模数（刀具模数）计算。这尤其会影响齿顶圆和齿根圆。相比之下，变位量 x* mx（轴向模数时为 mx）保持不变。

齿顶圆的公式（法向模数时为 mn）如下：

da1 = dm1 + 2 mn haP
da2 = d2 + 2 mx x2 + 2 mn haP

对于齿根圆，适用以下公式：

df1 = dm1 - 2 mn hfP
df2 = d2 + 2 mx x2 - 2 mn hfP

English Original

Calculation with normal module instead of axial module

The geometry of worm gear pairs is usually calculated with the axial module (or transverse module of the worm wheel). If you click on this checkbox, all the values used for the reference profile are calculated with the normal module (tool module). This particularly affects the tip and root circle. In contrast, the profile shift x* mx (mx for an axial module) remains unchanged.

The formula for the tip circle (mn for the normal module) is then:

da1 = dm1 + 2 mn haP
da2 = d2 + 2 mx x2 + 2 mn haP

For the root circle, the following apply:

df1 = dm1 - 2 mn hfP
df2 = d2 + 2 mx x2 - 2 mn hfP
