基础数据：材料

  • 根据 DIN, BS, AISI, UNI, AFNOR, JIS, CN, 旧标签，材料编号，数据来源，注释： 供用户自定义的文本字段
  • 20°C 时的杨氏模量 E20: [N/mm2]
  • 泊松比 ν: [-]
  • 密度 ϱ: [kg/dm3]
  • 热膨胀系数 α: [10-6/K]
  • 20°C 时的剪切模量 G20: [N/mm2]
  • 处理类型： 在此列表中选择处理类型。
  • 材料类型： 在此列表中选择材料类型。
  • 硬度值： 该值仅用于信息目的，对计算影响可以忽略。
  • 硬度单位： 可在该列表中选择。
  • 芯部硬度值： 此值例如用于根据 AGMA 6101-F19/AGMA 6001-F19 进行强度计算。然而，对于其他计算，该值仅用于信息目的，对计算影响甚微。对于渗碳硬化钢，拉伸强度 Rm 的值是从 DIN EN 10084 标准中针对直径在 16 和 40 mm 之间的取值，并通过布氏硬度 HBW 的硬度转换进行计算。
  • 芯部硬度单位： 可从列表中选择。可以输入按布氏、洛氏C和维氏硬度测定的硬度值。根据输入，所需的硬度值将转换为所用的硬度单位。
  • 拉伸强度 Rm: [N/mm2] 最多可以定义 10 个不同的直径范围。
  • 屈服点 Rp: [N/mm2] 最多可以定义 10 个不同的直径范围。
  • 原始直径 d: [mm] 最多可定义 10 个不同的直径范围。
English Original

Basic data: Materials

  • Label according to DIN, BS, AISI, UNI, AFNOR, JIS, CN, Old label, Material number, Origin of data, Comment: Text fields for your own use
  • Young's modulus at 20°C E20: [N/mm2]
  • Poisson's ratio ν: [-]
  • Density ϱ: [kg/dm3]
  • Coefficient of thermal expansion α: [10-6/K]
  • Shearing modulus at 20°C G20: [N/mm2]
  • Type of treatment: Select the type of treatment in this list.
  • Material type: Select the material type in this list.
  • Hardness value: This value is purely for information purposes and has a negligible effect on the calculation.
  • Unit of hardness: You can select this in this list.
  • Core hardness value: This value is used, for example, for the strength calculation according to AGMA 6101-F19/AGMA 6001-F19. However, for other calculations, the value is purely for information purposes and has only a minor influence on the calculation. For case-hardened case hardening steels, the value for the tensile strength Rm was taken from the DIN EN 10084 standard for a diameter between 16 and 40 mm, and was then calculated with the hardness conversion of the Brinell hardness HBW.
  • Core hardness unit: You can select this from a list. The hardness values according to Brinell, Rockwell C and Vickers are possible as input values. Depending on the input, the required hardness values are converted into the hardness unit used.
  • Tensile strength Rm: [N/mm2] A maximum of 10 different diameter ranges can be defined.
  • Yield point Rp: [N/mm2] A maximum of 10 different diameter ranges can be defined.
  • Raw diameter d: [mm] A maximum of 10 different diameter ranges can be defined.
