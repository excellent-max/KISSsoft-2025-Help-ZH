齿轮体

在 齿轮体 选项卡中（您通过点击 计算菜单将其打开），您可以输入用于定义齿轮体的值，这会影响按照 ISO 6336 附录 E 规定的强度计算、接触分析和线载荷计算。为此，首先点击 齿轮轮缘定义 选项来定义齿轮体拓扑。这对应于下图所示的图纸之一。

图 15.92：不同的齿轮体拓扑（上：外齿轮，下：内齿轮）

情况（A）与情况（B）不同，因为它在齿轮体和轮齿之间有一个齿轮轮缘。齿圈和齿轮体可以采用不同的材料。

根据所选拓扑的不同，还有许多额外的输入选项可用：

  • 内径 di
  • 齿轮轮缘内径 dbi
  • 轮缘厚度系数 SR*
  • 轴直径 ds
  • 腹板厚度系数 bs/b*
  • 腹板厚度 bs

内径是计算质量转动惯量所必需的。对于情况（B），它可以通过 di 的输入或轮缘厚度系数 SR* 来定义。对于情况（C），内径与轴直径相同。

齿轮轮缘的内径对于情况（A）是必需的。这可以通过直接输入 dbi 或使用轮缘厚度系数 SR* 来定义。

按照 ISO 或 AGMA 的定义，齿轮轮缘厚度 SR 确实会影响强度。如果已输入齿轮轮缘直径 dbi，则有效齿轮轮缘厚度 SR 由 (df - dbi)/2 确定。齿轮轮缘厚度 SR 将在报告中输出。当使用薄齿轮轮缘时，此系数会极大地影响安全系数的计算。对于薄齿轮轮缘，此值也可以按照 VDI 2737 计算（参见"考虑齿轮轮缘影响（VDI 2737）的齿根安全系数"章）。

腹板厚度系数：如果内径 < > 0，则将输入腹板厚度（bs 或 bs/b）的值纳入考虑。如果设置 bs/b = 1.0，则表示不存在腹板。在这种情况下，齿轮体系数 CR 为 1.0。比值 b/bs 可在 0.2 和 1.2 之间变化。此时，CR 小于 1（如果 b/bs < 1）或大于 1（如果 b/bs > 1）。然后使用系数 CR 计算轮齿接触刚度（cγα）。

如果选择“不考虑”刚度模型选项，则齿轮体对 ISO 6336 附录 E 中定义的接触分析和线载荷计算没有影响。相比之下，齿轮体始终在强度计算中被考虑。

Gear body

In the Gear body tab, which you open by clicking on the Calculation menu, you can input values for defining a gear body, which has influence on the strength calculation, the contact analysis and the line load calculation as specified in ISO 6336 Annex E. To achieve this, first click the Gear rim definition option to define the gear body topology. This corresponds to one of the drawings displayed in the figure below.

Figure 15.92: Different gear body topologies (top: external gears, bottom: internal gears)

Case (A) is different from case (B) because it has a gear rim between the gear body and the toothing. The tooth rim and the gear body may have different materials.

A number of additional input options, which vary according to the selected topology, are available:

  • Inside diameter di
  • Inside diameter of gear rim dbi
  • Rim thickness coefficient SR*
  • Shaft diameter ds
  • Web thickness factor bs/b*
  • Web thickness bs

The inner diameter is needed to calculate the mass moment of inertia. For case (B), it can be defined either by the input for di or the rim thickness coefficient SR*. For case (C), the inner diameter is the same as the shaft diameter.

The inner diameter of the gear rim is needed for case (A). This can be defined either by inputting dbi directly or by using the rim thickness coefficient SR*.

As defined in ISO or AGMA, the gear rim thickness SR does affect the strength. If a diameter has been entered for gear rim dbi, the effective gear rim thickness SR is determined from (df - dbi)/2. The gear rim thickness SR will be output in the report. Where thin gear rims are used, this factor can greatly influence the calculation of safety factors. For thin gear rims, this value can also be calculated in accordance with VDI 2737 ((see chapter Safety factor root with gear rim influence (VDI 2737)).

Web thickness factor: If the inside diameter is < > 0, the value input for the web thickness (bs or bs/b) is taken into account. If bs/b = 1.0 is set, this means no web is present. In this case, the gear body coefficient CR is 1.0. The ratio b/bs can vary between 0.2 and 1.2. In this case, CR is then < 1 (if b/bs < 1) or > 1 (if b/bs > 1). The coefficient CR is then used to calculate the tooth contact stiffness (cγα).

If the “Do not consider” stiffness model option is selected, the gear body has no influence on the contact analysis and line load calculation as defined in ISO 6336, Annex E. In contrast, the gear body is always considered in the strength calculation.
