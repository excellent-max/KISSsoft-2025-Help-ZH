中文翻译

用于确定疲劳强度的系数

以下系数用于计算修正后的疲劳强度 σf：

表面粗糙度系数 ka

你可以为列表中的每个个体单元设置表面粗糙度。系数 ka 则根据图4中所示的方法，从列表条目中确定，AGMA 6101-F09。

尺寸系数 kb

尺寸系数 kb 是根据轴径，采用图5所示的方法确定的，AGMA 6101-F09。

可靠性系数 kc

在 强度 选项卡中定义可靠性（默认值 0.99%）。该值用于确定可靠性系数 kc，采用图 6 所示方法（AGMA 6101）。

温度系数 kd

该系数 kd =1 是在温度范围 -30°C 到 120°C 之间时设置的。如果轴温度超出此范围，可以修改轴的条目。

寿命系数 ke

此系数是基于应力 σe 和 σu 以及载荷循环次数 NL 确定的。

表面处理系数 kf

对于键槽，此系数直接取自 AGMA 6101-F09 中的表2。

对于直边花键或普通花键，假定 Kt 系数为 2.0。

如果存在键和过盈配合的组合，标准规定 kf 系数为 0.33 至 0.4。我们建议输入值 0.33。

环形沟槽的缺口效应类型用于V形缺口和螺纹。其具有固定的 h/r = 20 比例。

系统从肩部、环形沟槽和横孔的图示中取用各自的 Kt 系数（图8至图10，AGMA 6101-F09），并将其与系数 q（图7，AGMA 6101-F09）一起用于计算系数 kf。

其他影响系数 kg

此系数可用于考虑例如热处理、残余应力（喷丸、冷轧等）、腐蚀和表面涂层等因素。

此系数的默认值设置为 kg = 1，但可用为轴输入的值覆盖。

English Original

Coefficients used to determine fatigue strength

The following coefficients are required to calculate the modified fatigue strength σf:

Surface finish coefficient ka

You can set the surface finish for each individual element in a list. Coefficient ka is then determined from the list entry, using the method shown in Figure 4, AGMA 6101-F09.

Size factor kb

The size factor kb is determined on the basis of the shaft diameter, using the method shown in Figure 5, AGMA 6101-F09.

Reliability coefficient kc

The Strength tab is where you define the reliability (default 0.99%). This value is used to determine reliability coefficient kc, using the method shown in Figure 6, AGMA 6101.

Temperature coefficient kd

The coefficient kd =1 is set for temperatures between -30°C and 120°C. The entries for the shaft can be modified if the shaft temperature lies outside this range.

Life factor ke

This coefficient is determined on the basis of stresses σe and σu and the number of load cycles NL.

Surface processing coefficient kf

For key ways, this coefficient is taken directly from Table 2 in AGMA 6101-F09.

For straight-side or normal splines, a Kt coefficient of 2.0 is assumed.

If a combination of a key and an interference fit is present, a kf coefficient of 0.33 to 0.4 is specified in the standard. We recommend to enter the value 0.33.

The notch effect type of the circumferential groove is used for V-notches and threads. It has a fixed ratio of h/r = 20.

The system takes an individual Kt coefficient from the diagrams for the shoulder, circumferential groove and cross hole (Figures 8 to 10, AGMA 6101-F09) and uses them, together with coefficient q (Figure 7, AGMA 6101-F09) to calculate coefficient kf.

Miscellaneous effects coefficient kg

This coefficient can be used to take into account, for example, heat treatments, residual stresses (shot peening, cold rolled, etc.), corrosion, and surface coatings.

The default value set for this coefficient is kg =1, however, it can be overwritten with the values entered for the shaft.
