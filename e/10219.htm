中文翻译

集成 KISSsoft 插件

KISSsoftCOM 服务器应作为安装过程的一部分进行注册。然而，如果此步骤未完成，并且 KISSsoft 接口无法工作，必须注册该插件。

前往 KISSsoft 安装目录并选择 ProEngineer 子文件夹。在该文件夹中，双击 ProECreoRegister.bat 文件以注册接口。

如果 KISSsoftCOM 服务器成功注册，将显示一条消息确认这一点。

要注销注册，请双击 ProEUnRegister.bat 文件（位于 KISSsoft 安装目录中）。然后显示一条消息确认注销成功。

使用下面介绍的 3 种方法之一，确保每次启动 Creo Parametric 时 KISSsoft 菜单都存在。针对全部 3 种变体，在 'config.pro' 文件（Creo 中）中添加此行：

open_protk_unsigned_apps 始终

变体 1：

将 Protk_EditGear_Creo.dat 文件复制到 Creo \Common Files\text\ 子目录（对于 Creo，将文件复制到 ...\text\ 子目录）。
然后，将文件重命名为 Protk.dat。使用此变体，可更改 Creo 的启动目录，且 KISSsoft 菜单始终随其一起启动。
然而，如果已存在不同的 Protk.dat 文件，请将 Protk_EditGear_Creo.dat 中的行插入到 Protk.dat 文件中。

变体 2：

将 Protk_EditGear_Creo.dat 文件复制到初始 Creo 工作目录，并重命名为 Protk.dat。
在这种情况下，应将 Protk.dat 文件复制到启动目录。路径在 parametric.exe 文件的属性中显示。

变体 3：

用户必须将以下行添加到其 config.pro 文件（在 Creo 中）。换句话说，用户定义自己的路径：
protkdat C:\Program Files\KISSsoft<version>
文件 Protk_EditGear_….dat 位于 ProEngineer 安装子目录，必须重命名为 Protk.dat 才能正常工作。

Protk.dat 文件内容说明：

NAME EditGear

EXEC_PATH C:\Program Files\KISSsoft AG\KISSsoft

XXXX\ProEngineer\EditGear\bin_nt\EditGear...

TEXT_PATH C:\Program Files\KISSsoft AG\KISSsoft

XXXX\ProEngineer\EditGear\text.GB

STARTUP DLL

ALLOW_STOP TRUE

UNICODE_ENCODING FALSE

END

EXEC_PATH 和 TEXT_PATH 必须是安装目录的绝对路径。

STARTUP DLL 和 UNICODE_ENCODING FALSE 是预定义的（不要更改）。

使用 ALLOW_STOP TRUE 停止 Creo Parametric 程序（Tools > 辅助应用 > 停止）。

可以在 Protk.dat 文件中删除此行，以防止用户停止接口。

NAME EditGear 和 END 必须存在，尽管可以更改 EditGear 的名称（如需）。

English Original

Integrating the KISSsoft Add-in

The KISSsoftCOM server should be registered as part of the installation process. However, if this didn't happen, and the KISSsoft interface doesn't work, you must register the Add-in.

Go to the KISSsoft installation directory and select the ProEngineer subfolder. In it, double-click on the ProECreoRegister.bat file to register the interface.

If the KISSsoftCOM server is registered successfully, a message is displayed to confirm that this is the case.

To delete the registration, double-click on the ProEUnRegister.bat file in the KISSsoft installation directory. A message is then displayed to confirm that deregistration was successful.

Use one of the 3 methods described below to ensure the KISSsoft menu is present every time you start Creo Parametric. Add this line for all 3 variants, in the 'config.pro' file (in Creo):

open_protk_unsigned_apps always

Variant 1:

Copy the Protk_EditGear_Creo.dat file to the Creo \Common Files\text\ subdirectory (for Creo, copy the file to the ...\text\ subdirectory).
Then, rename the file to Protk.dat. Using this variant, the user can change their Creo start directory, and the KISSsoft menu always starts along with it.
However, if a different Protk.dat file is already present, insert the lines from Protk_EditGear_Creo.dat into the Protk.dat file.

Variant 2:

Copy the Protk_EditGear_Creo.dat file into the initial Creo working directory and rename it Protk.dat.
In this case, the Protk.dat file is to be copied into the start directory. The path is displayed in the properties of the parametric.exe file.

Variant 3:

The user must add the following lines to their config.pro file (in Creo). In other words, the user defines their own path:
protkdat C:\Program Files\KISSsoft<version>
The Protk_EditGear_….dat file in the ProEngineer installation subdirectory must be renamed to Protk.dat to make it work.

Description of the content of the Protk.dat file:

NAME EditGear

EXEC_PATH C:\Program Files\KISSsoft AG\KISSsoft

XXXX\ProEngineer\EditGear\bin_nt\EditGear...

TEXT_PATH C:\Program Files\KISSsoft AG\KISSsoft

XXXX\ProEngineer\EditGear\text.GB

STARTUP DLL

ALLOW_STOP TRUE

UNICODE_ENCODING FALSE

END

EXEC_PATH and TEXT_PATH must be the absolute path of the installation.

STARTUP DLL and UNICODE_ENCODING FALSE are predefined (do not change them).

Use ALLOW_STOP TRUE to stop the Creo Parametric program (Tools > Auxiliary Application > Stop).

You can delete this line in the Protk.dat file to prevent users from stopping the interface.

NAME EditGear and END must be present, although you can change the EditGear name if required.
