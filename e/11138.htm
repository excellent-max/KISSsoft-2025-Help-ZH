结果

计算完成后，用户可直接在 KISSsys 中查看坎贝尔图的 2D 图形。更详细的 2D 显示以及其他若干有用的分析结果会出现在报告中，该报告在右键单击kSoftSystem 计算并选择「显示报告」时生成。所有计算数据也将在 KISSsys 中生成的结果表中提供。还可以点击「保存图表」按钮保存 2D 图，以便在后续计算中原样使用（这样每次都会生成新曲线）。

English Original

Results

Once the calculation is finished, the user can see the 2D plot for the Campbell diagram directly in KISSsys. A more detailed 2D display, and a number of other useful analysis results, appear in the report, which is generated when you right-click on the kSoftSystem calculation and then select ShowReport. All the calculation data is also available in the results table that is generated in KISSsys. You can also click on the Save plot button to save the 2D plot, if it is to be used (unchanged) in subsequent calculations (so that a new curve is generated each time).
