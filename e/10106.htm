中文翻译

节点密度

用户可以影响用于计算梁的节点数量。如果进行线性计算，这不会对结果产生影响，除了线弯矩会分布在现有节点上之外。梁元件在线性模型中无论长度如何都提供精确解。

影响节点密度的原因，一方面是为了加快计算速度（例如在 KISSsys 中进行的系列计算），另一方面是为了确保弯曲线显示及相应报告的精度。

节点密度影响非线性梁元件的精度。因此，与线性计算相比，非线性计算中两节点之间的最大距离会减半，无论预定义的值是多少。

节点密度仅影响采用有限差分法建模的元件。采用传递矩阵法建模的元件不依赖网格（见"使用 FEM Solver"章）。

English Original

Node density

The user can influence how many nodes are used to calculate a beam. If you are performing a linear calculation, this has no effect on the result, apart from line moments which are distributed across the existing nodes. The beam elements supply the exact solution in the linear model independently of the length.

Reasons for influencing the density of nodes are, on one hand, to speed up calculations (for example, in series calculations in KISSsys) and, on the other hand, to ensure the accuracy of the display of the bending lines and the corresponding report.

The density of the nodes affects the accuracy of non-linear beam elements. For this reason, the maximum distance between two nodes for non-linear calculations, when compared with a linear calculation, is halved, no matter what value is predefined.

The node density affects only the elements that are modeled with the finite differences method. Elements that are modeled with the transfer matrix method, are not grid-dependent (see chapter Use FEM Solver).
