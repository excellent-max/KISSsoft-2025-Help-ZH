中文翻译

常规

此处定义报告的范围（见 报告的范围 一章） 并确定是否将计算中的警告包含在内。还可设置字体大小、语言以及保存报告时使用的标准格式。

报告可以在两种不同的模式下查看："覆盖" 或 "对比"。

如果生成报告且之前的报告仍处于打开状态，数据将被更新。编辑器中的光标将保持在之前所在行。此功能将帮助您使用不同输入分析特定值。

在报告设置中，若需同时比较两个或更多报告，将报告模式更改为“对比”。此模式仅在使用 KISSedit 作为编辑器时可用。您还可以同步报告并同时滚动查看所有报告。

用户也可以直接在 KISS.ini 文件中设置这些报告设置。

English Original

General

Here you define the scope of the report (see chapter Scope of a report) and whether warnings from the calculation are to be included in it. You can also set the font size, language and the standard format used to save reports.

The report can be viewed in two different modes: "overwrite" or "compare".

If a report is generated, and a previous report is still open, the data will be updated. The cursor in the editor will remain in the same line it was in before this. This feature will help you analyze specific values using different inputs.

In the report settings, change the report mode to "compare" if you need to compare two or more reports at a time. This mode can only by set if you are using KISSedit as the editor. You can also synchronize the reports and scroll through them all at the same time.

You can also set these report settings directly in the KISS.ini file.
