表 62.2：预定义的数学函数

变量的表达式可以包含指定的运算和任意函数调用。如果要使用受限表达式，表达式必须以 # 开头，并且必须用 RETURN 返回结果：

#
IF a>b THEN
RETURN a;
ELSE
RETURN b;
ENDIF
