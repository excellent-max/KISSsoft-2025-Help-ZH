中文翻译

允许根据 DIN 3990/ISO 6336 进行简化计算

如果选择此选项，您可以使用钢齿轮的计算方法来计算塑料齿轮。该计算根据材料数据库中列出的无限寿命强度值进行。该数据库中给出的塑料值适用于油润滑、70°C 温度和 108 次载荷循环。与根据 VDI 2545 或 VDI 2736 的计算不同，强度值与温度和润滑类型无关。

该计算与整体淬硬钢的计算方式相同，采用 ISO 6336 中定义的相应 S-N 曲线（沃勒曲线）。

English Original

Allow simplified calculation according to DIN 3990/ISO 6336

If you select this option, you can use the calculation methods for steel gears to calculate plastic gears. This calculation is performed according to the infinite life strength values listed in the materials database. The values for the plastics given in this database apply for oil lubrication, a temperature of 70°C and number of load cycles 108. In contrast to the calculation according to VDI 2545 or VDI 2736, the strength values do not depend on the temperature and lubrication type.

The calculation is performed in the same way as for through hardening steel, with the appropriate S-N curve (Woehler line) as defined in ISO 6336.
