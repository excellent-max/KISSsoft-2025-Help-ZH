中文翻译

强迫响应

强迫响应分析可用于计算因不平衡质量而承受动态载荷的轴系的真实动态行为。计算行为中考虑了变形、旋转、力和扭矩。

要分析不平衡响应，请在 计算 菜单中选择 强迫响应。选择适当的选项以考虑不平衡质量。定义啮合刚度有四种可用方法（选择选项的说明见"模态分析"章）。您还可以选择系统中用于转速控制的参考边界。此外，您可以选择转速范围和计算步数。

最后，您还可以在此对话框中定义扭转、轴向和弯曲振动的材料阻尼。请注意，轴承的粘性阻尼必须在轴计算中为每个轴承单独定义。计算完成后，可以在报告或图形中访问结果。

English Original

Forced response

The forced response analysis can be used to calculate the real dynamic behavior of a shaft system that is subjected to dynamic loads because of unbalance masses. Deformations, rotation, forces and torques are taken into account in the calculated behavior.

To analyze the unbalance response, select Forced response in the Calculation menu. Select the appropriate option to take unbalance masses into account. There are four available methods for defining meshing stiffness (a description of the selection options is given (see chapter Modal analysis)). You can also select the reference boundary that is to be used for speed control in the system. In addition, you can select the speed range and the number of calculation steps.

Finally, you can also define the material damping for torsional, axial and bending vibrations in this dialog. Note that the viscous damping of bearings must be defined separately for each bearing in the shaft calculation. When the calculation is finished, the results can be accessed in the report or in graphics.
