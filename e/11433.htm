中文翻译

模态分析

此特殊计算用于计算整个轴系的固有频率和固有振型，包括轴之间齿轮连接的影响。

要开始运行此计算，请点击菜单中的 计算> 模态分析。您必须定义要计算的固有频率数量，并指定是仅包括扭转振动还是包括所有振动类型，以及是否考虑陀螺效应（不适用于扭转振动）。您还必须定义用于计算轮齿接触刚度的计算方法。对于最后这个选项，有以下选择：

  • 按 ISO 6336 Method B 定义，即此处所用的轮齿接触刚度与该标准中的描述一致。
  • 使用接触分析算法（针对每个齿轮副），即在齿轮连接中进行完整的接触分析。如果 KISSsoft 对特定齿轮副类型没有接触分析计算，或者该齿轮副不传递功率，则该特定齿轮副使用 ISO 6336 方法。
  • 无限：假设轮齿接触刚度为无限。选择此选项以检查极限条件。
  • 忽略：假设轮齿接触刚度为零，因此振动轴之间没有连接（每个轴独立振动）。

计算完成后，可以在报告或图形中查看结果。

请注意，当对行星系统进行模态分析时，计算没有考虑旋转行星的位置对系统弯曲刚度的影响。这与固有频率分析中通常采用的准静态计算过程类似。

English Original

Modal analysis

This special calculation has been designed to calculate the eigenfrequencies and eigenmodes of a complete shaft system, including the effect of gear connections between shafts.

To start running this calculation, click on Calculation> Modal analysis in the menu. You must define the number of eigenfrequencies to be calculated, and specify whether only torsional or all vibration types are to be included, and whether gyroscopic effects are to be taken into account (does not apply to torsional vibrations). You must also define which calculation method is to be used to calculate tooth contact stiffness. The following selections are available for this last option:

  • As defined in ISO 6336 Method B, if the tooth contact stiffness used here matches the description in this standard.
  • Using the contact analysis algorithm (for each gear pair), where a full contact analysis is performed in the gear connections. If KISSsoft does not have a contact analysis calculation for a particular gear pair type, or if the gear pair does not transfer power, the ISO 6336 process is used for that specific pair.
  • Infinite: the tooth contact stiffness is assumed to be infinite. Select this option if you want to check limiting conditions.
  • Ignore: the tooth contact stiffness is assumed to be zero and there is therefore no connection between the vibrating shafts (each shaft is vibrating independently).

When the calculation is finished, the results can be accessed in the report or in the graphics.

Note that, when you perform a modal analysis for a planetary system, the calculation does not take into account the effect of the positions of the rotating planets on the system's bending stiffness. This is similar to the quasi-static calculation procedure usually followed in eigenfrequencies analysis.
