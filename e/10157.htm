中文翻译

在数据库中输入齿轮计算材料

在比较某公司用于齿轮齿的材料时，发现KISSsoft 提供的数据库中并不包含所有所需的材料。

特别地，以下用于齿轮计算的关键值缺失：σFlim/Sat, σHlim/Sac, RzF, RzH 和 BM.

当用户重新定义材料及其属性时，必须将其与我们材料数据库中的类似材料进行比较。

首先，在数据库中定义材料的基本数据。然后，定义该基础材料的齿轮特定数据。

然后，根据硬度值计算 σFlim/Sat、σHlim/Sac 的值，如 ISO 6336-5 所述。

为此，可使用相关的材料简图、输入自定义材料的转换函数（参见 材料）或 ISO 中的公式。Sat、Sac 值是基于 σFlim、σHlim 转换的。

如果没有输入热接触系数 BM 的值，则使用默认值。

对于总高度，使用 RzF 10µm 和 RzH 3µm 作为平均值。可在 ISO 6336-2 中找到更多详细信息。

ISO 6336 第 2 部分提供了更多关于当引入附加材料硬化系数 Zw 时，总高度对齿面承载能力计算影响的信息。

English Original

Inputting materials for gear calculations in the database

When comparing the materials used for gear teeth in a particular company, it became evident that not all the required materials were present in the database provided by KISSsoft.

In particular, the following key values, necessary for gear calculation, are missing: include σFlim/Sat, σHlim/Sac, RzF, RzH and BM.

When you redefine materials and their properties, you must compare them with similar materials in our materials database.

First of all, define the basic data for a material in the database. Then, define the gear-specific data for this base material.

Then, calculate the values of σFlim/Sat, σHlim/Sac depending on the hardness values, as described in ISO 6336-5.

To do this, you can either use the relevant material diagram, the conversion function for inputting your own materials (see chapter Materials) or formulae from ISO. The Sat, Sac values are converted on the basis of σFlim, σHlim.

A default value is used if no value is input for the thermal contact coefficient BM.

For total heights, specify average values with RzF 10µm and RzH 3µm. You will find more detailed information about this in ISO 6336-2.

ISO 6336, Part 2 provides more information about the influence of the total height on the calculation of flank load capacity when an additional material hardening factor, Zw, has been introduced.
