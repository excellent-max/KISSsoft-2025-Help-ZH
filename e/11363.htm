中文翻译

强力刮削

如果您需要检查强力刮削是否可用作齿轮的最终加工工序，请选择此选项。单击"加号"按钮可打开一个窗口，您可以在其中输入具体的附加细节。

使用这些检查可粗略估计刀具和机床的限制，并可选择性地显示刀具与工件之间可能发生的碰撞。您可以使用这些测试进行初步评估，但这不能被视为替代与刀具制造商共同进行的最终分析。

刀具选择

所有检查条目都在强力刮削检查对话框中定义。最大和最小可能的刮齿刀直径是选择合适刀具的关键值。这些值已针对特定机床存储，也可以手动输入。

刀具的默认齿数设置为20。单击"尺寸计算"按钮可计算一个考虑了所有当前激活测试的合适齿数。

刀具与工件啮合

单击刀具与工件啮合可参考螺旋角定义刀具/工件配对。您可以输入该值，既可以是轴交角，也可以是刀具的螺旋角。

然后系统使用这些值来检查强力刮削对于该特定刀具/工件组合的齿形几何是否实际可行。

碰撞检查

系统还可以检查工件与刀具之间可能发生碰撞的配置。为此，请在碰撞检查中选择相应的场景。在每种情况下，输入与轮齿之间的相关距离（"槽宽"）以及相关直径（"槽直径"）。

刀具制造的结果与文档

结果列在报告中。从供应商处采购刀具的公司可以使用"询价"按钮生成一份特殊文档，其中包含获取强力刮削刀具报价所需的所有细节。

精细尺寸计算

强力刮削检查功能也可作为精细尺寸计算过程的一部分使用。一旦设置好条件，检查便会自动执行。在包含精细尺寸计算结果的选项卡中，用户可以右键单击"显示列"功能来激活它并显示"PSKx"列。

与Gleason强力刮削程序的接口

如果使用Gleason机床进行强力刮削加工，我们建议您使用Gleason的强力刮削软件来更准确地监控制造过程。为此，请选择为Gleason自有程序生成输入数据 复选框。每次执行计算时，这会自动生成相应的" GleasonPowerSkivingInput-?.cuc"文件。

English Original

Power skiving

Select this option if you need to check whether power skiving can be used as the final machining process on a gear. Click the Plus button to open a window in which you can enter specific additional details.

Use the checks to generate a rough estimate of the limitations of the tool and the machine and also, optionally, to show possible collisions between the tool and the workpiece. You can use the tests to perform an initial evaluation, but this cannot be regarded as a replacement for a final analysis performed together with the tool manufacturer.

Tool selection

The Check for Power skiving dialog is where all the entries for the checks are defined. The maximum and minimum possible skiving wheel diameters are the key values for selecting the appropriate tool. These values are already stored for specific machines, and can also be entered manually.

The default number of teeth on the tool is set to 20. Click on the Sizing button to calculate a suitable number of teeth which takes into account all the currently active tests.

Meshing tool with work piece

Click on Meshing tool with work piece to define a tool/workpiece pairing with reference to the helix angle. You can enter this value either as the axial crossing angle or as the helix angle of the tool.

The system then uses these values to check whether power skiving is actually possible for the tooth geometry of this particular tool/workpiece combination.

Collision check

The system can also check the configuration for possible collisions between the workpiece and the tool. To do this, select the corresponding scenarios in Collision check. In each case, enter the relevant distance to the gear teeth, the "Groove width", and the relevant diameter, the "Groove diameter".

Results and documents for tool manufacture

The results are listed in the report. Companies that purchase tools from suppliers can use the "Offer" button to generate a special document that contains all the details needed for obtaining an offer for a power skiving tool.

Fine sizing

The Check for Power skiving function is also available as part of the fine sizing process. The check is performed automatically once the conditions have been set. In the tab that contains the fine sizing results, the user can right-click on the "Display columns" function to activate it and display the "PSKx" columns.

Interface to the Gleason power skiving program

We recommend you use Gleason's power skiving software to monitor the manufacturing process more accurately, if Gleason machines are used for the power skiving process. To do this, select the Generate input data for Gleason's in-house program checkbox. This automatically generates the appropriate " GleasonPowerSkivingInput-?.cuc" file every time a calculation is performed.
