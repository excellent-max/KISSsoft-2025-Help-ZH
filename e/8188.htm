中文翻译

外轮廓上的缺口

对于“小”内径，由于按实心轴计算缺口效应值而产生的误差相对较小。然后，您可以将结果用作近似值。但是，当涉及“大”内径时，您必须修正缺口效应值。

根据 FKM 准则 2020 第 7 版，对于带有纵向孔的圆轴，您不能使用实心圆轴的缺口效应系数来准确计算弯曲和拉伸/压缩的缺口效应值。对于扭转以及带有环向缺口、轴肩或锥体的圆轴，应使用实心圆轴的缺口效应系数。对于带有纵向孔的圆轴，应使用名义应力值。

English Original

Notches on the outer contour

For "small" internal diameters, the error due to calculating notch effect values for solid shafts is relatively small. You can then use the results as approximations. However, when "large" internal diameters are involved, you must correct the notch effect values.

According to the FKM Guideline 2020, 7th Edition, you cannot accurately calculate the notch effect values for a round shaft that has a longitudinal bore for bending and tension/compression using the notch effect coefficients for a round solid shaft. You should use the notch effect coefficient for a round solid shaft for torsion and round shafts that have a circumferential notch, shoulder or cone. Use the nominal stress value for a round shaft that has a longitudinal bore.
