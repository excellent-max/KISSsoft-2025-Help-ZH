至 Autodesk Inventor 的 3D 接口

制造商：KISSsoft AG

Inventor 与 KISSsoft 之间的接口通过在 3D CAD 系统中的直接集成创建。使用此接口可运行所有 KISSsoft 计算模块，从 Inventor 内部即可调用。在 KISSsoft 中计算的圆柱齿轮或锥齿轮可直接在 Inventor 中生成带有真实齿形的 3D 零件（见"3D 齿轮的生成"章）。用 KISSsoft 计算的轴可生成由圆柱和圆锥元素组成的 3D 零件（见"生成 3D 轴"章），并且这些 3D 零件可直接在 Inventor 中生成。在 KISSsoft 中，您可以单击按钮一键启动 Inventor。系统会打开一个新零件并生成相应的零件。您可以创建直齿或斜齿的外啮合或内啮合圆柱齿轮、直齿或斜齿齿条、直齿锥齿轮（如 DIN 3971 图 1 中所定义）以及轴。
您还可以向现有轴添加轮齿（见"存在现有轴数据时的轮齿"章）。此外，通过该接口，2D 范围内的齿轮制造数据（见"添加制造数据"章）可以表格形式自动插入到图纸中。齿轮制造数据附加到相应的切槽（齿槽）上。

3D interface to Autodesk Inventor

Manufacturer: KISSsoft AG

The interface between Inventor and KISSsoft is created by direct integration in the 3D CAD system. Use this to run all KISSsoft calculation modules from within Inventor. Cylindrical or bevel gears calculated in KISSsoft can be generated directly in Inventor as a 3D part (see chapter Generation of 3D gears) with a real tooth form. Shafts calculated with KISSsoft can be generated as a 3D part comprising cylinder and cone elements (see chapter Generating 3D shafts) directly in Inventor. From within KISSsoft, you can start Inventor with one click on a button. The system opens a new part, and generates the appropriate part. You can create cylindrical gears with straight or helical teeth, which are outside or inside, racks with straight or helical teeth, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1, and shafts.
You can also add gear teeth to existing shafts (see chapter Gear teeth if existing shaft data is present). In addition, gear manufacturing data in the 2D range (see chapter Adding manufacturing data) can automatically be inserted on the drawing as a table, with the interface. The gear manufacturing data is attached to the relevant cutout (tooth space).
