中文翻译

基本尺寸

毛坯尺寸 输入字段对强度计算起决定性作用。但是，如果在 热处理状态 下拉列表中选择 预加工至实际直径 选项，则在 强度 输入窗口中，毛坯尺寸值的设置对计算没有影响。相反，如果选择设置为 毛坯直径，则会选择取整后的最大轴直径，并使用该值进行强度计算。点击输入字段右侧的复选框，以指定车削前毛坯的自定义直径。

English Original

Base size

The Raw dimension input field is decisive for strength calculation. However, if you select the Pre-machined to actual diameter option in the State during heat treatment drop-down list, in the Strength input window, the setting for the raw measure value has no effect on the calculation. In contrast, if the selection is set to Raw diameter, the largest rounded shaft diameter is selected, and the strength calculation is performed with this value. Click the checkbox to the right of the input field to specify your own diameter for the blank before it is turned.
