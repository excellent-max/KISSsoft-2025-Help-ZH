中文翻译

功率、扭矩和转速

单击功率输入字段（用于扭矩）旁的尺寸计算按钮，计算功率（扭矩），从而可保持预定义的最小安全系数（见"安全系数"章）。

功率、扭矩和转速必须始终定义为正值。输入工作齿面以预设旋转方向。

对于行星齿轮级，转速输入字段旁的加号按钮现在变为可见。然后您可以输入第二个转速值（除参考齿轮的转速之外）。您可以输入正值或负值的转速。正值表示第二个齿轮与所选参考齿轮同向旋转。负值表示反向旋转。

注意：

当您在 KISSsys 中使用齿轮副对行星齿轮进行建模时，加号按钮对齿轮副同样有效，这与调用 KISSsys 时一样。然后您可以输入行星架转速 [nSteg]。参考齿轮的主转速 [n]（n - nweb）随后用于计算。这样可得到精确的载荷循环次数。
如果定义了带值的载荷谱，则不能更改参考齿轮、扭矩、转速或功率。

English Original

Power, torque and speed

Click the Sizing button next to the power input field (for the torque) to calculate the power (torque) so that a predefined minimum safety (see chapter Safety factors) can be maintained.

Power, torque and speed must always be defined with a positive value. Enter the working flank to predefine the sense of rotation.

The Plus button next to the speed input field now becomes visible for planetary stages. You can then input a second speed value (in addition to the speed of the reference gear). You can enter the speed as either a positive or negative value. A positive value means that the second gear rotates in the same direction as the selected reference gear. A negative value means it rotates in the opposite direction.

Note:

The Plus button is also active for gear pairs when you are modeling epicyclic gears with gear pairs in KISSsys, as it is when you call KISSsys. You can then enter the speed of the planet carrier [nSteg]. The main speed [n] of the reference gear with n - nweb is then used in the calculation. This returns the exact number of load cycles.
You cannot change the reference gear, torque, speed or power if the load spectrum with values is defined.
