中文翻译

尺寸计算

输入扭转力矩和旋转角度，然后点击尺寸计算按钮，以计算 线径、杆长 和扭转弹簧刚度，据此您可以确定杆径 d 或杆长 ls。在这种情况下，首先使用允许的剪切应力值来计算 d，然后使用杆径来计算杆长 ls。为了能够确定尺寸，会假设各种值。（矩形、带齿：df = 1.35·d；六角形：df = 1.3·d；da = df + df/7；Rh = (da-d)·1.2）。这些值不会传递到主界面。

English Original

Sizing

Enter the torsional moment and angle of rotation and then click the Sizing button to calculate the Wire diameter, the Shank length and the torsional spring rate, from which you can size the bar diameter d or the shank length ls. In this case, the permitted shear stress value is firstly used to calculate d and then the bar diameter is used to calculate the shank length ls. Various values are assumed so that you can size the dimensions. (rectangular, toothed: df = 1.35·d; hexagonal: df = 1.3·d; da = df + df/7; Rh = (da-d)·1.2). These values are not transferred to the main screen.
