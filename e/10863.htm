中文翻译

离散化模型

已生成一个离散化的齿部模型，以便将 Weber/Banaschek 开发的齿轮副啮合变形理论应用于具有斜齿的三维圆柱齿轮。为此，轮齿沿宽度方向分布在 N 个切片中，并根据在计算设置中选择的刚度模型类型进行耦合。

如果选择的刚度模型是 影响数，则所有邻近切片都对每个切片的总变形有贡献，其中较近的切片对所考虑的切片影响更大。如果选择 刚度耦合，则切片通过扭转刚度 Cc 耦合到相邻切片，并且每个齿轮在每个切片中都有各自的刚度。如果选择 刚度耦合（组合刚度），则采用相同的模型，但每个齿轮没有单独的刚度，而是使用每个齿轮的组合刚度。此外，对于组合刚度选项，由轴向偏移或齿宽不等引起的悬臂切片不予考虑。

C_{c}=0.04N^{2}{{C_{R+B,i}+C_{R+B,i+1}} \over 2}

0.04：通过与 FEM 的对比计算确认的经验系数。用户可在计算设置中修改该因子（耦合刚度修正因子）。此选项仅当刚度模型未选择影响数时有效。下图显示了刚度耦合选项的刚度耦合连接。

English Original

Discretized model

A discretized toothing model has been generated so that the deformation theory of meshing in gear pairs developed by Weber/Banaschek can be applied to three dimensional cylindrical gears with helical gear teeth. To achieve this, the teeth are distributed in N slices across the width and are coupled together depending on what type of stiffness model is chosen in the Calculation Settings.

If the stiffness model chosen is Influence numbers, then all nearby slices contribute to the total deformation of each slice, with closer slices having more influence on the considered slice. If Stiffness coupling is chosen, then the slices are coupled to adjacent slices by a torsional stiffness Cc and each gear has a separate stiffness for each slice. If Stiffness coupling (combined stiffness) is chosen, then the same model is chosen but each gear does not have a separate stiffness and instead uses a combined stiffness from each gear. In addition, for the combined stiffness option, overhung slices due to axial offsets or unequal facewidths are not considered.

0.04: Empirical coefficient confirmed by comparative calculations with FEM. The user can change this factor (coupling stiffness modification factor) in the Calculation settings.
