中文翻译

帮助文本查看器

KISSsoft 手册以 HTML 格式显示在帮助文本查看器中。要打开手册，请在目录或搜索功能中选择某项。如果按功能键 F1，系统将显示关于光标当前在 KISSsoft 中所处位置的更多信息。

English Original

Helptext Viewer

The KISSsoft manual is displayed in the Helptext viewer in HTML format. To open the manual, select something in the Table of Contents or the Search function. If you press function key F1, the system displays more information about where the cursor is currently located in KISSsoft.
