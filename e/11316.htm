中文翻译

生成 GDE 格式（VDI 2610）并为齿廓图、齿向线图和齿形生成详细数据

单击生成 GDE 格式（VDI 2610）和为齿廓图、齿向线图和齿形生成详细数据，计算用于生成齿廓图和齿向线图的各个点。此选项还会计算特定齿形的点。单击报告 > 特殊报告 > 齿廓图、齿向线图和齿形的详细数据以显示记录这些图上的点和齿形点的报告。单击文件 > 导出 > GDE以生成 GDE 输出文件。这将创建一个“GEAR DATA EXCHANGE”xml 文件（GDE 格式）。

但是，如果要对多个齿轮甚至多对齿轮副进行映射，则先将齿轮 1、然后齿轮 2，接着将配对 1 的 <mating_data> 部分写入文件，随后再写入配对 2（如果存在）的相同数据，依此类推，直到所有齿轮都已添加到文件中。

KISSsoft 中提供的以下修形受 GDE 格式支持：

  • 齿顶和齿根修形，线性
  • 齿廓鼓形修整，以滚动长度为中心
  • 齿向鼓形修整
  • 扭转
  • 压力角修形（角分）
  • 螺旋角修形（角分）
  • 齿端修薄，线性

目前支持 3.1 和 3.2 版本。

English Original

Generate GDE format (VDI 2610) and generate detailed data for profile diagram, flank line diagram and tooth form

Click on Generate GDE format (VDI 2610) and Generate detailed data for profile diagram, flank line diagram and tooth form to calculate the individual points used to generate the profile diagram and the flank line diagram. This option also calculates the points for the particular tooth form. Click on Report > Special reports > Detailed data for profile, flank line diagram and tooth form to display a report documenting the points for the diagrams and the tooth form points. Click on File > Export > GDE to generate the GDE output file. This creates a "GEAR DATA EXCHANGE" xml file (in GDE format).

However, if several gears, or even several gear pairs, are to be mapped, first gear 1, then gear 2, and then the <mating_data> section, for pair 1, is written to the file, followed by the same data for pair 2 (if present), etc., until all the gears have been added to the file.

The following modifications, which are available in KISSsoft, are supported in GDE format:

  • Tip and root relief, linear
  • Profile crowning, roll length-centered
  • Flank line crowning
  • Twist
  • Pressure angle modification (arc minutes)
  • Helix angle modification (arc minutes)
  • End relief, linear

Versions 3.1 and 3.2 are currently supported.
