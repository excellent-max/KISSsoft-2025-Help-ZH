Note

Level 2, or higher, requires at least one floating element.
Level 3, or higher, requires a flexible gear rim.
In a flexible assembly, the planets must be mounted on flexible pins/shafts or on bearings with couplings.

Depending on the toothing quality and the number of planets, use the Calculated according to AGMA 6123 method to determine the distribution coefficient Kγ for application levels 1 to 3.

If a different load distribution coefficient is input for each element, when load spectra are in use, you should select the Own input, per load stage method.
