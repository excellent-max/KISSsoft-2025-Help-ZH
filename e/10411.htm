中文翻译

Parasolid 3D轴的导出

Parasolid 可用于生成轴的实体模型。可导出的数据格式有 STEP、Parasolid 文本（X_T）和二进制（X_B）。

选择 文件 > 导出 > 轴 > 3D 几何 以生成模型。如果计算模型包含多个轴，可通过选择 文件 > 导出 > 几何 3D 系统 来导出它们。

English Original

Parasolid Export of 3D Shafts

Parasolid can be used to generate the solid model of the shaft. The available data formats for export are STEP, Parasolid text (X_T) and binary (X_B).

Select File > Export > Shaft > 3D Geometry to generate the model. If the calculation model contains a number of shafts, you can export these by selecting File > Export > Geometry 3D System.
