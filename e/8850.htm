中文翻译

输入窗口中的必要输入项

在开始精细定尺寸过程之前，必须在 基本数据 或 几何 和 强度 标准选项卡中正确输入以下数据，以确保计算返回您需要的结果。

几何：

  • 参考齿廓
  • 惰轮/行星轮数量（用于配置行星齿轮级、3 齿轮和 4 齿轮）

强度：

  • 材料
  • 功率/转速
  • 工况系数
  • 使用寿命
  • 润滑
English Original

Necessary entries in the input window

Before you start the fine sizing process, you must enter the following data correctly in the Basic data or Geometry and Strength standard tabs to ensure the calculation returns the results you require.

Geometry:

  • Reference profile
  • Number of idler gears/planets (to configure planetary gear stage, 3-gear and 4-gear)

Strength:

  • Materials
  • Power/Speed
  • Application factor
  • Required service life
  • Lubrication
