中文翻译

常规

制造图纸用于在同一表面上显示多个图形，从而生成可用于制造齿轮的打印就绪图像。您也可以同时显示图纸数据报告。使用控制文件来定制显示以适应特定要求。控制文件存储在模板目录中（通常位于 KISSDIR\template）。它具有模块名称和文件扩展名.grc（例如Z012gear1.grc）。

您也可以像通常一样将此处生成的图形保存为 .dxf 文件。

English Original

General

Manufacturing drawings are designed to display a number of graphics on the same surface, and therefore create a print-ready image that can be used to manufacture a gear. You can also display the drawing data report at the same time. Use a control file to tailor the display to suit specific requirements. The control file is stored in the template directory (usually under KISSDIR\template). It has the module name and the file extension .grc (e.g. Z012gear1.grc).

You can also save the graphic generated here as a .dxf file in the usual way.
