中文翻译

检查中心距变化时的安全系数变化

是否可以检查当齿轮以不同的中心距安装时，安全系数会如何变化？

选择 计算 > 设置 > 计算设置 以激活该选项 “““使用运行中心距和制造变位系数的计算””” 在 通用 选项卡。然后可以分别输入变位系数和中心距。计算则使用工作节圆上的圆周力，而不是参考圆上的圆周力。

English Original

Check changes in safeties if the center distance changes

Is it possible to check how the safeties change when gears are mounted with a different center distance?

Select Calculation > Settings > Calculation settings to activate the option Calculation with operating center distance and manufacturing profile shift in the General tab. You can then input the profile shift coefficients and center distance independently of each other. The calculation then uses the circumferential forces in the operating pitch circle instead of the circumferential forces in the reference circle.
