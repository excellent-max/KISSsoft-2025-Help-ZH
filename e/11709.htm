中文翻译

激励谐波数

强迫响应分析基于频响法。对于激励谐波数，所有参与啮合的齿轮副都考虑相同数量的激励力频率。如果该数量超过任一齿轮副可用的最大谐波数，则激励中采用所有齿轮副中最低的最大谐波数。可设置的最大谐波数为 100。当还给出扭矩波动激励时，给定的谐波数将同时用于两种激励类型。选择合适的谐波数尤为重要，以便在要求的结果精度与分析工作量之间取得平衡。大量的激励谐波会导致动态方程数量增多，从而可能需要更长的计算时间。在进行强迫响应分析之前，建议您检查传动误差幅值、啮合刚度或扭矩波动的影响，以决定应考虑的激励阶次范围。

English Original

Number of excitation harmonics

The forced response analysis is based on the frequency response approach. In the case of the Number of excitation harmonics, the same number of excitation forces frequencies is considered for all active gear pairs. If this number exceeds the maximum number of available harmonics of any gear pair, then the lowest maximum number of harmonics among all gear pairs is considered in the excitation. The possible maximum number of harmonics which can be set is 100. When the torques ripple excitation is also given, then the given number of harmonics is considered for both excitation types. It is particularly of great importance to select a suitable number of harmonics to make a trade-off between the demanded level of the results accuracy and the analysis effort. A large number of excitation harmonics results in a higher number of dynamic equations and can consequently require more calculation time. Before performing the forced response analysis, we recommend you check the influence of transmission error amplitudes, meshing stiffness or torque ripple to decide the extent to which excitation orders should be considered.
