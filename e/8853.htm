中文翻译

限制齿顶圆直径

齿顶圆超过指定值的方案将被拒绝。如果 |da| < |dalimit|，则内齿方案将被拒绝。如果不想限制齿顶值，可以输入 0 或 1010 。

但是，以下问题妨碍了该选项在实践中的合理使用：如果齿轮要安装到现有箱体中，关键是它不能接触箱体壁。

English Original

Limiting the tip diameter

Solutions whose tip circle exceeds the specified value are rejected. Solutions for internal teeth are rejected if |da| < |dalimit|. If you do not want to limit the tip value, you can input either 0 or 1010 .

However, the following problem prevents this option being used sensibly in practice: If a gear is to be installed in an existing housing, it is critical that it does not touch the walls of the housing.
