中文翻译

报告查看器

在 KISSsoft 中生成报告时，报告查看器会在主输入区中打开，报告菜单中的条目会被激活，并显示报告查看器工具栏。报告查看器是一个文本编辑器，支持保存和打印文本文件的常用功能。在 KISSsoft 中，您可以将报告保存为可移植文档格式 (.pdf)、Microsoft Word 格式 (.doc) 或 ANSII 文本 (.txt)。

报告查看器的其他功能包括撤销/重做、复制、剪切和粘贴以及搜索，并带有常用的快捷键。您可以放大视图，并在之后通过更改字体大小、粗体、斜体和下划线样式来编辑报告。要更改报告的总体外观，请选择报告 > 设置。

English Original

Report Viewer

When you generate a report in KISSsoft, the report viewer opens in the main input area, the entries in the Report menu are activated and the report viewer tool bar is displayed. The report viewer is a text editor that supports the usual functions for saving and printing a text file. In KISSsoft, you can save reports in portable document format (.pdf), in Microsoft Word format (.doc) or as ANSII text (.txt).

The report viewer's other functions are Undo/Redo, Copy, Cut and Paste, and Search, with the usual shortcuts. You can zoom in on the view and edit the report later on by changing the font size, bold, italics and underlining style. To change the general appearance of the report, select Report > Settings.
