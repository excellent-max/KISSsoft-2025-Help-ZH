导入现有的 KISSsoft 计算

如果 KISSsoft 计算已存在于新 KISSsys 系统的元素中，您只需在 KISSsoft 窗口中加载这些文件。为此，请单击 文件 -> 打开。但是，您应注意以下几点：

  • 存储在 fileName 变量中的文件名（位于 KISSsys 计算元素中）将被更改。该名称必须删除或修改。
  • 力元素和轴承在轴计算过程中会被覆盖。因此，您需要在导入计算后调用 Dialog 或 UpdateShaftElements 函数。无法导入 KISSsys 模型树结构中不存在的力元素和轴承。此外请注意，加载的轴计算中的力元素和轴承名称必须与模型中使用的名称相同。
  • 对于齿轮，您必须确保齿轮（齿轮 1 和齿轮 2）的顺序与模型中的定义匹配。
English Original

Importing existing KISSsoft calculations

If KISSsoft calculations are already present for the elements in a new KISSsys system, you can simply load the files in the KISSsoft window. Click on File -> Open to do this. However, you should note a few points:

  • The file name stored in the fileName variable, in the KISSsys calculation element, will be changed. The name must either be deleted or modified.
  • The elements of forces and the bearings are overwritten during the shaft calculation. For this reason, you need to call the Dialog or UpdateShaftElements function after importing the calculation. You cannot import force elements and bearings that are not present in the KISSsys model tree structure. Also note that the names of the force elements and bearings in the loaded shaft calculation must be identical to the names used in the model.
  • In the case of gears, you must ensure that the sequence of the gears (gear 1 and gear 2) matches the definition in the model.
