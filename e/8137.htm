中文翻译

轴承宽度

轴承宽度的参考值，依据 Niemann 第 I 卷表 15/1 [8] 定义。
正常范围：b/d = 1 至 2

轴承宽度的参考值，依据 ISO 7902 [69] 定义。
正常范围：b/d = 0.125 至 1

轴承宽度的参考值，依据 DIN 31652 [72] 定义。
正常范围：b/d = 0.01 至 5

轴承宽度的参考值，依据 DIN 31657 [69] 定义。
正常范围：b/d <= 0.8，计算 Qp 时假定 b/d = 0.8

d：轴承直径
b：轴承宽度

English Original

Bearing width

Reference value for bearing width as defined in Niemann, Volume I, Table 15/1, [8]
Normal range: b/d = 1 to 2

Reference value for bearing width according to ISO 7902, [69]
Normal range: b/d = 0.125 to 1

Reference value for bearing width according to DIN 31652, [72]
Normal range: b/d = 0.01 to 5

Reference value for bearing width according to DIN 31657, [69]
Normal range: b/d <= 0.8, b/d = 0.8 is assumed for the calculation of Qp

d: Bearing diameter
b: Bearing width
