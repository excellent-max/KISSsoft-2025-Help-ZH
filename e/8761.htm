齿廓修形（鼓形），滚动长度居中

图（见图 15.42）显示了轮廓图中定义的（滚动长度居中）齿廓修形。图中还显示了"值"设置。齿顶和齿根处修形的起点可以在 制造 选项卡中设置。

滚动长度居中齿廓修形是指，从计算齿面长度的中部开始，在横截面中朝向齿顶圆和齿根圆方向持续且递增地去除材料。点 A 和点 E 以及值 Ca 定义了圆弧状的修形过程。Ca = Cαa = Cαf 适用于齿廓修形。偏心齿廓修形（参见"偏心齿廓修形"章）可用于齿顶和齿根处不同的修形。
滚动长度居中修形的定义与 ISO 21771 中的定义相同，并在轮廓图中产生圆弧状修形。

English Original

Profile crowning, roll length-centered

Figure (see Figure 15.42) shows the (roll length-centered) profile crowning as defined in the profile diagram. The Value setting is also shown in this figure. The start of the modification at the tip and root can be set in the Manufacturing tab.

Roll length-centered profile crowning occurs where material is removed constantly, and increasingly, in the direction of the tip and root circle, in the transverse section, starting from the middle of the calculated tooth flank length. Points A and E and the value Ca define the arc-like progression. Ca = Cαa = Cαf applies for profile crowning. Eccentric profile crowning (see chapter Profile crowning, eccentric) can be used for different crowning at the tip and root.
The Roll length-centered crowning definition is the same as the definition in ISO 21771 and produces an arc-like modification in the profile diagram.
