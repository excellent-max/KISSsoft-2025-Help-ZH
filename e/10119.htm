中文翻译

非对称（镜像对称）齿面

如果齿面（左、右）不相同，导出齿廓时是否会出错？

用于计算（尺寸）的齿面是相同的。

系统中使用的导出功能不仅导出渐开线，还导出整个齿形。这是一个近似曲线。

你可以使用导出精确度（允许偏差 ε）来定义你希望以多大的精度逼近计算所得的齿形。

在每种情况下，为齿的一半或整个齿提供具有指定精度的近似曲线。只有在使用近似精度时才能使用镜像对称。

所选偏差越小，曲线越精细。

English Original

Non-identical (mirrored symmetry) tooth flanks

If the tooth flanks (left, right) are not identical, will this cause an error when the tooth contour is exported?

The tooth flanks used in the calculation (sizing) are identical.

The export function used in the system not only exports the involute but also the entire tooth form. This is an approximated curve.

You can use the export precision (permitted deviation ε) to define how closely you want to approximate the calculated tooth form.

In each case, an approximate curve with the specified level of accuracy is supplied for either half of the tooth or the whole tooth. You can only use mirror symmetry with approximation accuracy.

The smaller the selected deviation, the more detailed the curve.
