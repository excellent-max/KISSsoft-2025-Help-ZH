中文翻译

自动

齿形计算的默认操作是自动。然后，使用在标准选项卡中输入的数据（参见"标准选项卡和特殊选项卡"章）生成齿形（包括其全部预加工和最终加工）。您定义的任何修形在生成齿形时都会被考虑。您也可以在上下文菜单中禁用这部分操作。这同样适用于您指定的任何齿顶倒角或圆角。如果您选择 ZA 作为齿面形状，将生成 ZA 蜗杆。否则将创建 ZI 蜗杆。

注意

如果自动工序已被禁用，则在参考齿廓或修形输入窗口中输入的任何数据都不会被考虑。

English Original

Automatically

The default operation for the tooth form calculation is Automatically. The tooth form (with all its pre-machining and final machining) is then generated using the data entered in the standard tabs (see chapter Standard and special tabs). Any modifications you have defined are taken into account when generating the tooth form. You can also disable this part of the operation in the context menu. The same applies to any tip chamfer or rounding you specify. If you select ZA as the flank shape, a ZA worm will be generated. Otherwise a ZI worm is created.

Note

If the Automatically operation has been disabled, none of the data input in the Reference profile or Modifications input windows will be taken into consideration.
