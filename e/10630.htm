中文翻译

图纸数据

要访问创建图纸所需的弹簧数据，请点击图纸数据。使用 F10SPRING?.RPT 文件（用于压缩弹簧）或 F20SPRING?.RPT 文件（用于拉伸弹簧）等（? = d/e/a/f/i/s/r/p/c，对应所需语言），按要求修改模板。

English Original

Drawing data

To access the spring data required to create a drawing, click Drawing data. Use the F10SPRING?.RPT file (for compression springs), or the F20SPRING?.RPT file (for tension springs), etc. (? = d/e/a/f/i/s/r/p/c for the required language) to modify the template to your own requirements.
