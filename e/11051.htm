中文翻译

仅在以下条件得到满足时才考虑解决方案：

用户还可以定义其他标准以确保不满意的解被拒绝。这些值在当量圆柱齿轮的轮齿上进行计算和检查：

1. 有效直径到成形直径的最小距离 dΝf - dFf

啮合干涉发生在有效齿根圆小于齿根成形圆时。此处可以指定有效齿根直径与齿根成形圆之间的最小距离，即有效渐开线与制造渐开线之间的距离。输入值是两个直径的最小差值。结果视图中仅考虑大于或等于输入值的解。

2. 最小端面压力角（在齿根成形圆上任一点） alphafF

对于差速锥齿轮，需要在横截面（端截面）中具有最小的齿廓角，以确保轴向脱模性。仅考虑结果视图中大于或等于输入值的解。

3. 参考齿廓中的最小牙底倒圆角半径 rhofp

出于可制造性的原因，可能需要一个最小的牙底倒圆角半径（绝对值，单位 mm）。仅将结果视图中大于或等于输入值的解纳入考虑。

4. 最小齿顶间隙 c

出于可制造性的原因，可能需要一个最小的齿顶间隙（绝对值，单位 mm）。此值与齿顶间隙 c 进行比较。仅将齿顶间隙大于或等于输入值的解显示在结果视图中。

5. 齿顶成形圆上的最小齿厚 sFvan

齿顶成形圆上的最小齿厚 sFvan 对于达到所需的齿顶倒圆半径至关重要。此计算考虑了 修改 选项卡中的齿顶修形。只有齿顶成形圆上的齿厚大于或等于输入值的解才会显示在结果视图中。齿厚 sFvan 在齿宽中部进行检查。如果您还希望在剖面 I 和 II 中检查内侧和外侧的齿厚，请在模块特定设置中选择 差速器齿轮组的补充说明。

6. 制造必须能够采用齿顶倒圆 rK

只有能够执行 修改 选项卡条目中所定义的齿顶倒圆 rK 的解，才会显示在结果视图中。

注意

如果 模块特定设置 –> 差速器齿轮组 已选定，这些标准也会在“内侧”和“外侧”剖面中进行检查。然后只有满足预定义标准的解才会被考虑。

English Original

Only take solutions into account if the following conditions are fulfilled:

The user can also define other criteria to ensure unsatisfactory solutions are rejected. These values are calculated and checked on the virtual cylindrical gear toothing:

1. Minimum distance of active diameter to form diameter dΝf - dFf

Meshing interferences occur if the active root circle is less than the root form circle. Here you can specify a minimum value for the distance between the active root diameter and the root form circle, i.e. between active and manufactured involutes. The input value is the minimum difference between the two diameters. Only solutions greater than, or equal to, the input value are taken into account in the results view.

2. Minimum transverse pressure angle at a point on root form circle alphafF

For differential bevel gears, a minimum profile angle in the transverse section is required to ensure the axial demoldability. Only solutions greater than, or equal to, the input value are taken into account in the results view.

3. Minimum root rounding radius in the reference profile rhofp

A minimum root rounding radius may be required for reasons of manufacturability (absolute value in mm). Only solutions greater than, or equal to, the input value are taken into account in the results view.

4. Minimum tip clearance c

A minimum tip clearance may be required for reasons of manufacturability (absolute value in mm). This is compared with tip clearance c. Only solutions with a tip clearance greater than, or equal to, the input value are displayed in the results view.

5. Minimum tooth thickness on tip form circle sFvan

The minimum tooth thickness on the tip form circle, sFvan, is critical for achieving the required tip rounding radius. This calculation takes into account the tip alterations from the Modifications tab. Only solutions with a tooth thickness at the tip form circle that is greater than, or equal to, the input value are displayed in the results view. The tooth thickness sFvan is checked in the middle of the facewidth. Select Additions for differential gears in the Module specific settings if you also want the tooth thickness to be checked outside and inside, in sections I and II.

6. Manufacturing must be possible with tip rounding rK

Only solutions in which the tip rounding rK as defined by the entries in the Modifications tab can be executed are displayed in the results view.

Note

If Module specific settings –> Differential gears has been selected, these criteria are also checked in an "inside" and "outside" section. Only solutions which meet the predefined criteria are then taken into account.
