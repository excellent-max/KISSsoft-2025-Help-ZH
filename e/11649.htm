中文翻译

鼓形花键（Dudley）

对于花键具有鼓形齿修形的鼓形花键轴，其表面压力可使用 Dudley 计算方法 [87] 进行校核。

此计算方法需要额外输入转数（如果对齐类型不对中，鼓形在 AGMA 计算方法中被选中）。该计算所得的值连同 AGMA 6123 的结果一起，在报告中以单独区块给出。

English Original

Crowned splines Dudley

For crowned splined shafts, where the spline has a curved tooth modification, the surface pressure can be verified using the Dudley calculation method [87].

This calculation method requires the additional input of the Number of revolutions, if the alignment type not aligned, crowned is selected in the AGMA calculation method. The values from this calculation are given in a separate block in the report, along with the results from AGMA 6123.
