条件查询或分支使您能够仅在满足特定条件时输出某些值和文本。支持以下条件：

此条件输入方式如下：

IF (condition) {Var}
情况 1
ELSE
情况 2
END;

示例

IF (%i=0) {Zst.kXmnFlag}
齿顶修形：否
ELSE
齿顶修形：是
END;

如果Zst.kXmnFlag变量为 0，则输出第一个文本；否则输出第二个文本。IF, ELSE 和 END 之间可以有任意数量的行。每个用 IF 打开的分支都必须用 END; 关闭（不要忘记 END 后面的分号）。关键字 ELSE 是可选的，它使条件反转。分支可以相互嵌套，最多嵌套 9 层。

简单分支示例

IF (%i=1) {ZP[0].Fuss.ZFFmeth}
按方法 B 计算齿形系数
END;

如果ZP[0].Fuss.ZFFmeth变量为 1，则输出该文本；否则不输出文本。

嵌套分支示例

IF (%f≤ 2.7) {z092k.vp}

常规手动润滑

（文本 1）

ELSE

IF (%f<12) {z092k.vp}

使用滴油器润滑（每分钟2至6滴）

（文本 2）

ELSE

IF (%f<34) {z092k.vp}

使用油浴润滑

（文本 3）

ELSE

使用循环系统润滑

（文本 4）

END;

END;

END;

如果z092k.vp变量小于或等于 2.7，则输出文本 1。否则，系统会提示您确认 z092k.vp 是否小于 12。如果是，则输出文本 2。否则，系统会提示您确认 z092k.vp 是否小于 34。如果是，则输出文本 3，否则输出文本 4。

Condition query IF ELSE END

The condition query or branching enables you to output certain values and texts only if a particular condition has been fulfilled. The following conditions are supported:

Combination of characters

Meaning

==

equal to
>=

greater than or equal to
<=

less than or equal to

!=

not equal to

<

less than

>

greater than

This condition is entered as follows:

IF (condition) {Var}
Case 1
ELSE
Case 2
END;

Example

IF (%i=0) {Zst.kXmnFlag}
Addendum modified no
ELSE
Addendum modified yes
END;

If the Zst.kXmnFlag variable is 0, the first text is output. If not, the second text is output. There can be any number of rows between IF, ELSE and END. For each branching opened with IF you must use END; to close it again (do not forget the semicolon after END). The key word ELSE is optional. It reverses the condition. Branchings can be nested within each other up to a depth of 9.

Example of a simple branching

IF (%i=1) {ZP[0].Fuss.ZFFmeth}
Calculation of tooth form coefficient according to method: B
END;

If the ZP[0].Fuss.ZFFmeth variable is 1, the text is output. If not, no text is output.

Example of encapsulated branchings

IF (%f≤ 2.7) {z092k.vp}

Regular manual lubrication

(Text1 )

ELSE

IF (%f<12) {z092k.vp}

Lubrication with drop dispenser (2 to 6 drops per minute)

(Text 2)

ELSE

IF (%f<34) {z092k.vp}

Lubrication with oil bath lubrication

(Text 3)

ELSE

Lubrication with circulation system lubrication

(Text4)

END;

END;

END;

If the z092k.vp variable is less or equal to 2.7, text 1 is output. Otherwise you are prompted to confirm that z092k.vp is less than 12. If yes, text 2 is output. Otherwise you are prompted to confirm that z092k.vp is less than 34. If yes, text 3 is output, otherwise text 4 is output.
