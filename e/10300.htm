English Original

Definitions in [GRAPHICS]

Variable name

Description

BACKGROUND

0: black, 15: white
CLIPDIAGRAMCURVES

0: Display complete curve progression in diagrams, 1: Limit curves in diagrams to current axis range
PERSPECTIVEPROJECTION

0: 3D graphics in parallel projection, 1: 3D graphics in perspective projection
USESETTINGS

0: Don't save graphics settings, 1: Save graphics settings for specific users
