常规

KISSsys 是 KISSsoft 计算程序的扩展。使用 KISSsoft，您可以对单个轴、齿轮或轴毂连接进行尺寸确定、优化和重新计算。相比之下，KISSsys 适用于管理机器元素系统。

KISSsoft 中已存在不同计算之间的一些特殊连接。例如，轴承力可以从轴计算中传递，齿轮可以放置在轴上。但是，对于更大的系统（例如具有多个轴和齿轮的多级变速箱），必须为每一级单独输入功率和转速数据。如果要计算多个载荷，则必须在每次计算中更新载荷。

与 KISSsoft 中单个计算占主导地位不同，KISSsys 提供了一种将系统作为整体观察的方式。KISSsys 并非旨在取代 KISSsoft。相反，它是一个扩展，使用 KISSsoft 中已有的经过验证的计算模块。从根本上说：KISSsys 管理模型中各个元素之间的关系，但将各个元素的计算留给 KISSsoft。

English Original

General

KISSsys is an extension to the KISSsoft calculation program. With KISSsoft, you can size, optimize and recalculate individual shafts, gears or shaft-hub connections. In contrast, KISSsys is suitable for administering machine element systems.

Some special links between different calculations are already present in KISSsoft. For example, bearing forces can be transferred from the shaft calculation and gears can be placed on a shaft. However, in the case of larger systems, such as a multi-stage gearbox with several shafts and gears, power and speed data must be entered separately for each stage. If several loads are to be calculated, the load must be updated in each calculation.

In contrast to KISSsoft, where the individual calculations take center stage, KISSsys provides a way of observing a system as a whole. KISSsys has not been designed to replace KISSsoft. Instead, it is an extension that uses the tried and tested calculation modules that are already present in KISSsoft. Fundamentally: KISSsys administers the relationships between individual elements in a model but leaves the calculation of the individual elements to KISSsoft.
