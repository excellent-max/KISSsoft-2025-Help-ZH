元函数 SetElementData 和 GetElementData

使用 Script 或 COM 接口时，可以通过元函数 SetElementData(elementLabel, parameterName, value) 和 GetElementData(elementLabel, parameterName) 访问和修改大多数轴单元参数。下表列出了不同类型轴单元可用的参数名称。

English Original

Meta functions SetElementData and GetElementData

When using Script or COM interface most parameters of shaft elements can be accessed and modified by using the Meta functions SetElementData(elementLabel, parameterName, value) and GetElementData(elementLabel, parameterName). In the tables that follow the parameter names available for different types of shaft elements are given.
