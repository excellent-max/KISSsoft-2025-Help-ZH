中文翻译

更改展成参数

在 Solid Edge 中，您可以在复制齿槽（阵列）的两种设置之间切换。可能的模式有：SmartPattern 和 FastPattern。SmartPattern 生成的齿形更精确。但是，这需要相当长的时间，并且会生成非常大的齿轮文件。FastPattern 是一种精度较低的方法，但耗时更短，生成的齿轮文件也更小。到目前为止，一直使用 SmartPattern 来生成齿轮，否则齿轮无法正确创建或表示。在 kiss.ini（参见 [SOLIDEDGE] 中的定义 一章） 文件（该文件位于 KISSsoft 安装目录）中，您可以设置 SMARTPATTERN=0，以便以 FastPattern 模式复制齿槽。

English Original

Changing the parameter for generation

In Solid Edge, you can toggle between two settings for copying the tooth space (pattern). The possible modes are: SmartPattern and FastPattern. SmartPattern generates a more accurate tooth form. However, this takes quite some time and creates a very large gear file. FastPattern is a less accurate method, but takes less time and generates a smaller gear file. SmartPattern has always been used to generate gears up to now, since otherwise the gears cannot be created or represented correctly. In the kiss.ini (see chapter Definitions in [SOLIDEDGE]) file in the KISSsoft installation directory, you can set SMARTPATTERN=0, to copy the tooth space in FastPattern mode.
