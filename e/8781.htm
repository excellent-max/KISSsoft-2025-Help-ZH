关于齿廓修形的说明

如果您选择短修形，则两个齿轮的齿顶（或齿根）处修形长度按如下方式定义：未因修形而改变的部分齿面的重合度仍恰好为 1.0（对于 εα > 2 的深齿啮合，则仍恰好为 2.0）。这种修形方式最常用，因为它总能保证足够大的端面重合度（无论载荷如何）。
这种短修形从啮合线上的 A 点延伸到 H-AB 点（A 点与 B 点的中点），或从 E 延伸到 H-DE。然而，其结果是未修形部分的重合度为 1.0。

如果您希望设计一台尽可能安静运行的齿轮装置，通常最好选择长修形，因为在这种情况下传动误差通常要低得多。为正确评估修形的效果，我们建议您计算承载啮合（参见"接触分析"章）。

English Original

Notes about profile modification

If you select a short profile modification, the length of the modification at the tooth tip (or at the tooth root) for both gears is defined such that the contact ratio of the part of the tooth flank that has not been changed by the modification is still exactly 1.0 (for deep toothing with εα > 2 is still exactly 2.0). This type of profile modification is the one most frequently used because it always ensures a sufficiently large transverse contact ratio (no matter what load is involved).
This short profile modification runs from point A of the path of contact up to the point H-AB (the midpoint between point A and point B), or from E to H-DE. However, the result of this is that the contact ratio in the unmodified part is 1.0.

If you want to design a gear unit that runs as quietly as possible, it is usually better to select the long profile modification, because the transmission error is usually much lower in this case. To properly evaluate the effect of a profile modification, we recommend you calculate the meshing under load (see chapter Contact analysis).
