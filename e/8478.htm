用于强度计算的方法

ISO 14521 与 DIN 3996:2012 中定义的计算是相同的。

然而，ISO 14521 中定义的强度计算包含多种不同方法（A、B、C、D）。KISSsoft 使用文献记载中最精确的方法，通常是方法 B。此计算方法并非适用于所有材料（参见材料与润滑一章），因为某些经验值缺失。

ISO 14521 标准提供了一种计算方法来确定：

  • 效率
  • 磨损与抗磨损安全系数
  • 点蚀安全系数
  • 齿根安全系数
  • 挠度安全系数
  • 温度安全系数

轴交角的默认值设置为 90°，因为这是 DIN 3996 中定义的强度计算方法所规定的默认值。但是，您可以计算轴交角不为 90° 的几何，方法是使用 交错轴斜齿轮 计算模块（参见交错轴斜齿轮及带齿条的交错轴斜齿轮一章）。

注意：

  • 要进行强度计算，您需要非常特殊的材料数据，尤其是磨损值。标准仅针对最常用的蜗轮材料（大多为青铜）规定了这些值。这就是 KISSsoft 中材料选择有限的原因。
  • 润滑脂润滑：DIN 3996 中未提及润滑脂润滑。在这种情况下，KISSsoft 按油浴润滑进行计算。此假设是允许的，因为润滑类型对计算的影响非常小。
  • 齿根承载能力的疲劳极限值：标准提供了两个不同的值。如果您在数据库中输入较小的值，则不会接受因轮齿塑性变形导致的质量降低。
English Original

Methods used for strength calculation

The calculations defined in ISO 14521 and DIN 3996:2012 are identical.

However, strength calculation as defined in ISO 14521 includes a number of different methods (A,B,C,D;). KISSsoft uses the most precise documented method, which is usually Method B. This calculation method is not suitable for every material (see chapter Material and lubrication), because some of the empirical values are missing.

The ISO 14521 standard provides a calculation method for determining:

  • efficiency
  • Wear and safety against wear
  • Pitting safety
  • Root safety
  • Deflection safety
  • Temperature safety

The default value of the shaft angle is set to 90° because this is the default value specified in the strength calculation method defined in DIN 3996. However, you can calculate the geometry with a shaft angle that is not 90° by using the Crossed Helical Gears calculation module (see chapter Crossed helical gears and crossed helical gear with rack).

Notes:

  • To calculate strength, you require very special materials data, in particular the wear values. The standard only specifies these values for the most commonly used worm wheel materials (mostly bronze). This is why the selection of materials in KISSsoft is limited.
  • Grease lubrication: Grease lubrication is not mentioned in DIN 3996. In this situation, KISSsoft performs the calculation as for oil bath lubrication. This assumption is permissible, because the lubrication type has very little influence on the calculation.
  • Endurance limit values for tooth root load capacity: The standard provides two different values. If you enter the smaller value in the database, no decrease in quality due to plastic deformation of the teeth will be accepted.
