中文翻译

根据齿形计算成形直径

齿形计算模拟制造过程。在此过程中，它会计算齿根中的有效根切。选择根据齿形计算成形直径选项，以在每次计算运行中计算齿形、确定存在的任何根切并将其纳入计算。随后使用它来计算端面重合度以及齿根成形圆和齿顶成形圆（生成直径）。由于 KISSSOFT 已能自动正确计算凸角和根切情况下的成形直径，我们建议您不再使用此选项。

您可以选择将齿根成形圆、齿顶成形圆或这两个值都包含在齿形中。到目前为止，齿条的成形直径尚未取自齿形。

注意：

如果选择了此选项并且已预定义齿廓修形，则计算出的成形直径将位于修形的起点处。这通常会导致非常小的端面重合度 εα.i 和 εα.e。这是正确的，因为修形起点处的齿形不再与渐开线完全匹配。然而，为告知用户端面重合度过低而显示的消息相当令人困惑。如果齿廓修形尺寸设置正确，使承载啮合涉及整个齿高，则可以忽略此消息。这是因为承载状态下的端面重合度对应于理论端面重合度 εα。一般来说，我们建议您不要将此选项与齿廓修形一起使用。

English Original

Calculate form diameters from tooth form

The tooth form calculation simulates the manufacturing process. In doing so it calculates the effective undercut in the tooth root. Select the Calculate form diameter from tooth form option to calculate the tooth form in every calculation run, define any undercut that is present and include it in the calculation. This is then used to calculate the transverse contact ratio and the root and tip form circles (generated diameters). As KISSSOFT already automatically calculates the form diameters correctly for protuberance and undercut, we recommend you no longer use this option.

You can select whether the root form circle, the tip form circle, or both these values, are to be included in the tooth form. Up to now, the form diameter for racks has not been taken from the tooth form.

Note:

If this option is selected and profile modifications have been predefined, the calculated form diameter will be at the beginning of the modification. This often results in very small transverse contact ratios εα.i and εα.e. This is correct because, the tooth form at the start of the modification no longer exactly matches the involute. However, the message that is displayed, to inform the user that the transverse contact ratio is too low, is rather confusing. If the profile modification has been sized correctly, so that meshing under load involves a whole tooth height, this message can be ignored. This is because the transverse contact ratio under load corresponds to the theoretical transverse contact ratio εα. Generally speaking, we recommend you do NOT use this option with profile modifications.
