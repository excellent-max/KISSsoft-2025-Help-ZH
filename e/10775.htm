菜单、上下文菜单和工具栏

使用 文件 主菜单来打开、存储或保存模型。也可用于打开和关闭项目，或关闭并退出 KISSsys。还可打开或关闭 KISSsys 模板。

通过 视图 主菜单中的相应选项，可以隐藏或显示用户界面中的每个独立停靠窗口。您还可以刷新所有视图。

系统 主菜单选项使用户能够生成 KISSsoft 报告并运行运动学和 KISSsoft 计算。还可从 KISSsoft 数据库中选择一个载荷频谱，或在 KISSsys 中定义自己的频谱。使用这些功能可调用元素和变量概览的属性。

使用 插入 菜单选项可调用助手，它将引导您完成创建简单齿轮单元或单级行星齿轮单元所需的步骤。与助手的使用方式相同，可以使用元素框向模型添加元素，且不受任何限制。组框包含预定义的齿轮级，也可用于创建模型。默认模板用于将现有计算模板添加到已完成的模型中。

在 附加项 菜单中，用户将找到管理员设置、许可证工具、配置工具和语言设置。选择 附加项 -> 设置 更改通用程序设置，例如个体元素的名称或表格设置。

按照 Windows 约定，你将在菜单栏末尾找到 帮助 图标。可使用它在 KISSsoft 手册和 KISSsys 编程帮助中导航。选择 帮助 -> 信息，显示有关程序版本以及 KISSsoft 提供的支持的信息。

在主菜单窗口中，您可以找到用于组织已打开的子窗口（如表格和3D视图）的选项。打印选项仅在打开表格时启用。

除主菜单外，KISSsoft在许多位置使用上下文菜单。使用上下文菜单来访问特定区域或模型元素的动作。通常，单击右键鼠标按钮来显示上下文菜单。

工具栏为您提供更快访问菜单中经常使用的动作的途径。您还应阅读工具提示：它们显示工具栏中动作的信息，以及状态栏中的更详细说明。

English Original

Menus, context menus and the tool bar

Use the File main menu to open, store or save models. Also use it to open and close projects, or close and exit KISSsys. You can also open or close KISSsys templates.

Each individual docking window in the user interface can be hidden or displayed by selecting the appropriate option in the View main menu. You can also refresh all views.

System main menu options enable you to generate the KISSsoft report and run kinematics and KISSsoft calculations. You can also select a load spectrum for the model from the KISSsoft database or define your own spectra in KISSsys. Use these functions to call the properties of the elements and variables overviews.

Use Insert menu options to call an Assistant, which will guide you through the steps required to create a simple gear unit or a single stage planetary gear unit. In the same way as with the Assistant, you can use the Elements box to add elements to a model, but without any restrictions. The Group box contains predefined gear stages which can also be used to create a model. Default templates are used to add existing calculation templates to a finished model.

In the Extras menu, you will find the administrator settings, the license tool, the configuration tool and the language setting. Select Extras -> Settings to change general program settings such as the names of individual elements or table settings.

In accordance with Windows conventions, you will find the Help icon at the end of the menu bar. You can use it to navigate in the KISSsoft manual and the KISSsys programming help. Select Help -> Info to display information about the program version and the support provided by KISSsoft.

In the Main menu window, you will find options for organizing the opened sub-windows, such as tables and 3D views. The print option is only enabled if a table is open.

In addition to the main menu, KISSsoft uses context menus in many locations. Use context menus to access actions for a particular area or model element. Normally, you click the right-hand mouse button to display context menus.

The tool bar gives you faster access to actions from the menus that are used especially frequently. You should also read the tool tips: they display information about the actions in the tool bar and also the more detailed explanations in the status bar.
