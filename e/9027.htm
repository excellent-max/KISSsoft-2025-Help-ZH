中文翻译

对第三方程序的要求

要在第三方程序中成功运行和使用 KISSsoft，必须满足以下最低要求。第三方程序必须

  1. 具有用于提供信息（例如输入数据）的查询机制（即宏语言），
  2. 能够读写 ASCII 文件，
  3. 能够启动程序。
English Original

Requirements placed on the third party program

To successfully run and use KISSsoft within a third party program, the following minimum requirements must be met. The third party program must

  1. have a query mechanism (i.e. macro language) for providing information, e.g. input data,
  2. be able to write and read ASCII files,
  3. be able to start a program.
