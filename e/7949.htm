设置

选择 计算 > 设置 以输入其他值：

  • 出现错误消息（许用压力、许用预紧力）时不中止计算。
    如果显示有关超过屈服点或许用压力的错误消息，则在选中此选项时程序会继续计算。
  • 计算最小预紧力 FM/αA
    如果选中此选项，还会计算载荷工况 FM/αA。预紧力 FM/αA 是必须达到的最小预紧力。αA 是拧紧系数，它描述预紧力的分散程度。如果选中此选项，该预紧力的结果将显示在报告中。
  • 偏心夹紧时不增加所需的夹紧力
    KISSsoft 会增大所需的夹紧载荷，以防止偏心夹紧时产生缝隙。您可以在此处关闭此功能。使用此选项时请谨慎。该计算假定不会产生缝隙！
  • 计算表面压力时忽略头部支承区域的内径 da
    如果选中此选项，则在计算表面压力时不考虑 da 。因此，支承面积不是使用较大的直径（头部支承区域的内径 da 或孔直径 dh）来确定，而总是改用孔直径 dh。支承面积会增大到孔直径 dh，前提是由 da 限定的区域开始屈服。
    此选项不符合 VDI 2230，因为在该标准中总是使用较大的直径。
  • 对螺纹孔接头使用贯穿螺栓接头的柔度
    如果被夹紧件的接触面面积相对于螺栓头支承面积较小，则在计算柔度时可以将螺纹孔接头当作贯穿螺栓接头来处理。
  • 工作力仅在工作温度下出现
    通常，KISSsoft 根据所需的夹紧载荷以及环境温度和工作温度下的载荷来计算最小预紧力。如果工作力仅在工作温度下出现，则可以选择此选项。在这种情况下，最小预紧力仅在工作温度下计算。
  • 使用估算公式自动计算与温度相关的材料数据
    KISSsoft 可以通过使用经验公式自动计算工作温度下的材料数据。这些经验公式不考虑您输入的材料数据：它们采用"常用钢"的平均温度依赖关系！如果未选中此选项，您可以手动输入工作温度下的材料数据。
  • 确定垫圈的比热膨胀
    这会显示垫圈子窗口中的热膨胀值输入字段。如果未选中此选项，则使用板的平均热膨胀来计算预紧力差值。换句话说，垫圈与板具有相同的热膨胀。因此，您可以选择输入该值。如果您输入了该值，则预紧力差值将使用您指定的值来计算，但此计算中仍使用板的柔度。VDI 2230 并未规定对垫圈使用专门的热膨胀计算。
  • 在无扭转的情况下计算装配和工作应力
    如果连接是使用螺栓中不产生扭转应力的工艺拧紧的，则可以选择此选项。因此，在计算所需的防屈服安全系数时，仅考虑螺栓中的拉应力。
  • 折减系数
    当机器处于工作状态时，折减系数用于计算等效应力。在许多情况下，弹性预紧连接中的扭转应力会减少 50%。因此，VDI 2230 建议此处使用值 0.5。
  • 超过屈服点
    此处提供三个选择选项：不允许超过屈服点、仅允许在工作期间超过屈服点，或者允许在工作期间和装配期间超过屈服点。这使您能够选择首选的计算变体。
  • 硬化系数
    在计算装配期间和工作期间是否已超过屈服点时，会使用一个附加的硬化系数 kv。硬化系数的默认值为 1.15。VDI 规定该值应在 1.1 到 1.2 之间。
  • 工作期间的附加扭矩
    在计算工作应力时，可以定义一个附加扭矩。然后，该扭矩用于剪切应力计算。这既适用于不允许超过屈服点的情况，也适用于允许超过屈服点的情况。
  • 工作期间的附加横向力
    在计算工作应力时，可以定义一个附加横向力。然后，该力用于剪切应力计算。这适用于超过屈服点的情况。
  • 无限寿命强度
    列表框用于选择要进行无限寿命强度计算的螺栓类型。对于高强度摩擦型紧固件，由于特殊的几何特征，其可持续疲劳寿命会降低 10%。对于热镀锌高强度摩擦型紧固件，其可持续疲劳寿命会降低 30%。（VDI 2230 中关于交变应力的章节的注释）
  • 螺栓拉伸强度系数
    该系数用于计算为获得 Rm 的实用值所需的最小旋合长度，如 VDI 2230 中所述（参见"旋合长度"章）。
  • 屈服点利用率（参考）
    还可以在 预紧力和拧紧扭矩 图形中显示参考利用率。如果您覆盖该值，则可以定义任意参考利用率并将其插入图形中。如果您不覆盖该值，则会设置屈服点和旋转角控制拧紧的默认值，即 100% 利用率。对于所有其他拧紧技术，则采用 90% 利用率。

Settings

Select Calculations > Settings to enter additional values:

  • Don't abort calculation when error messages (permissible pressure, permissible pretension force) occur.
    If error messages about exceeding the yield point or the permissible pressure are displayed, the program continues the calculation if this option is selected.
  • Calculate minimum pretension force FM/αA
    If this option is selected, the load case FM/αA is also calculated. The pretension force FM/αA is the minimum pretension force that must be achieved. αA is the tightening factor. It describes the pretension force scatter. If this option is selected, the results for this pretension force are displayed in the report.
  • Do not increase required clamping force for eccentric clamping
    KISSsoft increases the required clamp load to prevent gaping for eccentric clamping. You can switch off this function here. Take care when using this option. The calculation assumes that gaping does not occur!
  • Ignore inside diameter of head bearing area da when calculating surface pressure
    If this option is selected, da is not taken into account when the surface pressure is calculated. Consequently, the supporting area is not determined using the greater diameter (inside diameter of head bearing area da or bore diameter dh), but always the bore diameter dh instead. The supporting area increases to the bore diameter dh if the area limited by da begins to yield.
    This option is not VDI 2230 compliant, as, in it, the greater diameter is always used.
  • Use the resiliences of a through-bolt joint for a tapped thread joint
    If the interface area of the clamped part is relatively small compared to the bolt head bearing area, the tapped thread joint can be treated like a through-bolt joint when the resiliences are calculated.
  • Operating force only at operating temperature
    Normally, KISSsoft calculates the minimum pretension force based on the required clamp load and loading at ambient and operating temperatures. This option can be selected if the operating force only occurs at operating temperature. In this case, the minimum pretension force is then only calculated at operating temperature.
  • Calculate temperature dependent material data automatically with estimation formulae
    KISSsoft can automatically calculate material data at operating temperature by using empirical formulae. These empirical formulae do not take into account the material data you entered: they use an average dependency for "commonly used steels"! If this option is not selected, you can enter the material data at operating temperature manually.
  • Determine specific thermal expansion of washers
    This displays the input field for thermal expansion values in the sub-window for washers. If this option is not selected, the difference in pretension force is calculated using the average thermal expansion of the plates. In other words, the washer has the same thermal expansion as the plates. This is why you have the option of inputting this value. If you do so, the difference in pretension force is calculated using the value you specified, but the resilience of the plates is still used in this calculation. VDI 2230 does not specify that a special thermal expansion calculation is to be used for washers.
  • Calculate mounting and operating stress without torsion
    You can select this option if the connection is tightened using a process in which torsional stresses do not occur in the bolt. As a result, only the tensile stress in the bolt is taken into account for calculating the required safety against yield.
  • Reduction coefficient
    The reduction coefficient is used to calculate equivalent stress when the machinery is in its working state. In many cases, the torsional stresses in elastically preloaded connections reduce by 50%. For this reason, VDI 2230 recommends the value 0.5 is used here.
  • Exceeding the yield point
    Three selection options are available here: yield point cannot be exceeded, yield point can only be exceeded during operation, or yield point can be exceeded during operation and mounting. This enables you to select your preferred calculation variant.
  • Hardening coefficient
    An additional hardening factor, kv is used when calculating whether the yield point has been exceeded during mounting and during operation. The default value for the hardening coefficient is 1.15. VDI specifies that it should between 1.1 and 1.2.
  • Additional torsional moment during operation
    An additional torsional moment can be defined when calculating working stress. This torsional moment is then used in the shear stress calculation. This applies both in cases where the yield point cannot be exceeded and in cases in which the yield point can be exceeded.
  • Additional transverse force during operation
    An additional transverse force can be defined when calculating working stress. This force is then used in the shear stress calculation. This applies in cases where the yield point is exceeded.
  • Infinite life strength
    Selection list used select the type of bolt for which the infinite life strength calculation is to be performed. In the case of high-strength friction-grip fasteners, the sustainable fatigue life is reduced by 10% because of special geometrical features. In the case of hot-galvanized high-strength friction-grip fasteners, the sustainable fatigue life is reduced by 30%. (Comment in VDI 2230, chapter on alternating stress)
  • Tensile strength of bolt coefficient
    This coefficient is used to calculate the minimum length of engagement required to achieve a practical value for Rm, as in VDI 2230 (see chapter Length of engagement).
  • Utilization of yield point (reference)
    A reference utilization can also be displayed for the Pretension forces and tightening torques graphic. If you overwrite the value, any reference utilization can be defined and then inserted in the graphic. If you do not overwrite the value, the default value for yield point and rotation angle-controlled tightening with 100% utilization is set. For all other tightening techniques, 90% utilization is applied.
