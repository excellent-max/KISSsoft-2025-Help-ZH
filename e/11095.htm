中文翻译

简化的齿轮视图

可用两种不同视图中的任意一种绘制齿轮。在简化视图中，可在图纸中创建一个仅包含齿轮的边轮廓和参考圆的剖面显示视图。目前，简化视图仅适用于外部齿。简化视图选项不是默认设置。

要查看简化显示，请打开 KISSsoft 安装目录中的 kiss.ini 文件并更改此项：

SIMPLIFIEDPRESENTATION=1

English Original

Simplified gear view

You can draw the gear in one of two different views. In the simplified view, you can create a section display view of the gear in the drawing which only contains the gear's edge contours and reference circle. Currently, the simplified view is only available for external teeth. The simplified view option is not the default setting.

To view a simplified display, open the kiss.ini file in the KISSsoft installation directory and change this entry:

SIMPLIFIEDPRESENTATION=1
