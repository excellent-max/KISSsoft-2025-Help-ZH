中文翻译

使用滚齿刀具生成圆柱齿轮

要使用刀具生成圆柱齿轮，请输入齿轮参考齿廓。当您添加此操作时，窗口会根据您在 参考齿廓 输入窗口中定义的值自动填充。如果刀具是非触顶刀具，则参考齿廓的齿顶高根据齿顶圆自动确定，而不采用您输入的值。对于特殊应用（使用不同模数的刀具制造齿轮），您可以修改模数 mn 和压力角 αn。然后可以使用尺寸计算按钮。单击尺寸计算按钮可根据指定的基圆在每种情况下计算正确的值。单击 刀具... 按钮打开 定义刀具 窗口（参见 刀具：滚齿刀具 一章），该窗口显示刀具列表。要定义公差带，您可以直接输入生成变位系数（自定义输入），或使用预处理或最终处理公差。

滚齿刀具数据也可以作为系数或绝对长度（mm 或英寸）输入。如果滚齿刀具数据是图纸中给出的长度（以 mm 或英寸为单位），这些选择选项会让您的工作轻松得多。

在对 haP0* 进行尺寸计算时，系统会计算该值，随后用它来加工直至有效齿根直径的渐开线。此处显示的推荐值是精确计算值，再加 0.05（以便在齿根直径和有效齿根直径之间获得一个小间距）。

如果您使用尺寸计算按钮来定义砂轮，半径 ϱaP0 应较小（例如 0.1*mn），否则磨削过程可能触及齿根半径。

注意

此处输入的刀具信息独立于 参考齿廓 输入窗口中指定的数据。换句话说，齿形计算完全基于 齿形 输入窗口中定义的值。

English Original

Generate cylindrical gear with hobbing cutter

To generate a cylindrical gear with a cutter, input the gear reference profile. When you add this operation, the window is filled automatically, based on the values you defined in the Reference profile input window. If the tool is a non-topping tool, the addendum of the reference profile is determined automatically from the tip circle, and not transferred from the values you input. For special applications (manufacturing a gear with a cutter with a different module), you can modify the module mn and the pressure angle αn. You can then use the Sizing buttons. Click the Sizing buttons to calculate the correct value in each case for the specified base circle. Click the Cutter... button to open the Define cutter window (see chapter Tool: Hobbing cutters), which displays a list of tools. To define the tolerance field, you can either enter the generating profile shift coefficients directly (Own input), or use the pretreatment or final treatment tolerances.

The hobbing cutter data can also be input as coefficients or as absolute lengths (mm or inch). These selection options make your job much easier if the hobbing cutter data are the lengths (in mm or inches) given in a drawing.

When sizing haP0*, the system calculates the value, which is then used to manufacture the involute up to the active root diameter. The proposed value shown here is the exactly calculated value, to which 0.05 is added (to obtain a small distance between the root diameter and the active root diameter).

If you use the Sizing button to define the grinding wheel, the radius ϱaP0 should be small (e.g. 0.1*mn), otherwise the grinding process may reach the root radius.

Note

The cutter information entered here is independent of the data specified in the Reference profile input window. In other words, the tooth form calculation is based exclusively on the values defined in the Tooth form input window.
