中文翻译

椭圆形齿根修形

齿根圆角被一个椭圆形轮廓所取代，该轮廓与齿面和齿根圆相切延伸。其目的是获得尽可能大的曲率半径。轮廓的走向可通过范围 1 ÷ 20 内的系数来影响。如果您在修形起始直径处点击“尺寸计算”按钮，软件会为有效齿根圆直径建议一个值（略微增大，以避免将修形应用于根切时出现问题）。如果您希望齿形的某一部分延伸至齿根圆，则齿根圆上的可定义长度应设置为 > 0。例如，如果要使用测量滚柱来测量齿根圆，这是一个不错的方法。

齿根区域较大的齿厚意味着必须检查与齿轮副中另一齿轮的展成过程。有关类似椭圆轮廓的数学描述，请联系 KISSsoft 技术支持，索取单独的“kisssoft-anl-123-E-Elliptical root modification”说明文档。

English Original

Elliptical root modification

The root fillet is replaced by an ellipse-shaped contour which progresses tangentially in the flank and root circle. The aim is to achieve the greatest possible radius of curvature. The course of the contour can be influenced by the coefficient in the range 1 ÷ 20. If you click on the Sizing button for the diameter at the start of modification, the software suggests a value for the active root diameter (slightly increased, to prevent problems when applying the modification to an undercut). The definable length on the root circle is then set to > 0 if you want an area of the tooth form to run on to the root circle. For example, this is a good idea if the root circle is to be measured with measuring rollers.

The greater tooth thickness in the root area means that the generation process with the other gear in the pair must be checked. For a mathematical description of contours that are similar to ellipses, please contact KISSsoft Support and ask for the separate "kisssoft-anl-123-E-Elliptical root modification" instructions.
