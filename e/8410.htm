中文翻译

轴承力曲线

使用 定义齿向载荷系数 对话框窗口中的轴承配置选项来计算轴承力曲线。在这种情况下，计算中会使用轴承距离 L 和距离 s。齿向载荷系数计算中给出的值用作轴承之间的距离。该图形的目的不是显示正确的轴承力，而是表示这些力的变化。

轴承力的变化会引起轴的振动和箱体变形的变化。

English Original

Bearing force curve

Use the bearing configuration options in the Define face load factor dialog window to calculate the bearing force curve. In this case, both the bearing distance L and the distance s are used in the calculation. The value given for the face load factor calculation is used as the distance between the bearings. The purpose of this graphic is not to display the correct bearing forces, but to represent the variations in these forces.

Variations in the bearing forces cause vibrations in the shafts and changes in housing deformations.
