中文翻译

引用

引用元素的行为与任何其他变量一样，区别在于另一个变量会获取数据。必须为引用元素输入有效的变量名作为目标。引用目标必须作为字符串输入。这可以是带引号的实际名称，也可以是得到字符串的表达式，例如字符串的串联（例如gear1+'.z'，其中字符串变量为gear1或'gearwheel1.z'）。系统会用红色标记无效的引用。

English Original

References

A reference element behaves like any other variable, with the difference that another variable fetches the data. A valid variable name must be entered as the target for the reference element. The reference target must be entered as a character string. This will be either an actual name in quotation marks or an expression resulting in a character string, e.g. a concatenation of character strings (e.g. gear1+'.z' with the string variables gear1 or 'gearwheel1.z'). The system marks an invalid reference in red.
