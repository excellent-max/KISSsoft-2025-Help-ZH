中文翻译

输出文件

为了向调用 KISSsoft 的程序返回相关数据，指定的输出文件 MMMMUSER.OUT 将在计算后立即生成。输出文件的范围和格式将在名为 MMMMUSER.RPT 的报告模板窗口中定义。

这意味着 KISSsoft 可以完全适应第三方程序的语法。命令的范围和报告生成器的语法在“报告”部分中说明（参见"报告模板"章）。此外，还提供了示例报告文件，以帮助您创建报告模板。

English Original

Output file

To return the data that is relevant for the KISSsoft calling program, the specified output file MMMMUSER.OUT will be generated immediately after a calculation. The scope and the format of the output file will be defined in a report template called MMMMUSER.RPT window.

This means that KISSsoft can fully adapt itself to the syntax of a third party program. The range of commands and the report generator's syntax is described in the Reports section (see chapter Report templates). Example report files are supplied to help you with this.
