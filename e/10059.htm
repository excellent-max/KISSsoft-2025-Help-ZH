轴计算材料

该表适用于轴 (w010):

  • 根据 Hänchen 计算强度的值：
    • 弯曲疲劳极限 σbW: [N/mm2]
  • 根据 DIN 743 计算强度的值:
    • 参考直径 db [mm], 拉伸强度 Rm [N/mm2], 屈服点 Rp [N/mm2], 弯曲疲劳极限 σbW [N/mm2], 拉伸/压缩疲劳极限 σzdW [N/mm2], 扭转疲劳极限 τtW [N/mm2]
    • 实验数据： 数据库条目引用外部表（参见「外部表」章节）。实验 Haigh 图的表以 W01-???.dat 开头。
    • CrNiMo钢： 在确定渗碳钢的尺寸系数K1时，需要指定该钢是否为CrNiMo渗碳钢。材料20NiCrMo13-4, 17NiCrMo6-4, 17NiCrMoS6-4, 18NiCr5-4, 17CrNi6-6, 18CrNiMo7-6, 14NiCrMo13-4, 22CrMoS3-5和15NiCr13属于这一组。根据 DIN 10084，这些材料的拉伸强度没有明显下降。根据林克教授的说法，这些材料也属于这一组。

    • 参考直径 Rm,N 的拉伸强度 [N/mm2], 参考直径 Re,N 的屈服点 [N/mm2], Rp,N 的有效参考直径 deff,N,p [mm], Rm,N 的有效参考直径 deff,N,m [mm], A 的有效参考直径 deff,N,a [mm], 计算 Kd,p（流动）的常数 ad,p, 计算 Kd,m（断裂）的常数 ad,m, 计算 Kd,a（断裂伸长率）的常数 ad,A
    • 断裂伸长率 A: [%]
    • FKM 组： 显示该条目所属材料组的选择列表。
English Original

Material Shaft calculation

The table applies to shafts (w010):

  • Values for calculating strength according to Hänchen:
    • Bending fatigue limit σbW: [N/mm2]
  • Values for strength calculation according to DIN 743:
    • Reference diameter db [mm], Tensile strength Rm [N/mm2], Yield point Rp [N/mm2], Bending fatigue limit σbW [N/mm2], Tension/compression fatigue limit σzdW [N/mm2], Torsion fatigue limit τtW [N/mm2]
    • Experimental data: The database entries refer to external tables (see chapter External tables). Tables for the experimental Haigh diagram begin with W01-???.dat.
    • CrNiMo case hardening steel: When determining the size factor K1 for case hardening steel, you need to specify whether the steel is CrNiMo case hardening steel. The materials 20NiCrMo13-4, 17NiCrMo6-4, 17NiCrMoS6-4, 18NiCr5-4, 17CrNi6-6, 18CrNiMo7-6, 14NiCrMo13-4, 22CrMoS3-5 and 15NiCr13 belong to this group. According to DIN 10084, there is no significant drop in the tensile strength of these materials. These materials also belong to this group according to Prof. Linke.
  • Values for strength calculation according to FKM:
    • Tensile strength for reference diameter Rm,N [N/mm2], Yield point for reference diameter Re,N [N/mm2], Effective reference diameter for Rp,N deff,N,p [mm], Effective reference diameter for Rm,N deff,N,m [mm], Effective reference diameter for A deff,N,a [mm], Constant for the calculation of Kd,p (flow) ad,p, Constant for the calculation of Kd,m (fracture) ad,m, Constant for the calculation of Kd,a (elongation at break) ad,A
    • Elongation at break A: [%]
    • FKM Group: Selection list showing the material group to which the entry belongs.
