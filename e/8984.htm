与 Siemens NX 的 3D 接口：

制造商：KISSsoft AG

Siemens NX 与 KISSsoft 之间的接口在 3D CAD 系统中建立了直接集成。借助它，所有 KISSsoft 计算模块都可以直接从 Siemens NX 内部运行。在 KISSsoft 中计算的圆柱齿轮或锥齿轮可以直接在 NX 中作为 3D 零件（参见 3D 齿轮的生成 一章）以真实齿形生成。在 KISSsoft 中计算的轴可以作为由圆柱和圆锥元素组成的 3D 零件（参见 3D 轴的生成 一章）直接在 NX 中生成。您可以按照 DIN 3971 图 1 创建外齿或内齿的直齿或斜齿圆柱齿轮、直齿或斜齿齿条、蜗杆或直齿锥齿轮以及轴。

如果您要生成新零件，将首先打开 新建 对话框。在其中，您可以输入用于生成零件的文件名。当您使用 Teamcenter 时，其对话框会自动显示，以便您也可以在 Teamcenter 环境中生成或保存零件。

您还可以选择为现有轴添加轮齿（参见 存在现有轴数据时的轮齿 一章）。此外，2D 范围内的齿轮制造数据（参见 添加制造数据 一章） 可以通过该接口自动作为表格插入到图纸中。齿轮制造数据被附加到相应的切口（齿槽）上。

English Original

3D interface to Siemens NX:

Manufacturer: KISSsoft AG

The interface between Siemens NX and KISSsoft creates the direct integration in the 3D CAD system. Use this to run all KISSsoft calculation modules directly from within Siemens NX. Cylindrical or bevel gears calculated in KISSsoft can be generated directly in NX as a 3D part (see chapter Generation of 3D gears) with a real tooth form. Shafts calculated with KISSsoft can be generated as a 3D part comprising cylinder and cone elements (see chapter Generating 3D shafts) directly in NX. You can create cylindrical gears with straight or helical teeth, which are outside or inside, racks with straight or helical teeth, worms, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1, and shafts.

If you are generating a new part, the New dialog opens first. In it, you can enter the name of the file in which the part should be generated. When you use Teamcenter, its dialog is displayed automatically so you can also generate or save the part in the Teamcenter environment.

You also have the option of adding toothing to existing shafts (see chapter Gear teeth if existing shaft data is present). In addition, gear manufacturing data in the 2D range (see chapter Adding manufacturing data) can automatically be inserted on the drawing as a table, with the interface. The gear manufacturing data is attached to the relevant cutout (tooth space).
