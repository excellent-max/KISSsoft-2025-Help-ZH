表 38.1：不同制造工艺的精度等级

花键公差

作为比较，我们针对 DIN 5480、ISO 4156 和 ANSI B92.1（花键）中规定的公差，以及 ISO 1328（圆柱齿轮副）中给定的公差计算了一个示例，其精度等级为 6 级（外）和 7 级（内）。

ISO 4156 精度等级的结果比 DIN 5480 精度等级的相同结果高 3 到 4 个精度等级。

ANSI B92.1 返回与 ISO 4156 相同的结果。

这非常令人困惑，因为所有其他齿轮（直齿或斜齿圆柱齿轮、锥齿轮、蜗杆等）返回的精度等级对于 DIN、ISO 和 AGMA 公差结果而言大多非常相似。

Table 38.1: Accuracy grades for different manufacturing processes

Tolerances for splines

As a comparison, we have calculated an example for the tolerances specified in DIN 5480, ISO 4156 and ANSI B92.1 (spline) and for the tolerances given in ISO 1328 (cylindrical gear pair) with accuracy grade 6 (external) and accuracy grade 7 (internal).

The results for the ISO 4156 accuracy grade are 3 to 4 accuracy grades higher than the same results for the DIN 5480 accuracy grade.

ANSI B92.1 returns the same results as ISO 4156.

This is all very confusing, because all other gears (cylindrical gears with straight or helical teeth, bevel gears, worms, etc.) return accuracy grades that are mostly very similar for DIN, ISO and AGMA tolerance results.
