中文翻译

内轮廓

内轮廓与外轮廓一样，从左到右构建。例如，如果要从右侧生成带轴向孔的轴，则必须首先输入一个内部圆柱体的数据，该圆柱体从左侧开始，直径为 0，一直延伸到孔开始的位置。

English Original

Inner contour

The inner contour is built up from left to the right, in the same way as the outer contour. For example, if you want to generate a shaft with an axial hole from the right-hand side, you must first input data for an inside cylinder starting from the left-hand side with a diameter of 0 that extends up to the point where the bore begins.
