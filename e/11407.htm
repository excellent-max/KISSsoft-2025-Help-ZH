中文翻译

齿形导出

在 计算 菜单中，单击"齿形导出"可将齿轮或刀具的形状以坐标形式导出到文本文件。
导出功能有以下几种设置：

  • 选择截面
  • 选择操作
  • 选择分隔符
  • 文本文件格式
  • 减少点数
  • 删除重复点
English Original

Tooth form export

In the Calculations menu, click on "Tooth form export" to export the shape of the gear or tool to a text file, as coordinates.
There are a number of settings available here for the export functions:

  • select the cross-section
  • select the operation
  • select the separator
  • text file format
  • reduce the number of points
  • remove duplicate points
