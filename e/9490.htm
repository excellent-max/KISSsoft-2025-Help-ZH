中文翻译

不同齿轮计算程序之间的差异

当您比较使用不同齿轮计算程序执行的计算时，总会发现结果存在差异。其中许多差异是由于输入的数据不同造成的。然而，即使输入的所有数据都相同，您仍然会得到不同的结果。

我们的用户经常提出的问题之一是 KISSsoft 计算的结果是否正确。

KISSsoft 圆柱齿轮计算功能中使用的主要计算流程基于 DIN 3990、ISO 6336 和 AGMA。它忠实地遵循方法 B 中描述的步骤。然而，由于 DIN 3990 或 ISO 6336 提供了各种不同的方法（B、C、D）和子方法，不同的计算程序产生略微不同的结果也就不足为奇了。大多数程序并非始终使用方法 B 进行计算。相反，它们部分使用方法 C 甚至 D，这些方法更容易编程。

为了让我们的用户更加放心，我们因此在 KISSsoft 中集成了 FVA 程序 计算变体。该变体提供的结果与 ST+ FVA 程序完全相同，后者由慕尼黑工业大学开发，可用作参考程序。
KISSsoft 根据 DIN 3990 的计算与 FVA 程序之间的微小差异，是由于 FVA 程序相对于 DIN 3990 中定义的标准默认流程存在轻微（允许的）偏差。

English Original

Differences between different gear calculation programs

You will always discover differences in the results when you compare calculations performed with different gear calculation programs. Many of these differences are due to the different data entered. However, even if all the data entered is the same, you will still get different results.

One of the questions our users often ask is whether the results calculated by KISSsoft are correct.

The main calculation process used in the KISSsoft cylindrical gear calculation functions is based on DIN 3990, ISO 6336, and AGMA. It faithfully follows the procedure described in Method B. However, as DIN 3990 or ISO 6336 offer various different methods (B, C, D) and sub-methods, it is no surprise that different calculation programs produce slightly different results. Most programs do not perform calculations that consistently use Method B. Instead, they partially use Method C or even D, which are easier to program.

To give our users additional reassurance, we have therefore integrated the FVA program calculation variant in KISSsoft. This variant supplies exactly the same results as the ST+ FVA program that was developed by the Technical University in Munich, and which can be used as a reference program.
The minor differences between KISSsoft's calculations according to DIN 3990 and the FVA programs are due to the slight (permissible) deviations of the FVA program from the standard default process defined in DIN 3990.
