中文翻译

完整系统的 Parasolid 导出

可以使用 Parasolid 生成并导出完整的 3D 装配体。选择 文件 > 导出... > 完整 3D 模型 可将完整系统保存为 STEP、Parasolid 文本 (X_T) 或 Parasolid 二进制 (X_B) 文件。将使用 3D 查看器的设置。

English Original

Parasolid export of the complete system

The complete 3D assembly can be generated and exported using Parasolid. Select File > Export... > Complete 3D model to save the complete system as a STEP, Parasolid text (X_T) or Parasolid binary (X_B) file. The settings for the 3D viewer are used.
