中文翻译

珩齿

如果您需要检查珩齿是否可以用作齿轮的精加工工艺，请选择此选项。单击 Plus 按钮打开一个窗口，您可以在其中输入特定的附加详细信息。

使用这些检查可以粗略估计刀具和机床的局限性，也可以（可选）显示刀具与工件之间可能的碰撞。您可以使用这些测试进行初步评估，但这不能替代与刀具制造商一起进行的最终分析。

碰撞检查

系统还可以检查配置中工件与刀具前侧或后侧之间可能发生的碰撞。为此，请在 “碰撞检查” 中选择相应的场景。所需数据显示在各个帮助屏幕中（信息按钮）。

刀具制造的结果和文档

结果列在报告中。从供应商处采购刀具的公司可以使用 “报价” 按钮生成一份特殊文档，其中包含获取珩齿刀具报价所需的所有详细信息。

精尺寸设计

检查珩齿功能也可作为精尺寸设计过程的一部分使用。条件设置完成后，检查将自动执行。在包含精尺寸设计结果的选项卡中，用户可以右键单击显示列功能以将其激活，并显示 “珩齿” 列。

English Original

Honing

Select this option if you need to check whether honing can be used as the final machining process on a gear. Click the Plus button to open a window in which you can enter specific additional details.

Use the checks to generate a rough estimate of the limitations of the tool and the machine and also, optionally, to show possible collisions between the tool and the workpiece. You can use the tests to perform an initial evaluation, but this cannot be regarded as a replacement for a final analysis performed together with the tool manufacturer.

Collision check

The system can also check the configuration for possible collisions between the workpiece and the tool front or rear side. To do this, select the corresponding scenarios in "Collision check". The required data is displayed in the individual help screens (Info button).

Results and documents for tool manufacture

The results are listed in the report. Companies that purchase tools from suppliers can use the "Offer" button to generate a special document that contains all the details needed for obtaining an offer for a honing tool.

Fine sizing

The Check for Honing function is also available as part of the fine sizing process. The check is performed automatically once the conditions have been set. In the tab that contains the fine sizing results, the user can right-click on the Display columns function to activate it and display the "Honing" columns.
