设置

单击图形 > 设置菜单选项以配置 图形并输入视频录制设置。


二维图形

选项：将曲线裁剪到图表范围

如果不选择此设置，则会显示整条曲线的完整变化过程，即使它超出了当前轴的范围。

三维图形

选项：背景、CAD 系统（您可以选择已购买许可证的接口）以及投影。

视频录制

视频编解码器：

  • H.264 - 一种广泛使用的格式，几乎在所有地方都受支持。
  • H.265 - 优化效果更好，支持高达 8k（UHD 8192×4320）的分辨率。但这可能导致兼容性问题。

模式：

  • 恒定比特率 (CBR) - 恒定比特率不会动态调整。如果图像中运动过多，这可能导致质量损失。
  • 无约束比特率 - 视频质量取决于平均最小比特率。包含大量运动的图像序列会以相应更高的比特率录制。
  • 受约束比特率 - 视频质量取决于平均比特率和最大比特率。整个视频的平均比特率不得低于指定值。但是，某个特定序列可能会达到最大比特率的极限。因此，编码器必须以低于平均比特率的速率对其他序列进行编码。
  • 恒定速率系数 (CRF)：如果设置了此项，则恒定比特率基于输入的恒定速率系数输入的值。

帧率：每秒的图像数。

固定宽度：如果输入固定宽度，视频将以该宽度（以像素为单位）录制。如果此处不输入值，则视频以当前尺寸生成。

固定高度：如果输入固定高度，视频将以该高度（以像素为单位）录制。如果此处不输入值，则视频以当前尺寸生成。

恒定速率系数：介于 0-100 之间的值，用于定义文件的带宽和大小。默认值为 24。

平均比特率：以比特每秒为单位的近似平均数据速率。

最大比特率：以比特每秒为单位的最大数据速率。

English Original

Settings

Click on the Graphic > Settings menu option to configure the graphics and input the settings for video recording.


2D graphics

Option: Clip curves to diagram range

If you do not select this setting, the entire curve progression is displayed, even if it exceeds the current axis range.

3D graphics

Options: Background, CAD system (you can select the interfaces for which licenses have been purchased) and Projection.

Video recordings

Video codec:

  • H.264 - a widely used format which is supported almost everywhere.
  • H.265 - has better optimization and supports a resolution of up to 8k (UHD 8192×4320). However, this can lead to problems of compatibility.

Mode:

  • Constant Bit Rate (CBR) - the constant bit rate is not adjusted dynamically. This can result in a loss of quality if there is too much movement in the image.
  • Unconstrained Bit Rate - the video quality depends on the average minimum bit rate. Image sequences involving a lot of movement are recorded with a correspondingly higher bit rate.
  • Constrained Bit Rate - the quality of the video depends on the average bit rate and the maximum bit rate. The average bit rate of the entire video must not fall below the specified value. However, it may happen that a particular sequence maxes out the maximum bit. For that reason, the encoder must encode other sequences at less than the average rate.
  • Constant Rate Factor (CRF): if this is set, the constant bit rate is based on the value input as the Constant Rate Factor.

Frame rate: the number of images per second.

Fixed width: if you input a fixed width, the video is recorded with this width (in pixels). If you do not input a value here, the video is generated at the current size.

Fixed height: if you input a fixed height, the video is recorded at this height (in pixels). If you do not input a value here, the video is generated at the current size.

Constant Rate Factor: a value between 0-100 which defines the file's band width and size. The default value is 24.

Average bit rate: approximate average data rate in bits per second.

Maximum bit rate: maximum data rate in bits per second.
