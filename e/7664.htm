变量对话框中的对话框元素

以下对话框元素可用于变量对话框：

水平分组：

水平分组提供了一个框架，其中各个对话框元素并排排列。它们的位置必须始终由垂直分组定义，这意味着水平分组中的所有对话框元素都必须在垂直分组中定义。水平分组的定义如下：

[C:VDLG_HORZ, Caption_str, DistAbove_n, DistAfter_n, [Dialogelem]]

  • C: VDLG_HORZ：水平分组的类型定义。
  • Caption：水平分组的标题。如果"Caption"不是空字符串，则会在水平分组周围绘制一个边框。
  • DistAbove：距水平分组上方的下一个对话框元素的距离。
  • DistAfter：距水平分组下方的下一个对话框元素的距离。"DistAfter"和"DistAbove"以像素为单位指定。
  • [Dialogelem]：用于定义位于水平分组中的对话框元素的元素数组。该数组只能包含 VDLG_Vert 类型的元素。

垂直分组：

垂直分组提供了一个框架，其中各个对话框元素在彼此下方排列。对话框元素的宽度由垂直分组定义。垂直分组的定义如下：

[C:VDLG_Vert,Caption_str,[XStart_r,XEnd_r],XPart_r,[Diag],Marg_n]

  • C:VDLG_Vert：垂直分组的类型定义。
  • Caption：垂直分组的标题。垂直分组始终在其周围绘制一个边框。
  • [XStart,XEnd]：XStart 和 XEnd 定义垂直分组宽度相对于上级对话框宽度的系数（介于 0 和 1 之间）。它们还定义了垂直分组的 X 位置。
  • XPart：介于 0 和 1 之间的系数，定义了对话框字段的提示值与输入值之间的比率（分配给输入字段的文本称为"提示"）。如果 XPart=-1，则提示位于对话框元素上方。
  • [Diag]：用于定义垂直分组中对话框元素的元素数组。
  • Marg：一个可选参数，定义了对话框元素相对于垂直分组边缘的位移。这意味着对话框元素与垂直分组的左边缘和右边缘都保留"Marg"（边距）距离。

RealEditFeld:

提供一个可在其中输入浮点数的编辑框。

[C:VDLG_Real,Prompt_str,Preset_r,res,res,Places_n]

  • C:VDLG_Real：RealEdit 字段类型定义。
  • Prompt：分配给输入字段的文本。
  • Preset：预设值。
  • res：此处为两个当前未使用的可选参数保留了位置。但是，在定义中这些位置不能留空（例如，[C:VDLG_Real,Prompt,Preset,0,0,Places] 是正确的解决方案，而 [C:VDLG_Real,Prompt,Preset,,,Places] 则不是）。
  • Point：定义输入字段中小数位数的可选参数。
  • 返回值：返回值是输入字符串。

IntEditFeld:

提供一个可在其中输入整数的编辑框。

[C:VDLG_Int,Promt_str,Preset_n]

  • C:VDLG_Int：IntEdit 字段类型定义。
  • Prompt：分配给输入字段的文本。
  • Preset：预设值。
  • 返回值：返回值是输入字符串。

StringEditFeld:

提供一个可在其中输入文本的编辑框。

[C:VDLG_Str,Promt_str,Preset_str]

  • C:VDLG_Str：StringEdit 字段类型定义。
  • Prompt：分配给输入字段的文本。
  • Preset：预设文本。
  • 返回值：返回值是输入字符串。

文本显示：

系统生成文本显示。如果输入空字符串而不是文本，则文本字段也可用于定义空格。

[C:VDLG_Prompt,Prompt_str,Fieldheight_n]

  • C:VDLG_Prompt：文本显示类型定义。
  • Prompt：字段文本。
  • 字段高度：文本显示的高度。

IntComboBox:

提供一个可在其中输入整数的组合框。

[C:VDLG_IntCom,Prompt_str,[Entr_n],Sign_n/[Ind_n],0,0,AsVal_b]

  • C:VDLG_IntCom：IntComboBox 类型定义。
  • Prompt：分配给组合框的文本。
  • [Eintr]：包含可用列表项的元素数组（对于 IntComboBox，列表项必须是整数）。
  • Sign/[Ind]：此处，您可以选择使用"Sign"直接设置一个包含在列表中的约束值，或使用"Ind"在特定列表位置选择一个值作为约束值（列表中的第一个元素位于位置 0）。"Sign"和"[Ind]"是可选参数。
  • AsVal：如果可选参数"AsVal"已设置且不等于 0，则返回值变为输入值。否则，返回值是所选条目的索引。

IntEditComboBox:

提供一个可编辑的组合框，可在其中输入整数。请确保此处输入的值是整数。

[C:VDLG_IntComE,Prompt_str,[Entr_n],Sign_n/[Ind_n]]

  • 参见 IntComboBox
  • 返回值：返回值是输入字符串。

RealComboBox:

提供一个可在其中输入浮点数的组合框。

[C:VDLG_RealCom,Prompt_str,[Entr_r],Sign_r/[Ind_n],0,0,AsVal_b]

  • 参见 IntComboBox

RealEditComboBox:

提供一个可编辑的组合框，可在其中输入浮点数。

[C:VDLG_RealComE,Prompt_str,[Entr_r],Sign_r/[Ind_n]]

  • 参见 IntComboBox
  • 返回值：返回值是输入字符串。

StringComboBox:

提供一个可在其中输入字符串的组合框。

[C:VDLG_StrCom,Prompt_str,[Entr_str],Sign_str/[Ind_n],AsPos_n]

  • 参见 IntComboBox
  • AsPos：与 IntComboBox 相反，如果可选参数"AsPos"已设置且不等于 0，则此处的返回值表示所选字段的索引。否则，返回值是输入值。

StringEditComboBox:

提供一个可编辑的组合框，可在其中输入字符串。

[C:VDLG_StrCom,Prompt_str,[Entr_str],Sign_str/[Ind_n]]

  • 参见 IntComboBox
  • 返回值：返回值是输入字符串。
English Original

Dialog elements for the variable dialog

The following dialog elements are available for the variable dialogs:

Horizontal grouping:

The horizontal grouping provides a framework in which the individual dialog elements are lined up beside each other. Their position must always be defined by a vertical group, which means that all dialog elements in a horizontal grouping must be defined in a vertical group. A horizontal group is defined as follows:

[C:VDLG_HORZ, Caption_str, DistAbove_n, DistAfter_n, [Dialogelem]]

  • C: VDLG_HORZ: type definition for horizontal grouping.
  • Caption: the horizontal grouping's caption. If "Caption" is not an empty string, a frame will be drawn around the horizontal group.
  • DistAbove: distance from the next dialog element, above the horizontal group.
  • DistAfter: distance from the next dialog element, below the horizontal group. "DistAfter" and "DistAbove" are specified in pixels.
  • [Dialogelem]: element array used to define the dialog elements located in the horizontal grouping. This array must only contain elements of the type VDLG_Vert.

Vertical grouping:

The vertical grouping provides a framework in which the individual dialog elements are lined up below each other. The width of the dialog elements is defined by the vertical group. A vertical group is defined as follows:

[C:VDLG_Vert,Caption_str,[XStart_r,XEnd_r],XPart_r,[Diag],Marg_n]

  • C:VDLG_Vert: type definition for vertical grouping.
  • Caption: the vertical grouping's caption. The vertical grouping always has a frame drawn around it.
  • [XStart,XEnd]: XStart and XEnd define a factor (between 0 and 1) for the width of the vertical group relative to the width of the hierarchically superior dialog. They also define the X-position of the vertical group.
  • XPart: a factor between 0 and 1 that defines the ratio between the prompted value and the input value for the dialog fields (the text assigned to an input field is called the "prompt"). If XPart=-1, the prompt is positioned above the dialog element.
  • [Diag]: element array used to define the dialog elements in the vertical grouping.
  • Marg: an optional parameter that defines the displacement of the dialog elements relative to the edge of the vertical group. This means that the dialog elements contain the "Marg" (margin) distance from both the left-hand and right-hand edge of the vertical group.

RealEditFeld:

Provides an edit box in which you can enter a floating comma number.

[C:VDLG_Real,Prompt_str,Preset_r,res,res,Places_n]

  • C:VDLG_Real: RealEdit field type definition.
  • Prompt: text assigned to the input field.
  • Preset: Preset value.
  • res: a space (place) has been reserved here for two optional parameters which are not currently in use. However, these places must not be left empty in the definition (e.g. [C:VDLG_Real,Prompt,Preset,0,0,Places] would be a correct solution but not [C:VDLG_Real,Prompt,Preset,,,Places]).
  • Point: an optional parameter that defines the number of decimal places in the input field.
  • Return value: The return value is the input string.

IntEditFeld:

Provides an edit box in which you can enter a whole number.

[C:VDLG_Int,Promt_str,Preset_n]

  • C:VDLG_Int: IntEdit field type definition.
  • Prompt: text assigned to the input field.
  • Preset: Preset value.
  • Return value: The return value is the input string.

StringEditFeld:

Provides an edit box in which you can enter text.

[C:VDLG_Str,Promt_str,Preset_str]

  • C:VDLG_Str: StringEdit field type definition.
  • Prompt: text assigned to the input field.
  • Preset: Preset text.
  • Return value: The return value is the input string.

Text display:

The system generates a text display. If an empty string is entered instead of text, the text field can also be used to define a space.

[C:VDLG_Prompt,Prompt_str,Fieldheight_n]

  • C:VDLG_Prompt: Text display type definition.
  • Prompt: Field text.
  • Field height: height at which the text is displayed.

IntComboBox:

Provides a combo box in which you can enter a whole number.

[C:VDLG_IntCom,Prompt_str,[Entr_n],Sign_n/[Ind_n],0,0,AsVal_b]

  • C:VDLG_IntCom: IntComboBox type definition.
  • Prompt: text assigned to the combo box.
  • [Eintr]: element array with the available list items (in the case of an IntComboBox, the components must be whole numbers).
  • Sign/[Ind]: here, you have the option of using "Sign" to either set a constraint value, which is contained in the list, directly, or using "Ind" to select a value in a particular list position as a constraint value (the first element in the list is located at position 0)."Sign" and "[Ind]" are optional parameters.
  • AsVal: if the optional "AsVal" parameter has been set, and does not equal 0, the return value becomes the input. Otherwise, the return value is the index of the selected entry.

IntEditComboBox:

Provides a editable combo box in which you can enter a whole number. Please ensure that the values entered here are whole numbers.

[C:VDLG_IntComE,Prompt_str,[Entr_n],Sign_n/[Ind_n]]

  • see IntComboBox
  • Return value: The return value is the input string.

RealComboBox:

Provides a combo box in which you can enter a floating comma number.

[C:VDLG_RealCom,Prompt_str,[Entr_r],Sign_r/[Ind_n],0,0,AsVal_b]

  • see IntComboBox

RealEditComboBox:

Provides a editable combo box in which you can enter a floating comma number.

[C:VDLG_RealComE,Prompt_str,[Entr_r],Sign_r/[Ind_n]]

  • see IntComboBox
  • Return value: The return value is the input string.

StringComboBox:

Provides a combo box in which you can input a string.

[C:VDLG_StrCom,Prompt_str,[Entr_str],Sign_str/[Ind_n],AsPos_n]

  • see IntComboBox
  • AsPos: In contrast to the IntComboBox, the return value here represents the index of the selected field, if the optional parameter "AsPos" has been set and does not equal 0. Otherwise, the return value is the input.

StringEditComboBox:

Provides a editable combo box in which you can enter a string.

[C:VDLG_StrCom,Prompt_str,[Entr_str],Sign_str/[Ind_n]]

  • see IntComboBox
  • Return value: The return value is the input string.
