[LICENSE] 中的定义

变量名

描述

LOGGING

用于配置许可证使用日志记录的数字。

0: 不记录日志文件

1: 登录, 登出, 无许可证, 使用中和缺少权限

2: 登录, 登出, 无许可证

3: 登录, 登出, 无许可证, 缺少权限

在联网版本中，还显示用户的使用时间，以秒为单位。

LICENSELOGFILE

.log 文件用于生成许可证使用情况报告。

TIMEOUT

未使用的浮动许可证在网络中再次激活前的等待时间 [min]。

LICENSEMANAGEMENTSTATE

如果此参数设置为 1，则 KISSsoft 启动时会立即显示许可证对话框，且“常规”选项卡处于激活状态。这使用户可选择要用于 KISSsoft 的许可证。

表 2.6：LICENSE 环境中使用的变量表

English Original

Definitions in [LICENSE]

Variable name

Description

LOGGING

Number used to configure the logging of license usage.

0: no log file

1: Log in, Log out, No license, Used and Missing rights

2: Log in, Log out, No license

3: Log in, Log out, No license, Missing rights

In network versions, the user's uptime is also displayed , in seconds.

LICENSELOGFILE

.log file for generating reports of license usage.

TIMEOUT

Time [min] until an unused floating license is activated on the network again.

LICENSEMANAGEMENTSTATE

If this parameter is set to 1, the License dialog is displayed immediately, when KISSsoft is started, and the "General" tab is active. This enables the user to select the license with which KISSsoft is to be used.
