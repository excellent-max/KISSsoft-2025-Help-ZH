中文翻译

需考虑轴弯曲和齿向修形

为使用此选项，必须激活根据 ISO 6336-1 附录 E 的载荷分布计算（KHβ）。（它用于计算轴弯曲。）然后确定整个齿宽上侧隙变化 Δjt.i 最小的位置。（该位置记录在「齿向载荷因子」报告中。）对于载荷谱，确定所有载荷区间中找到的最小值。
如果 Δjt.i 为负值，则工况间隙减小。因此，这会改变最小工况间隙。（最大工况间隙保持不变，因为它代表无载荷状态。）如果 Δjt.i 为正值，则工况间隙增大。这会导致最大工况间隙发生变化。（最小工况间隙保持不变。）
为确定由弯曲引起的侧隙变化，仅考虑轴向平面内的分量，包括圆周方向的齿向修形分量。垂直于轴向平面的弯曲分量不予考虑，因为在受载情况下（如果 KHβ < 2），齿面在整个齿宽上贴合，因此不会引起任何侧隙变化。

English Original

Take into account shaft bending and flank line modifications

In order to use this option, the load distribution calculation (KHβ) according to ISO 6336-1, Annex E, must be activated. (It is used to calculate the shaft bending.) It then determines the position with the lowest backlash change Δjt.i across the facewidth. (This position is documented in the "Face load factor" report). For load spectra, the lowest value found in all load bins is determined.
If Δjt.i is negative, the operating clearance is reduced. This therefore changes the minimum operating clearance. (The maximum operating clearance remains unchanged, as it represents the load-free state.) If Δjt.i is positive, the operating clearance increases. This leads to a change in the maximum operating clearance. (The minimum operating clearance remains unchanged.)
To determine the backlash change caused by bending, only the components in the axial plane, including the component of the flank line modification in the peripheral direction, are taken into account. The bending component normal to the axial plane is not considered, as the flanks lie above the entire facewidth, under load (if KHβ < 2), and therefore do not cause any backlash change.
