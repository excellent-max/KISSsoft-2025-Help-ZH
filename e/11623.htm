中文翻译

使用载荷谱：为每个载荷工况分别定义轴、油和箱体温度

如果使用此选项，您可以为每个载荷工况分别输入轴、油和箱体温度。只有在 基本数据 选项卡中选择考虑载荷谱时，此设置才可用。可以通过在载荷谱下拉菜单中选择 自定义输入 来定义数据。在那里，可以在表格中手动定义数据，或者从文本文件中读取数据。文本文件中相应的列必须按如下所示定义。更多详情（参见"载荷谱"章）和（参见"载荷谱"章）。


contents: h T n Temp TempHousing TempOil

// 变量名说明（变量名不可更改）

// - h … 频率

// - T … 扭矩

// - n … 转速

// - Temp … 轴温度

// - TempHousing … 箱体温度

// - TempOil … 油温

0.1 1 1 70 70 70

0.2 0.9 1 65 65 65

0.5 0.8 1.1 50 50 50

0.2 0.7 1.1 50 50 50


English Original

Using load spectra: define shaft, oil and housing temperatures individually for each load case

If you use this option, you can input shaft, oil, and housing temperatures individually for each load case. This setting is available only if you choose to take load spectrum into account in the Basic data tab. The data can be defined by choosing Own input in the load spectrum drop down menu. In there, the data can be defined manually in a table or they can be read from a text file. Appropriate columns in the text file must be defined as shown below. For more details (see chapter Load spectra) and (see chapter Load spectra).


contents: h T n Temp TempHousing TempOil

// Explanation of variable names (variable names cannot be changed)

// - h … frequency

// - T … torque

// - n … rotating speed

// - Temp … shaft temperature

// - TempHousing … housing temperature

// - TempOil … oil temperature

0.1 1 1 70 70 70

0.2 0.9 1 65 65 65

0.5 0.8 1.1 50 50 50

0.2 0.7 1.1 50 50 50
