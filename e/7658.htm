系统设置

您可以使用系统元素中的任何设置选项：

  • kSoftAcceptChanges: 默认设置是：将从 KISSsoft 应用更改。如果设置为否，则不会应用任何更改。如果设置为询问，则关闭 KISSsoft 时系统会提示您确认是否应应用这些更改。
  • kSysKinematicFunc: 在运动学计算期间，您可以调用OnCalcTorque函数。该函数的标准实现会调用所有轴的轴承作用力计算。
  • kSysKinematicMode: 运动学可以迭代或非迭代方式计算。如果要包含效率，则必须选择扭矩迭代。仅当已输入转速公式时，才需要转速迭代。
  • kSys3DElements: 您可以显示图形元素或实体元素（需要 3D 内核）。图形元素生成更快，实体元素更详细。您还可以在此模块中显示导入的箱体。
  • project_name: 项目名称显示在 KISSsoft 计算报告中。
  • project_contract: 委托编号显示在 KISSsoft 计算报告中。
English Original

System settings

You can use any of the setting options in the System element:

  • kSoftAcceptChanges: default setting yes: the changes will be applied from KISSsoft. If the setting is no, nothing will be applied. If the setting is asked, you will be prompted to confirm whether the changes should be applied when KISSsoft is closed.
  • kSysKinematicFunc: you can call up the OnCalcTorque function while the kinematics is being calculated. The standard implementation of this function calls up the calculation of the bearing actions for all shafts.
  • kSysKinematicMode: kinematics can either be calculated iteratively or non-iteratively. Iterations for the torque must be selected if you want to include the efficiencies. Iterations for speeds are only necessary if formulae for speeds have been entered.
  • kSys3DElements: you can display either graphical elements or solid elements (3D kernel required). Graphical elements are generated more quickly, and solid elements are more detailed. You can also display an imported housing in this module.
  • project_name: the project name is displayed in the KISSsoft calculation reports.
  • project_contract: the commission number is displayed in the KISSsoft calculation reports.
