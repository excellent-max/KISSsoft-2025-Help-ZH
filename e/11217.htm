中文翻译

根据 DIN 5480 计算花键连接，采用齿面定心

在 齿面定心连接 中，齿面用于定心和旋转同步。齿面定心连接中轴和轮毂使用的齿根圆标称长度为理论齿根圆直径，按 hfP = 0.55*m 计算。所有没有 大径定心 或 小径定心 标注的基准齿廓均适用于齿面定心花键连接。

在涉及切削加工工艺的场合中，所用公差涵盖合适的最大可能齿根高（hfP = 0.65*m）以及齿根圆直径公差。齿槽齿根圆直径的公差带为 9H，轮毂齿根圆直径的公差带为 11a。

以下值适用于 齿面定心的花键:

  • 轮毂齿顶圆直径 da2，公差带 H11
  • 轴齿顶圆直径 da1，公差带 h11
  • 轮毂齿根圆直径 df2 的公差，按 Adf2 = (0.2*m+1.73*(Ae+TG)) 计算。
  • 轴齿根圆直径 df1 的公差，按机械加工计算：Adf1 = -(0.2*m+(1.73*As+TG))；冷滚压成形时：Adf1 = -0.76*m。

下面描述如何根据基础标准 DIN 5480-1 的表 5 计算根圆公差。

选择 计算→ 设置 → 通用，然后选择根圆公差是根据工艺过程（DIN 5480-16, 4.3.1）计算还是根据基础标准（DIN 5480-1, 表5）计算。

当根圆公差按照基础标准DIN 5480-1（表5）计算时，齿根牙型直径按第13页上的公式计算：

轴根部牙型直径: dFf1 = |da2| - 2*cFmin

轮毂齿根牙型直径：dFf2 = -(da1 + 2*cFmin);

cFmin 来自 DIN 5480-1 标准中的表 4。

如果分度圆直径或模数超出定义的范围，表中相邻的边值将被用作cFmin。

所计算的齿根直径公差带也在此处使用。

English Original

Calculating spline connections according to DIN 5480 with flank centering

In flank-centered connections, the flanks are used for centering and rotational synchronization. The nominal lengths of the root diameter used for the shaft and the hub in flank-centered connections are the theoretical root diameter calculated with hfP = 0.55*m. All reference profiles without the note Major diameter fit or Minor diameter fit are for flank-centered splined joints.

The allowances that apply where cutting manufacturing processes are involved cover the appropriate greatest possible dedendum (hfP=0.65*m) and the root diameter allowances. The tolerance field for the root diameter of the tooth space is 9H. For the hub root diameter it is 11a.

The following values apply for flank-centered splines:

  • Hub tip diameter da2 with tolerance field H11
  • Shaft tip diameter da1 with tolerance field h11
  • Allowance for the hub root diameter df2, calculated with Adf2 = (0.2*m+1.73*(Ae+TG)).
  • Allowance for the hub root diameter df1, calculated for machining: with Adf1 = -(0.2*m+(1.73*As+TG)). For cold roll forming: with Adf1 = -0.76*m.

This process for calculating root circle tolerances according to the base standard, DIN 5480-1, Table 5, is described below.

Select Calculations→ Settings → General and then select whether root circle tolerances are to be calculated according to the manufacturing process (DIN 5480-16, 4.3.1) or according to the base standard (DIN 5480-1, Table 5).

When the root circle tolerances are calculated according to the basic standard DIN 5480-1 (Table 5), the root form diameter is calculated as specified by the formulae on page 13:

Shaft root form diameter: dFf1 = |da2| - 2*cFmin

Hub root form diameter: dFf2 = -(da1 + 2*cFmin);

cFmin comes from Table 4 in the DIN 5480-1 standard.

If either the reference diameter or the module lie outside of the defined range, the adjacent edge value in the table is used as cFmin.

The tolerance band calculated for the root diameter is also used here.
