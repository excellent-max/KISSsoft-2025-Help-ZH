中文翻译

材料属性

在 材料属性 下拉列表中选择一个条目，以指定 KISSsoft 如何定义与强度相关的材料特性值。

  1. 参考直径 σB, σS, σW 和尺寸系数 K1(deff)： σB, σS, σW（参考直径值）取自数据库表 W000，并乘以尺寸系数 K1。
  2. 有效直径 σBeff, σSeff, 参考直径 σW 和尺寸系数 K1(deff): σBeff 和 σSeff 取决于尺寸，取自数据库表 KISS。 参考直径的 σW 取自数据库表 W000，并乘以尺寸系数 K1 。
  3. 有效直径 σBeff, σSeff, 参考直径 σW (K1=1): σBeff 和 σSeff 取决于尺寸，取自数据库表 KISS。 用于参考直径的 σW 取自数据库表 W000。尺寸系数 K 1 不予考虑。
  4. 有效直径 σBeff, σSeff，以及 σW 由 Rm 确定：σBeff 和 σSeff 取决于尺寸，取自数据库表 KISS。σW 根据标准由拉伸强度 Rm 确定。

根据计算方法的公式符号：

σB (DIN 743), Rm (FKM): 拉伸强度
σS (DIN 743), Rp (FKM): 屈服点
K1 (DIN 743), Kdm, Kdp, KdA (FKM): 尺寸系数

材料的数据，用于计算轴的强度，是从数据库中的值导出的，如下：

  • 疲劳极限因子（用于拉伸/压缩、弯曲等）直接从材料数据库中获取。在数据库中，这些值为每种计算方法定义。如果这些材料的数据已在计算方法中指定，则使用这些值。
  • 拉伸强度值根据特定EN标准中定义的直径存储在数据库中。使用原始直径从数据库中获取拉伸强度值，并用于计算。这种定义有效拉伸强度的方法非常可靠，可用于每种计算方法。其效果是每种计算方法都使用相同的数值。
  • 当您指定计算方法时，您可以决定依据相关标准中给出的要求使用材料数据库。然后，实际拉伸强度使用从试样直径（通常为 10 mm）的基础拉伸强度得出的厚度系数，按照标准（必须是 FKM 或 DIN。如果使用 Hänchen，这将触发错误消息）来定义。
  • 屈服点或应变极限是从数据库或标准中获取的，与拉伸强度的方式相同。
English Original

Material properties

Select an entry in the Material properties drop-down list to specify how KISSsoft is to define the material characteristic values that are relevant to strength:

  1. Reference diameters σB, σS, σW and size factor K1(deff): σB, σS, σW (reference diameter values) are taken form the database table W000 and multiplied by the size factor K1.
  2. Effective diameters σBeff, σSeff, reference diameter σW and size factor K1(deff): σBeff and σSeff are taken from the database table KISS dependent on size. σW for the reference diameter is taken from the database table W000 and multiplied by the size factor K1 .
  3. Effective diameters σBeff, σSeff, reference diameter σW (K1=1): σBeff and σSeff are taken from the database table KISS dependent on size. σW for the reference diameter is taken from the database table W000. The size factor K 1 is not taken into account.
  4. Effective diameters σBeff, σSeff, and σW determined from Rm: σBeff and σSeff are taken from the database table KISS dependent on size. σW is determined from the tensile strength Rm according to the standard.

Formula symbols according to the calculation method:

σB (DIN 743), Rm (FKM): Tensile strength
σS (DIN 743), Rp (FKM): Yield point
K1 (DIN 743), Kdm, Kdp, KdA (FKM): Size factors

The material's data, used to calculate the shaft strength, is derived from the values in the database as follows:

  • Fatigue limit factors (for tension/compression, bending, etc.) are taken directly from the material database. There, these values are defined for every calculation method. If data for these materials has been specified in the calculation method, it is these values that are used.
  • Tensile strength values are stored in the database according to their diameter as defined in the specific EN standard. The raw diameter is used to fetch the tensile strength value from the database and use it in the calculation. This method of defining the effective tensile strength is very reliable and can be used for every calculation method. It has the effect that the same values are used for each calculation method.
  • When you specify a calculation method, you can decide to use the material database on the basis of the requirements given in the relevant standard. Then, the real tensile strength is defined using the thickness factor taken from the base tensile strength of the sample diameter (normally 10 mm), according to the standard (which must be FKM or DIN. If you use Hänchen, this triggers an error message).
  • The yield point or strain limits are taken either from the database or from the standard, in the same way as for the tensile strength.
