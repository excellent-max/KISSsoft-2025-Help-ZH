中文翻译

轴的粗略尺寸设计

轴的粗略尺寸设计基于当量应力。许多选项会影响此功能的行为：

  1. 当量应力：轴材料所承受的最大当量应力。
  2. 仅更改圆柱直径：如果选择此选项，则保留构成外轮廓的圆柱长度，仅更改其直径。否则，KISSsoft 会同时设置圆柱的长度和直径。在这种情况下，内轮廓会被删除。
  3. 不删除截面 A-A 等：如果选择此选项，用于强度计算的用户自定义截面（A-A、B-B 等）不会被删除，并且 KISSsoft 会尝试在新设计中找到最关键的截面。
  4. 尺寸设计中考虑轴承：如果选择此选项，滚动轴承将按其所需额定寿命进行尺寸设计。
  5. 使轴直径与轴承孔径匹配：如果选择此选项，KISSsoft 会将最终圆柱直径向上取整，以匹配轴承的内径。
  6. 从模型获取轴承类型：如果选择此选项，则保留现有轴承。否则，您可以根据需要用特定轴承类型替换模型中的轴承。
  7. 必要时移动轴承：在对轴承进行尺寸设计时，可能会选中更大、更宽的轴承，从而覆盖相邻圆柱。如果选择此选项，则会移动轴承，使其不覆盖圆柱。

计算完成后，会显示旧的轴轮廓，以便您更轻松地比较新旧数据。

English Original

Rough sizing of shafts

The rough sizing of shafts is based on equivalent stress. A number of options affect the behavior of this functionality:

  1. Equivalent stress: the maximum equivalent stress to which the shaft material is subjected.
  2. Change only cylinder diameters: If this option is selected, the length of the cylinders that form the outer contour is retained and only their diameter is changed. Otherwise, KISSsoft sets both the length and diameter of the cylinders. In this case, the inner contour is deleted.
  3. Do not delete cross sections A-A etc.: If this option is selected, the user-defined cross sections for the strength calculation (A-A, B-B etc.) are deleted, and KISSsoft attempts to find the most critical cross sections in the new design.
  4. Consider bearings in sizing: If this option is selected, rolling bearings are sized according to their required rating life.
  5. Match shaft diameter to bearing bore: If this option is selected, KISSsoft rounds up the final cylinder diameter to match the bearing's internal diameter.
  6. Take bearing type from model: If this option is selected, existing bearings are retained. Otherwise, you can replace the bearings in the model with a specific bearing type as required.
  7. Move bearing if needed: When a bearing is being sized, it may happen that a larger, wider bearing is selected, and this covers the neighboring cylinder. If this option is selected, the bearing is moved so that it does not cover the cylinder.

Once the calculation has finished, the old shaft contour is displayed so you can compare the old and new data more easily.
