中文翻译

在表中添加变量

在 用户界面 表中插入变量的一种方法是：从 属性 对话框中选择一个变量，然后点击 工具栏 菜单中的相应图标。之后可以将变量作为文本（名称）、参考或表达式插入到表中。

变量作为文本

你可以直接在单元格中输入文本，或单击 文本 图标插入文本。为此，必须先在元素的 属性 窗口中选择变量，并预选表中的单元格，然后点击图标将所需值转移到单元格中。你也可以按住鼠标左键，将所需参数拖放到单元格中直接插入。默认设置是将变量中设定的值以表达式形式插入。单击 附加项 -> 设置，然后在 表格 选项卡中定义默认设置为文本、参考或表达式。

变量值作为参考

参考数据以红色显示。这些值在 属性 窗口中引用同一元素或不同元素中的另一个变量。可在此表中或在此窗口中更改此值。

你可以像添加文本一样向单元格添加引用值。为此，可在元素的属性中选择要插入的参数，然后在表中预选单元格。最后，单击 参考 图标，所需值即被传递到单元格。或者，可以按住鼠标右键，在相应的单元格中插入参数，此时会显示一个选择窗口，可在其中按需选择文本、参考或表达式。

变量值作为表达式

表达式仅以值的形式显示，不能在表中修改。要在单元格中插入表达式，请使用与前面 变量值作为参考 方法相同的步骤。

English Original

Adding variables to tables

One way of inserting variables in the UserInterface table is to select a variable from the Properties dialog and then click on the appropriate icon in the Toolbar menu. You can then insert the variables either as text (Name), as a reference, or as an expression.

Variable as text

You can either enter texts directly in the cell or click on the Text icon to insert them. To do so, you must first select the variable and preselect the cell in the table in an element's Properties window. Then click on the icon to transfer the value you want into the cell. You can also hold down the left-hand mouse button and drag and drop the required parameter, to insert it directly into the cell. The default setting is that the value set in the variable is inserted as an expression. Click on Extras -> Settings and then the Tables tab to define the default setting as a text, reference or expression.

Variable value as a reference

Referenced data is displayed in red. These values reference another variable of the same element, or a different element, in the Properties window. You can either change this value in the table or in the window.

You can add referenced values to cells in the same way as you add texts. To do so, you can select the parameter you want to insert, in an element's property. After this, the cell should be preselected in the table. Finally, click on the Reference icon. This transfers the required value to the cell. Alternatively, you can hold down the right-hand mouse button and insert the parameter in the appropriate cell. A selection window is displayed, in which you can select a text, reference or expression, as required.

Variable value as an expression

The expression is merely shown as a value and cannot be modified in the table. To insert an expression in the cell, use the same procedure as described in the previous method, Variable value as a reference.
