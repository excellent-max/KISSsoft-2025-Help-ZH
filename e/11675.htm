时域

分辨率： 时域结果的质量可以通过将分辨率设置为低、中、高或很高来调整。此选项不影响频域结果的质量。在强制响应分析中，生成时域数据的结束时间会被调整，以便能够捕获所有可能的激励，并为所有激励频率完成整周期的振动。为此确定一个基础激励频率 Ω0。它与所有激励频率的公因子相关。这意味着激励频率是 Ω0 的整数倍。因此，结束时间计算为

T_{end}=2\Pi /(\Omega _{0})

然后计算步长时间：

\Delta T=2\Pi /(R_{f}{\cdot }f_{max})

其中 Rf 是分辨率因子，根据分辨率级别进行调整（低：Rf = 10，中：Rf = 25，高：Rf = 50，很高：Rf = 100）。此外，fmax 是系统的最高激励频率。

绘图步长因子： 绘图步长因子 P 定义了用于生成输出的采样绘图数据的数量，方式如下：

  1. 根据用户设置的分辨率，计算用于计算时域结果的时间步长 ΔT。
  2. 用于计算和绘制结果的时间步长 ΔTplot 随后由 ΔTplot=P·ΔT 计算得出。
  3. 最大可能的时间步长 ΔTmax= 2π/(10·fmax)，它对应于最低分辨率。
  4. 如果时间步长为 ΔTplot > ΔTmax，则 ΔTmax 是用于计算和绘制结果的最终时间步长。

仅当分辨率不为“低”时，绘图步长因子才生效。

结束时间： 默认设置是，用于计算时域结果的结束时间 Tend 按上述方式计算。但是，如果需要特定的时间 Tend，或者默认结束时间很高、生成时域结果需要的时间过长，可以在此修改结束时间。

Time domain

Resolution: The quality of the results in the time domain can be adjusted by setting the resolution to low, medium, high or very high. This option does not affect the quality of the results in the frequency domain. In the forced response analysis, the end time for generating the time domain data is adjusted so that it can capture all possible excitations and complete full periods of the vibrations for all excitation frequencies. Plot step factor: The plot step factor P defines the number of sampling plot data for generating the outputs in the following manner:

  1. According to the resolution set by the user, the time step ΔT for calculating the results in the time domain is calculated.
  2. The time step ΔTplot for calculating and plotting the results is then calculated from ΔTplot=P·ΔT.
  3. The highest possible time step, ΔTmax= 2π/(10·fmax), which corresponds to the lowest resolution, is calculated.
  4. If the time step is ΔTplot > ΔTmax, ΔTmax is the final time step for calculating and plotting the results.

The plot step factor is only active if the resolution is not "low".

End time: The default setting is that end time Tend, which is used to calculate the time domain results, is calculated as described above. However, if a specific time Tend is required or if the default end time is high and too much time is needed to generate the time domain results, the end time can be modified here.
