中文翻译

配置张紧轮

此处您可以选择以下任一选项：

  • 不带张紧轮
  • 张紧轮位于内侧
  • 张紧轮位于外侧

如果选择了内侧/外侧张紧轮，则可以输入锥形弹簧垫圈直径和张紧轮的位置 (x/y)。在 配置 选项卡中，可以使用鼠标交互式定位张紧轮（x 和 y 值显示在状态栏中）。

English Original

Configuring tensioning pulleys

Here, you can select either:

  • Without tensioning pulley
  • Tensioning pulley inside
  • Tensioning pulley outside

If you selected an inside/outside tensioning pulley, you can input the conical spring washer diameter and the position (x/y) of the tensioning pulley. In the Configuration tab, you can position the tensioning pulley interactively using the mouse (the x and y values are displayed in the status bar).
