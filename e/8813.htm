中文翻译

计算插齿刀

您可以为现有的齿形计算插齿刀。为此，请输入插齿刀的齿数和制造中心距。中心距对使用展成法创建齿形的可行性有显著影响。请尝试多种不同的数值以找到最佳值。

计算出的插齿刀随后将用作再次计算圆柱齿轮的刀具。通过比较两种齿形，您可以评估该齿形可在多大程度上通过展成法制造。单击 刀具 以显示插齿刀。

English Original

Calculating a pinion type cutter

You can calculate a pinion type cutter for an existing tooth form. To do this, enter the number of teeth on the pinion type cutter and the manufacturing center distance. The center distance has a significant effect on the practicability of creating a tooth form using the generation process. Try out a number of different values to find the best one.

The calculated pinion type cutter is then used as a tool for calculating the cylindrical gear again. By comparing the two tooth forms you can then evaluate the extent to which the tooth form can be manufactured using the generation process. Click Tool to display the pinion type cutter.
