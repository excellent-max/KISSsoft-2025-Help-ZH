中文翻译

计算 2D FEM 齿根应力

这种特殊计算可用于在平面应力或平面应变状态的假设下，使用 FEM 方法计算齿轮轮齿齿根处的应力。

以下输入字段可用：

  1. 选择齿轮副/选择齿轮，用于要分析的齿轮/齿轮副。齿轮副选择选项仅在具有多个齿轮副的模块中可用（例如三齿轮轮系）。
  2. 边界条件，齿轮分段（用于 FEM 分析的固定条件）。这可以是齿轮的内径或外径（对于外齿轮或内齿轮）、选择用于分析的齿轮分段的侧面，或内径或外径且在侧面上滑动。最后一种变体（直径固定，侧面滑动）通常是最好的。
  3. FE 模型的网格密度可以使用七个网格密度级别来定义。第一个级别表示粗网格，最后一个级别表示非常细的网格。随着网格密度的增加，FE 模型中的齿形表示得更准确。这对产生的应力有显著影响。我们建议在设计的前期阶段使用级别 1-4，在最终应力评估中使用级别 5-7。
  4. 应力准则（搜索最大应力时使用的应力类型）。这可以是最大主应力或 Von Mises 应力。由于该计算用于分析齿根弯曲应力，我们建议使用最大主应力。
  5. 假设 用于 2D 建模 （针对平面状态）。在此，用户可以选择平面应力或平面应变状态。对于标准齿轮，我们建议选择平面应变状态。平面应力适用于齿宽非常小的齿轮（齿宽小于齿厚）。
  6. 齿数：要包含在 FE 模型中的齿数。

在 FE 分析之前，计算载荷并施加到中间齿接触点处的力作用角上。如果选择输入施加的力数据选项，用户可以手动输入载荷、力作用直径和力作用角。无论建模了多少个齿，载荷只施加到 FE 模型中的中间齿上。因此，该齿的网格比其周围任何建模齿的网格更细（尽管在高网格密度级别下，网格密度的差异相当小）。软件会自动在中间齿的缺口周围和齿根区域生成更细的网格，以便更准确地计算这些区域周围的应力。

在斜齿轮的 2D 分析中，根据 ISO 6336-3 计算并使用当量直齿轮。当量齿轮可以随时从 KISSsoft 导出（文件 > 导出）。

FEM 结果在 KISSsoft 结果窗口和报告中提供。单击图形 > FEM > 2D 结果（2D 齿根应力） > 齿根区域应力（中间截面），以可视化齿轮中间截面从齿根到力作用点的应力分布（主应力或 von Mises 当量应力，取决于用户的选择）。单击图形 > FEM > 3D FEM 结果，以查看齿轮建模的横截面。您还可以显示其他结果，例如位移或主应力。

English Original

Calculating 2D FEM tooth root stress

This special calculation can be used to calculate the stresses at the root of a gear tooth using the FEM method under the assumption of a plane stress or plane strain state.

The following input fields are available:

  1. Select gear pair/Select gear for the gear/gear pair to be analyzed. The gear pair selection option is only available in modules with multiple gear pairs (e.g. three gears train).
  2. Boundary condition, gear segment (fixation condition for the FEM analysis). This can either be the internal or external diameter of the gear (for external or internal gears), the sides of the gear segment selected for the analysis, or the inside or external diameter with sliding on the side. The last variant (diameter fixed, sliding sides) is usually the best.
  3. The mesh density of the FE model can be defined using seven mesh density levels. The first level represents a coarse mesh and the last level represents a very fine mesh. The tooth form in the FE model is represented more accurately as the mesh density increases. This has significant impact on the resulting stresses. We recommended that levels 1-4 are used for the first stages of the design and levels 5-7 for the final stress evaluation.
  4. Stress criterion (stress type to be used when searching for maximum stress). This can be either the maximum principal stress or the Von Mises stress. As the calculation is used to analyze the tooth root bending stress, we recommend you use the maximum principal stress.
  5. Assumption for 2D modeling for the plane state. Here, the user can select either a plane stress or a plain strain state. We recommend you select a plain strain state for standard gears. Plane stress is suitable for gears with a very small facewidth (facewidth smaller than tooth thickness).
  6. Number of teeth to be included in the FE model.

Before the FE analysis, the load is calculated and applied to the force application angle at the point of contact of the middle tooth. If the Input application of force data option is selected, the user can enter the load, the force application diameter and the force application angle manually. Load is only applied to the middle tooth in the FE model, no matter how many teeth are being modeled. Therefore the mesh of this tooth is finer than that of any modelled teeth around it (although the difference on the mesh density is quite small for high mesh density levels). The software automatically generates a finer mesh around notches and at the root region of the middle tooth, to provide a more accurate calculation of the stresses around these areas.

In the 2D analysis for helical gears, the equivalent spur gear is calculated and used, according to ISO 6336-3. The equivalent gear can be exported from KISSsoft at any time (File > Export).

The FEM results are provided at the KISSsoft result window and in the report. Click on Graphic > FEM > 2D Results (2D Root Stress) > Stress at root area (middle section) to visualize the stress distribution (principal stress or von Mises equivalent stress, depending on the user selection) at the middle section of the gear from the tooth root to the point of force application. Click on Graphic > FEM > 3D FEM Results to view the modeled cross section of the gear. You can also display other results, such as the displacements or principal stresses.
