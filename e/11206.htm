条件 II

此处，各齿轮的基准齿廓 h*aP 可以逐步变化。齿根高 h*fP 由到配对齿轮所需的顶隙确定（h*fP2 - H*aP1）。如果此值不变，则每个变体中的顶隙值将与「基本」选项卡中输入的值相同。
您还可以指定始终自动设置最大可能的齿顶倒圆角半径 ϱ*fP。

English Original

Conditions II

Here, the reference profile h*aP of the individual gears can be varied step-by-step The dedendum h*fP is determined via the required tip clearance to the counter gear (h*fP2 - H*aP 1). If this value is not changed, the tip clearance value in every variant will be the same as the value entered in the Basic tab.
You can also specify that the maximum possible tip rounding radius, ϱ*fP , is always set automatically.
