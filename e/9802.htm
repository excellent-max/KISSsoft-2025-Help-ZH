中文翻译

服务器上的安装

  1. 将 KISSsoft 加密狗/MxNet 安装目录复制到服务器上。
  2. 在服务器上启动 MxNet32。您将在任务栏中看到一个加密狗图标。
  3. 双击此图标以启动用户界面。
  4. 现在输入 应用程序：KISSsoft 和任何扩展名为 .mx 的文件作为 服务器文件。客户端必须对该文件具有读写访问权限。现在单击 新建条目 添加此条目。
  5. 然后单击 活动用户 按钮查看谁在使用 KISSsoft。您还可以重新激活已使用的许可证。
English Original

Installation on the server

  1. Copy the KISSsoft dongle/MxNet installation directory onto a server.
  2. Start MxNet32 on the server. You will see a dongle icon in the task bar.
  3. Double-click this icon to start the user interface.
  4. Now enter Application: KISSsoft and any file with the file extension .mx as the server file. The clients must have both read and write access to this file. Now click New Entry to add this entry.
  5. Then click the Active Users button to check who is using KISSsoft. You can also reactivate a license that has already been used.
