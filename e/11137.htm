中文翻译

计算过程

要对带有坎贝尔图的轴系统进行计算，请在 KISSsys 中点击「kSoftSystem」计算单元。右键单击该单元，然后选择「CampbellDiagram」选项。坎贝尔图对话框包含所有必要条目。可以从系统中包含带已定义边界条件联轴器的轴列表中选择用于计算的参考轴。在此对话框中，还可以选择计算齿轮的计算方法以及参考轴的速度范围。可以定义各种不同速度以及要纳入坎贝尔图中的固有频率数量。最后，可以选择要在坎贝尔图中绘制的共振曲线数量。计算首先对参考轴的每个速度进行系统运动分析。更新所有轴的速度，然后对每个速度进行模态分析。

English Original

Calculation procedure

To run a calculation for shaft systems with a Campbell diagram, click on the kSoftSystem calculation element in KISSsys. Right-click on the element, and then select the CampbellDiagram option. The Campbell diagram dialog has all the necessary entries. You can select the reference shaft for the calculation from a list of shafts in the system that include a coupling with a defined boundary condition. In this dialog, you can also select the calculation method for calculating the gears and the speed range of the reference shaft. You can define the various different speeds, together with the number of eigenfrequencies, that are to be taken into account in the Campbell diagram. Finally, you can select the number of resonance curves that are to be drawn in the Campbell diagram. The calculation starts with a kinematic analysis of the system for each speed of the reference shaft. The speeds of all of the shafts are updated and then a modal analysis is performed for each of these speeds.
