中文翻译

消息输出

程序窗口下部有一个消息输出窗口。来自 KISSsoft 计算的错误消息和警告显示在 消息 下。来自 KISSsoft 的调用记录在 KISSsoft 下，因此通常不需要此视图。

与 KISSsoft 一样，在下方程序窗口中会看到一个信息选项卡。如果存在有关特定功能的信息，则会显示在此选项卡中。

English Original

Message output

There is an output window for messages in the lower part of the program window. Error messages and warnings from KISSsoft calculations are displayed under Messages. Calls by KISSsoft are reported under KISSsoft, so this view is usually not required.

In the lower program window, as in KISSsoft, you will see an information tab. If information about a particular function is present, it is displayed in this tab.
