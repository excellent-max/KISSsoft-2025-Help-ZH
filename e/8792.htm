用插齿刀展成圆柱齿轮

如果要计算使用插齿工艺制造的齿轮的齿形，则必须定义插齿刀的几何形状。

所需输入数据：

  • 插齿刀的参考齿廓
    在插齿刀的参考齿廓中，当 x0 + xE = 0 时，交换工作齿轮参考齿廓中所用的齿顶和齿根值。在其他情况下，需要在 x0 处输入位移。
  • Z0 插齿刀的齿数
  • x0 插齿刀的变位系数
    （但是，如果 x0 未知，可以使用圆柱齿轮计算根据齿顶圆直径或公法线长度来确定变位系数（参见"变位系数"章））
  • 或者确定小齿轮齿顶倒角的长度 s，或小齿轮齿顶圆角的半径 r（见图 15.74）

English Original

Generating a cylindrical gear with a pinion type cutter

If you want to calculate the tooth form of gears manufactured using a shaping process you must define the geometry of the pinion type cutter.

Required input data:

  • Reference profile of the pinion type cutter
    In the reference profile of the pinion type cutter, swap the values of the tip and root used in the reference profile of the work gear at x0 + xE = 0. In other cases, you need to input a displacement at x0.
  • Z0 number of teeth on the pinion type cutter
  • x0 profile shift for the pinion type cutter
    (however, if x0 not known, you can use the cylindrical gear calculation to define the profile shift from the tip diameter or the base tangent length (see chapter Profile shift coefficient))
  • or determine the length of the chamfer on the pinion tooth tip s or the radius of the rounding r on the pinion tooth tip (see Figure 15.74)
