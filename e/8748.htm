中文翻译

齿根圆直径余量

齿根圆直径余量通常由齿厚余量计算得出。在齿轮切削过程中，齿轮侧隙是通过减小刀具的加工距离（中心距）来产生的。这就是齿根圆直径余量取决于齿厚余量的原因。

在特殊情况下会使用不同的制造工艺，例如对于烧结齿轮或挤出塑料齿轮。用户可以随后输入自己的齿根圆直径余量。

单击“转换”按钮以指定最小和最大齿根圆直径，余量将从这些直径计算得出。单击“加号”按钮以指定符合 ISO 286 的公差带。这将定义余量，这些余量只需在输入界面中输入一次。公差等级不会保存以供后续使用。

English Original

Root diameter allowances

Root diameter allowances are usually calculated from the tooth thickness allowances. In the gear cutting process, the gear backlash is produced by reducing the manufacturing distance of the tool. This is why the root diameter allowances depend on the tooth thickness allowances.

A different manufacturing process is used in special cases, e.g. for sintered gears or extruded plastic gears. The user can then input their own root diameter allowances.

Click the Convert button to specify the minimum and maximum root diameter from which the allowances are to be calculated. Click the Plus button to specify a tolerance field according to ISO 286. This defines the allowances, which only need to be entered once in the input screen. The tolerance class is not saved for later use.
