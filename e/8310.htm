中文翻译

材料

您可以从此选择列表中选择轴材料，从而为每根单独的轴指定特定材料。如果将此功能与元素树中的 连接 元素一起使用，则可以生成由不同材料制成的轴。

English Original

Material

You can select a shaft material from this selection list and therefore assign a specific material to each individual shaft. If you use this function together with the Connections element in the Element Tree, you can generate shafts made of different materials.
