中文翻译

计算过程

为了计算系统动力学，首先将一个 KISSsys kSoftSystem 计算导入模型。右键单击，然后在上下文菜单中选择“模态分析”，以显示一个对话框，其中可以设置各种参数用于计算。必须定义要计算的特征频率数量，指定仅包含扭转振动或所有振动类型，以及是否考虑陀螺效应（不适用于扭转振动），并选择用于计算齿接触刚度的计算方法。最后选项的可用选择为：

  • 齿接触刚度，如在 ISO 6336 中所定义的。
  • 使用 KISSsoft 接触分析（CA）算法，其中在齿轮连接中进行全接触分析。如果 KISSsoft 没有针对特定齿轮副类型的接触分析计算，或该齿轮副不传递功率，则使用 ISO 6336 过程对该特定副进行处理。
  • 无限：假设齿接触刚度为无限。选择此选项以检查极限条件。
  • 忽略：齿接触刚度假设为零，因此振动轴之间没有连接（每根轴独立振动）。

上述所有动态计算属性也可在计算的“属性”窗口中设置（右键单击“计算”并选择“属性”窗口）。

English Original

Calculation procedure

To calculate the system dynamics, first import a KISSsys kSoftSystem calculation into the model. Right-click and then select "Modal analysis" in the context menu, to display a dialog in which you can set various parameters for the calculation. You must define the number of eigenfrequencies to be calculated, specify whether only torsional or all vibration types are to be included, and whether gyroscopic effects are to be taken into account (does not apply to torsional vibrations), and select which calculation method is to be used to calculate tooth contact stiffness. The following selections are available for this last option:

  • Tooth contact stiffness as defined in ISO 6336
  • Using the KISSsoft Contact Analysis (CA) algorithm, where a full contact analysis is performed in the gear connections. If KISSsoft does not have a contact analysis calculation for a particular gear pair type, or if the gear pair does not transfer power, the ISO 6336 process is used for that specific pair.
  • Infinite: the tooth contact stiffness is assumed to be infinite. Select this option if you want to check limiting conditions.
  • Ignore: the tooth contact stiffness is assumed to be zero, and there is therefore no connection between the vibrating shafts (each shaft is vibrating independently).

All the dynamic calculation properties mentioned above are also available in the calculation's Properties window (right-click on Calculation and select the Properties window).
