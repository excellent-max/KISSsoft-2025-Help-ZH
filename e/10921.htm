中文翻译

摩擦力矩，密封件

定义密封件摩擦力矩的确定方式：

  • SKF 主目录根据所选计算方法
    • 根据 SKF 主目录 4000/IV T DE:1994
      您可以在 SKF 目录中找到已集成在 KISSsoft 软件中的、适用于您轴承中所用密封件类型的数值。如果 KISSsoft 系统在轴承标签中发现已知的密封件标签，它将使用目录中列出的系数计算磨削密封件的摩擦力矩。否则，摩擦力矩将设置为零。
    • 根据 SKF 主目录 17000/1 EN:2018
      您可以在 SKF 目录中找到已集成在 KISSsoft 软件中的、适用于您轴承中所用密封件类型的数值。如果 KISSsoft 系统在轴承标签中发现已知的密封件标签，它将使用目录中列出的系数计算磨削密封件的摩擦力矩。否则，摩擦力矩将设置为零。
      在 KISSsoft 中，配合表面的直径按公式 ds = d + (D - d) * 0.2 计算。
  • 根据 ISO/TR 13593:1999（Viton M 密封件），Mseal 按以下公式计算：Mseal = 3,736*10^-3*dsh；Mseal 单位为 Nm，dsh 为轴径，单位 mm。
  • 根据 ISO/TR 13593:1999（Buna N 密封件），Mseal 按以下公式计算：Mseal = 2,429*10^-3*dsh；Mseal 单位为 Nm，dsh 为轴径，单位 mm。
English Original

Moment of friction, seals

Defines how the moment of friction is to be defined for seals:

  • SKF main catalog according to selected calculation method
    • According to SKF main catalog 4000/IV T DE:1994
      You will find values from the SKF catalog for the seal types used in your bearings integrated in the KISSsoft software. If the KISSsoft system finds a familiar seal label in the bearing label, it calculates the moment of friction for a grinding seal using the coefficients listed in the catalog. Otherwise, the moment of friction is set to zero.
    • According to SKF main catalog 17000/1 EN:2018
      You will find values from the SKF catalog for the seal types used in your bearings integrated in the KISSsoft software. If the KISSsoft system finds a familiar seal label in the bearing label, it calculates the moment of friction for a grinding seal using the coefficients listed in the catalog. Otherwise, the moment of friction is set to zero.
      In KISSsoft, the diameter of the mating surface is calculated with the formula ds = d + (D - d) * 0.2
  • according to ISO/TR 13593:1999 Viton Mseal, this diameter is calculated with the formula: Mseal = 3,736*10^-3*dsh; Mseal in Nm, dsh Shaft diameter in mm
  • according to ISO/TR 13593:1999 Buna N Mseal this diameter is calculated with the formula: Mseal = 2,429*10^-3*dsh; Mseal in Nm, dsh Shaft diameter in mm
