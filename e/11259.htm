精确尺寸设计

加载“滚动轴承 ISO/TS 16281”模块后，单击精确尺寸设计选项 打开一个窗口，在该窗口中您可以对滚动轴承的内部几何进行精确尺寸设计。与齿轮精确尺寸设计（参见"精确尺寸设计宏观几何"章）的方式相同，您可以改变几何参数以生成大量不同的轴承变体。您在轴承数据中选择的类型现在决定了有哪些具体的输入参数可用（例如，滚动体数量、径向游隙、曲率比等）。该轴承类型的任何现有轴承数据都会直接传递到精确尺寸设计函数。

您需要一定经验才能有效使用精确尺寸设计函数。这是因为该过程可能会生成内部几何既不符合当前适用标准、也不符合实际已制造滚动轴承的轴承变体。系统确实会检查您输入的某些参数，并在遇到不可信数据时显示警告消息。

您可以在窗口中第一个选项卡的上三分之一处输入滚动轴承的外部尺寸。中间三分之一是输入内部轴承几何参数（根据轴承类型）的位置。在每种情况下，参数变体的数量由起始值、终值和间隔确定（例如：如果涉及 11 到 15 个滚动体，且间隔设置为两个滚动体，则程序恰好计算三个变体，前提是所有其他间隔都设置为零）。

此选项卡的下三分之一是定义系统生成的每个滚动轴承变体必须满足的边界条件的位置。您可以将滚动体的密度设置为 0% 到 100% 之间的一个数字（如果设置为 100%，轴承将拥有如此多的此类滚动体，以至于它们会沿整个工作节圆长度相互接触）。您在此输入的最小壁厚适用于内外圈滚道。任何不满足边界条件的轴承变体将在其余计算中被忽略。

现在，单击窗口底部区域的“计算”按钮以生成轴承变体。系统现在计算详细的内部几何以及额定载荷和额定寿命。在这种情况下，载荷数据取自“滚动轴承 ISO/TS 16281”模块中的“额定”选项卡。进度条显示计算的进行情况。

此处确定的轴承变体随后显示在精确尺寸设计窗口中“结果”选项卡的表格中。这些结果也可以在报告中输出。轴承变体还以图形的形式显示在“图形”选项卡中（与齿轮精确尺寸设计函数的结果类似（参见"图形"章））。在这里，您可以沿水平和垂直轴显示不同参数的值。您还可以使用颜色标度使结果更易于理解。

English Original

Fine sizing

After you have loaded the "Roller bearing ISO/TS 16281" module, click on the Fine sizing option to open a window in which you can perform fine sizing on the internal geometry of rolling bearings. In the same way as for fine sizing gears (see chapter Fine sizing macrogeometry), you can vary the geometry parameters to generate a multitude of different bearing variants. The type you selected in the bearing data now determines which specific input parameters (for example, number of rolling bodies, radial clearance, osculation etc.) are available. Any existing bearing data for the bearing type is transferred directly to the fine sizing function.

You need a certain amount of experience before you can use the fine sizing function effectively. This is because the process may generate bearing variants whose internal geometry does not match either the currently applicable standards or roller bearings that have actually been manufactured. The system does check some of the parameters you input, and displays warning messages when it encounters implausible data.

You input the external dimensions of the roller bearing in the upper third of the first tab in the window. The middle third is where you input the parameters for the internal bearing geometry (according to the bearing type). In each case, the number of variants for the parameters are determined from the start values, the final values and the intervals (for example: if between 11 and 15 rolling bodies are involved, and the interval is set to two rolling bodies, the program calculates exactly three variants, if all the other intervals are set to zero).

The lower third of this tab is where you define the boundary conditions that each of the rolling bearing variants the system generates has to fulfill. You can set the density of the rolling bodies to a number between 0% and 100% (if you set it to 100%, the bearing will have so many rolling bodies of this type that they will touch each other along the whole length of the operating pitch circle). The minimum wall thicknesses you enter here apply to the inner and outer ring races. Any bearing variants that fail to meet the boundary conditions are ignored in the rest of the calculation.

Now, click on the "Calculate" button in the bottom area of the window to generate the bearing variants. The system now calculates the detailed inner geometry and the load rating and rating life. In this case, the load data is taken from the "Rating" tab in the "Rolling bearing ISO/TS 16281" module. A progress bar shows you how the calculation is progressing.

The bearing variants determined here are then displayed in a table in the "Results" tab in the Fine sizing window. These results can also be output in the report. The bearing variants are also displayed as a graphic in the "Graphic" tab (in a similar way to the results of the Gear fine sizing function (see chapter Graphics)). Here you can display the values of different parameters along the horizontal and vertical axes. You can also use a color scale to make the results easier to understand.
