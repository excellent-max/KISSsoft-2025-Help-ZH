中文翻译

计算热安全工作转速极限

热安全工作转速由热参考转速通过转速比导出。nθ = fn * nθr

在从该方程迭代得到转速比之前，必须先计算载荷和润滑参数：

KL * fn5/3 + KP * fn = 1

载荷参数 KL：

KL = 10-6 * (π/30) * nθr*10-7 * (f0r * n2/3 * nθr2/3 * dm3)/Q

润滑膜参数 KP：

KP = 10-6 * (π/30) * nθr*(f1 * P1 * dm)/Q

nθr：热名义转速 [rpm]
f0：取自 DIN 732 表 A.1 的摩擦系数 [-]
f1：取自 DIN 732 表 A.1 的摩擦系数 [-]
n：润滑剂粘度 [mm2/s]
dm：滚动轴承平均直径 [mm]
P1：参考载荷 [N]
Q：总散热量 [kW]

English Original

Calculating the thermally safe operating speed limit

The thermally safe operating speed is derived from the thermal reference speed, using the speed ratio. nθ = fn * nθr

The load and lubrication parameters must be calculated before the speed ratio can be iterated from this equation:

KL * fn5/3 + KP * fn = 1

Load parameter KL:

KL = 10-6 * (π/30) * nθr*10-7 * (f0r * n2/3 * nθr2/3 * dm3)/Q

Lubricant film parameter KP:

KP = 10-6 * (π/30) * nθr*(f1 * P1 * dm)/Q

nθr: thermal nominal speed [rpm]
f0: Coefficient of friction from Table A.1, DIN 732 [-]
f1: Coefficient of friction from Table A.1, DIN 732 [-]
n: Lubricant viscosity [mm2/s]
dm: average rolling bearing diameter [mm]
P1: Reference load [N]
Q: Total dissipated heat flows [kW]
