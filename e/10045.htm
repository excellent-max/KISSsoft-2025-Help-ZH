同步带标准

  • 文件名：数据库条目引用外部表（见外部表一章）。同步带标准的数据表以 Z091-???.dat 开头。
  • 计算方法：
    • 1）“普通”同步带（RPP）
    • 2) GT类型（PolyChain）
    • 3) AT类型（Brecoflex）
    • 4) PG类型（PowerGrip）

区别：

  • 带钢绳的同步带特殊计算（方法3）
  • 计算工况系数：增速比的特殊因子以相加（方法 1、2 或 4）或以相乘（方法 3）方式计入
  • 在较大传动比下提供更高性能的附加性能表（方法 2）
  • 皮带预张力计算方法：
    • 1）按圆周力的百分比（%）计算；松弛量 = 张紧长度的 1/50
    • 2）按最大允许圆周力的百分比（%）计算；松弛量 = 张紧长度的 1/50
    • 3) 按（工况系数×功率(W)/参考圆圆周速度 (m/s)）的百分比；松弛量 = 张紧长度的 1/64（根据 DAYCO RPP Panther）
    • 4）按圆周力的百分比（%）计算；松弛量 = 张紧长度的 1/64
  • 功率表 b 的名义范围： [mm] 皮带宽度，对应存储在文件中的性能数据（参见文件名）。
  • 皮带预张力系数 f: 0 ... 1.0 (% 因子用于计算皮带预张力系数)
  • 最大带速 vmax: [m/s]
  • 运行加数 Fs： 无影响
  • 节距 p: [mm] 同步带节距
  • 弹性 E：[N] 弹性 = 使皮带长度加倍的力（公称宽度）。如果不知道此值，请输入 0 作为参考值（在这种情况下，弯曲试验时弹性将被忽略）。
  • 应变 ε：[%] 沿带总长度的应变
  • 单位长度重量 q: [kg/m/mm] 每米长度和每毫米宽度

English Original

Toothed belt standard

  • File name: The database entries refer to external tables (see chapter External tables). Tables for the toothed belt standard begin with Z091-???.dat.
  • Calculation method:
    • 1)"normal" toothed belts (RPP)
    • 2) GT types (PolyChain)
    • 3) AT types (Brecoflex)
    • 4) PG types (PowerGrip)

Differences:

  • Special calculation for toothed belts with integrated steel rope (Method 3)
  • Calculating the operating factor: the special factor for the speed increasing ratio is added (Method 1, 2 or 4) or multiplied (Method 3)
  • Additional performance table for higher performance at greater conversions (Method 2)
  • Calculation method for belt pre-tension:
    • 1) in % of the circumferential force; slack = 1/50 of the tension length
    • 2) in % of the maximum permitted circumferential force; slack = 1/50 of the tension length
    • 3) in % of (operating factor*power(W)/circumferential speed reference circle (m/s)) (according to DAYCO RPP Panther) Slack = 1/64 of the tension length
    • 4) in % of the circumferential force; Slack = 1/64 of the tension length
  • Nominal range for power table b: [mm] belt width, which corresponds to the performance data stored in the file (see file name).
  • Coefficient for belt pre-tension f: 0 ... 1.0 (% factor for calculating the belt pre-tension coefficient)
  • Maximum belt speed vmax: [m/s]
  • Summand for operation Fs: No influence
  • Pitch p: [mm] pitch of the toothed belt
  • Elasticity E: [N] Elasticity = force that doubles the length of a belt (with nominal width). If you do not know this value, enter 0 as the guide value (in this case the elasticity is ignored when the bending test is performed).
  • Strain ε: [%] strain along the total length of the belt
  • Weight per length q: [kg/m/mm] per meter length and millimeter width
