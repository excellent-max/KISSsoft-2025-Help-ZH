中文翻译

显示图形

在 数据 变量中定义图形后，您可以使用图形元素的 显示 功能显示该图形。之后您可以通过选择菜单或图形窗口中的 刷新 功能进行更新。

English Original

Displaying graphics

After you have defined the graphic in the data variable, you can use the graphical element's Show function to display the graphic. You can update it later by selecting the Refresh function in the menu or the graphics window.
