中文翻译

齿厚变位系数

此因子仅应在特殊情况下使用。因子 xs 与锥齿轮的处理方式相同，通过 ΔAs = 2 * xs * mn 修改齿厚。始终满足 xs2 = -xs1，因此输入 xs1 时顶隙保持不变。对于正常应用，xs1 的输入值 应在区间内 -0.1 ≤ xs1 ≤ +0.1。

此因子可用于以下情况：例如当蜗杆显著比齿轮更硬时，会导致齿轮在运行过程中磨损。当齿轮齿因磨损而变得越来越薄并最终断裂时，齿轮装置失效。例如用 xs1 = -0.1 修改蜗杆的齿厚，会使蜗轮齿更厚，从而显著延长使用寿命。

English Original

Tooth thickness modification coefficient

This factor should only be used in special cases. The factor xs modifies the tooth thickness with ΔAs = 2 * xs * mn, as for bevel gears. xs2 = -xs1 always applies, so that the clearance remains unchanged if you input xs1. For normal applications, the values for xs1 are entered in intervals of -0.1 ≤ xs1 ≤ +0.1.

This factor can be used, for example, if the worm is significantly harder than the gear, which causes the gear to wear during operation. The gear unit fails when the gear tooth breaks because it has become increasingly thinner, due to wear. Modifying the worm's tooth thickness with e.g. xs1 = -0.1 will make the worm wheel tooth thicker. This will result in a much longer service life.
