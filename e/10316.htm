起始和结束块

KISSsoft 中的报告通常生成时包含一个起始块和一个结束块。可自行定义这些起始和结束块。起始块和结束块在模板文件中定义，这些模板文件存储在安装文件夹中的 rpt 目录下。

English Original

Start and end block

Reports in KISSsoft are usually generated with a start block and an end block. You can define these start and end blocks yourself. The start and end blocks are defined in template files which are stored in the rpt directory in the installation folder.

Commands that can be used in these templates and what they mean:

 

Command

Description

DATE

Date (select "Extras > Settings" and then set your preferred output format.)

TIME

Time (select "Extras > Settings" and then set your preferred output format.)

PROJECT

Project name

PROJECTDESCRIPTION

Description of the project

FILENAME/DESCRIPTION

File name

FILENAME.EXT

File name with extension (e.g. "Example1.Z12")

FILEPATH

Path with file name (e.g. "C:\Temp\GearPair.Z12")

DESCRIPTION

Description of the file

COMMENT

Comment for the file

CUSTOMER

Customer name as defined in the project

USER

User name (Windows user name)

RELEASE

Version number (e.g. "04-2010")

COMPANY

Company name (as defined in the license file)

NLINES

Number of lines in the report

IMPERIALUNITS

Whether US customary units are specified for IF statements

METRICUNITS

Whether metric units are specified for IF statements

PROJECTUSED

Whether projects are used for IF statements
