中文翻译

元素树

元素树以树状结构显示轴系统的结构。轴位于最高层级。具有多个轴的系统中的连接元素也会在此显示。每个轴将其主要元素按外轮廓（见 外轮廓 一章）、内轮廓（见 内轮廓 一章）、强度（见 定义子元素 一章）、轴承（见 轴承 一章）和截面（见 截面 一章）分组。子元素位于主元素（圆柱和圆锥）之下。

可通过元素树选择、复制、插入和删除元素。可在上下文菜单中选择选项，以显示每个元素可执行的操作。根据元素类型，可执行特殊操作。还可设置轴、滚动轴承和截面尺寸。还可将外轮廓和内轮廓导入/导出为 DXF（见 导入轴几何体 一章 / 导出轴几何体 一章）。

English Original

Element Tree

The Element Tree illustrates the structure of the shaft system in a tree structure. Shafts are at the highest level. The connecting elements in systems with several shafts are also shown here. Each shaft groups its main elements by Outer contour (see chapter Outer contour), Inner contour (see chapter Inner contour), by Strength (see chapter Defining sub-elements), by Bearings (see chapter Bearings) and by Cross sections (see chapter Cross sections). The sub-elements are located beneath the main elements, cylinder and cone.

You can select, copy, insert and delete elements via the Element Tree. You can select options in a context menu to display the actions that are available for each element. Special actions are available, depending on the element type. You can also size shafts, rolling bearings and cross sections. You can also import/export outer and inner contours to DXF (see chapter Importing the shaft geometry)/ (see chapter Export shaft geometry).
