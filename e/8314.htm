中文翻译

外轮廓

您可以使用（空心）圆柱体、（空心）圆锥体和梁来定义轴几何。您可以使用元素框，或在上下文菜单中选择“添加”，将元素添加到元素树中。如果您在轴编辑器或元素树中选中了一个轮廓元素，可在上下文菜单中选择“在前插入”，在其左侧插入新元素；或选择“在后插入”，在其右侧插入新元素。默认情况下，新元素插入到右侧。

梁可用的截面形状有：

矩形截面

双 T 截面

H 型截面

矩形截面（空心）

L 型截面

English Original

Outer contour

You can use (hollow) cylinders, (hollow) cones and beams to define the shaft geometry. You can either use the Element box or select "Add" in the context menu to add elements to the Element Tree. If you have selected a contour element in the Shaft editor or Element Tree, select "Insert before" in the context menu to insert a new element to the left of it or select "Insert after" to insert a new element to the right of it. By default, the new element is inserted to the right.

Possible profiles for beams are:

Rectangular profile

Double T profile

H profile

Rectangular profile (hollow)

L profile
