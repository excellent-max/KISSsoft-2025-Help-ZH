中文翻译

使用导入的滚刀数据生成齿条

您可以将刀具定义为 .dxf 文件。在这种情况下，轮廓必须按如下方式输出，以便 KISSsoft 能正确读取：

图 15.83：刀具齿廓

注意

文件（.dxf）只能包含您为导入指定的图层中的轮廓 A 至 E。

除轮廓外，您还必须定义制造中心距。在这种情况下，中心距的参考线通过齿条高度来定义。

注意

此工序不应与“自动”工序结合，除非有意为之。要禁用“自动”，右键点击“禁用”。

English Original

Generating a rack with imported hobbing cutter data

You can define a cutter as a .dxf file. In this case, the contour must be output as follows so that it can be read correctly by KISSsoft:

Figure 15.83: Tool profile

Note

The file (.dxf) must only contain contours A to E in the layer you can specify for importing.

In addition to the contour, you must also define the manufacturing center distance. In this case, the reference line for the center distance is defined using the rack height.

Note

This operation should not be combined with the "automatic" operation, if this is not intended. To deactivate "automatic", right-click "Deactivate".
