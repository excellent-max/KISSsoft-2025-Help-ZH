中文翻译

齿形

除实际计算外，齿形计算还提供许多其他选项，因为它可以模拟使用精确定义刀具的制造过程。这些选项包括，例如：

  • 利用修形和齿根轮廓优化进行齿形修整
  • 考虑使用不同刀具进行多道制造工序
  • 计算制造轮齿所需的刀具（插齿刀或滚刀）（例如，针对从 CAD 程序导入的齿形或经修改的齿形）
  • 用于注塑模具或用于制造插齿刀的齿形修整

注意

提供了专门讲解齿形修整的特别教程。这些教程可从 KISSoft 网站下载：https://www.kisssoft.com。

齿形计算模块的输入窗口分为两栏。左栏显示要对齿轮执行的操作。右栏包含计算公差范围和导出组近似区域以及相应的操作组。

English Original

Tooth form

In addition to the actual calculation, the tooth form calculation offers a number of other options, because it simulates manufacturing with a precisely defined cutter. These options include, for example,

  • tooth form modifications with profile modifications and root contour optimization
  • taking into account several steps in the manufacturing with different tools
  • calculating the cutter (pinion type cutter or hobbing cutter) required to manufacture the gear teeth (for example, for tooth forms that have been imported from a CAD program or for modified tooth forms)
  • tooth form modifications for injection molds or for use in manufacturing pinion type cutters

Note

Special tutorials that specifically deal with tooth form modifications are available for use. These tutorials can be downloaded from the KISSoft website, https://www.kisssoft.com.

The Tooth form calculation module input window has of two columns. The left-hand column shows which operations are to be performed on the gears. The right-hand column consists of the Tolerance field for calculation and Approximation for export groups areas and the relevant operations group.
