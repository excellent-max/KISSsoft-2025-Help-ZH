中文翻译

齿顶修正

齿顶修正k*mn 通常是从齿廓变位量总和计算得出，以确保齿顶间隙不发生变化。然而，如果基准齿廓设置为 自身输入，齿顶修正将不进行计算。在外啮合齿轮副中，齿顶修正的减少会导致齿顶圆修正出现负值。相反，在内齿中，结果是两个齿轮的齿顶圆修正均为正值，因此齿高也会增加。在 KISSsoft 中，内齿的齿高未增加，因此齿顶修正被限制在0。

或者，您可以指定自己的齿顶修正。但该设置仅对非修顶工具有效。否则，该值在计算时将被设置为 0。单击“尺寸计算”按钮，可为恒定的齿顶间隙计算建议值。

点击“转换”按钮，输入一个齿顶圆直径（da、daE 或 dai），该直径用于根据现有基准齿廓转换齿顶修正。

English Original

Tip alteration

The tip alteration k*mn is usually calculated from the profile shift total to ensure that the tip clearance does not change. However, if the reference profile is set to Own Input, the tip alteration will not be calculated. In an external gear pair, a reduction in the tip alteration results in a negative value for the tip circle reduction. In contrast, in internal toothings, the result is a positive value for both gears, and therefore also an increase in the tooth height. In KISSsoft, the tooth height of internal toothing is not increased, and therefore the tip alteration is limited to 0.

Alternatively, you can specify your own tip alteration. However, this only has an effect on non-topping tools. Otherwise, the value is set to 0 when it is calculated. Click a Sizing button to calculate the proposed value for a constant tip clearance.

Click the Convert button to input a tip diameter (either da, daE or dai) which is used to convert the tip alteration, using the reference profile present.
