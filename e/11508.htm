齿廓鼓形修形，直径居中

图（参见图 15.43）显示了齿廓图中定义的（直径居中的）齿廓鼓形修形。此图中还显示了数值设置。修形在齿顶和齿根处的起始位置可在 制造 选项卡中设置。

直径居中的齿廓鼓形修形是指：在端面内，从计算齿高的中部开始，沿齿顶圆和齿根圆方向，材料被持续且逐渐地去除。弧线形曲线由点 A 和 E 以及数值 Ca 设定。对于齿廓鼓形修形，Ca = Cαa = Cαf 成立。直径居中的齿廓鼓形修形在齿高方向上产生一段圆弧。

English Original

Profile crowning, diameter-centered

Figure (see Figure 15.43) shows the (diameter-centered) profile crowning as defined in the profile diagram. The Value setting is also shown in this figure. The start of the modification at the tip and root can be set in the Manufacturing tab.

Diameter-centered profile crowning occurs where material is removed constantly, and increasingly, in the direction of the tip and root circle, in the transverse section, starting from the middle of the calculated tooth height. The arc-like curve is set using points A and E and the value Ca. Ca = Cαa = Cαf applies for profile crowning. Diameter-centered profile crowning results in an arc of circle in the direction of the tooth height.
