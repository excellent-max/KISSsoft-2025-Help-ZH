中文翻译

使用组创建模型

除了使用元素框和草图器创建模型外，您还可以使用组助手生成各个完整的子装配体。随后可通过在模型树结构中拖放，合并这些子装配体中的各根轴，从而由各个组创建一个统一的齿轮箱方案。

English Original

Creating a model with groups

Besides creating a model using the Element Box and the Sketcher, you can use the Groups Assistant to generate individual finished sub-assemblies. You can then merge the individual shafts in these assemblies by dragging and dropping them in the model tree structure. This creates a single gearbox concept from the individual groups.
