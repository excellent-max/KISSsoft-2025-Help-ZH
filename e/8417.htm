中文翻译

3D 导出

选择图形 > 3D 导出可将刚设计的齿轮几何图形导出到指定的 CAD 系统。下一节（参见"设置"章）提供了关于应使用哪个 CAD 系统及其接口的更多详细信息。

注意：

首次调用此函数之前，请确保您使用的是合适的 CAD 系统。如果您指定的 CAD 程序尚未安装，调用此函数时可能会出现问题。

English Original

3D export

Select Graphics > 3D Export to export the geometry of the gears you have just designed to a specified CAD system. The next section (see chapter Settings) provides more detailed information about which CAD system you should use, and its interface.

Note:

Before you call this function for the first time, make sure you are using a suitable CAD system. If you have specified a CAD program that has not yet been installed, you may cause a problem when you call this function.
