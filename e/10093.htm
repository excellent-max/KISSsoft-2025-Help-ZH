使用用户自己的 S-N 曲线（Wöhler 曲线）进行计算

金属材料的 S-N 曲线（Wöhler 曲线）通常由数据库中的耐久极限值 sigFlim、sigHlim 以及有限寿命计算值 YNT（牙底）和 ZNT（齿面）确定，并符合 ISO、AGMA 或 DIN。如果已选择此选项，并且用户为材料输入了自己的 S-N 曲线（Wöhler 曲线），则强度计算将使用用户的 S-N 曲线（Wöhler 曲线）。

如果使用自己的 S-N 曲线（Wöhler 曲线）来计算塑料材料，那么 使用自己的 S-N 曲线（Wöhler 曲线） 标志将不起作用。

使用用户自己的 S-N 曲线（Wöhler 曲线）进行计算的注意事项：

  • 您可以使用 ISO、DIN 和 AGMA 中规定的计算方法来计算金属材料。
  • S-N 曲线（Wöhler 曲线）存储在文件中（参见：数据库）。材料的许用应力（σFadm 用于牙底和/或 σHadm 用于齿面）根据循环次数 NL 定义。
  • 耐久极限值 σFlim 和 σHlim 直接输入到数据库中，也是编制文档所必需的，并应与 S-N 曲线（Wöhler 曲线）数据一起，以有意义的组合形式详细说明。我们建议使用 σFlim / σHlim 的值 σFadm / σHadm（当 NL=107 时）。
  • 使用寿命因子 YNT 和 ZNT 定义并报告如下： YNT = σFadm / σFlim, ZNT = σHadm / σHlim
  • 其他影响允许材料值的因素，例如 Ydrel, YRrelT, YX, ZL, ZV, ZR 和 ZW，是根据所选计算方法（ISO、DIN 或 AGMA）进行计算和使用的。因此，所选允许材料值 σFG 或 σHG 并不完全等于来自 S-N 曲线（Wöhler 曲线）的 σFadm / σHadm。
English Original

Calculation with own S-N curve (Woehler line)

The S-N curve (Woehler line) of metallic materials is usually defined by the endurance limit values sigFlim, sigHlim, entered in the database, and the finite life calculation values YNT (root) and ZNT (flank) in accordance with ISO, AGMA or DIN. If this option has been selected, and you input your own S-N curves (Woehler lines) for material, the strength calculation is performed using your S-N curve (Woehler lines).

If you use your own S-N curves (Woehler lines) to calculate plastics, the Calculation with own S-N curve (Woehler line) flag has no effect.

Notes about calculation methods using your own S-N curves (Woehler lines):

  • You can use the calculation methods specified in ISO, DIN and AGMA for metallic materials.
  • The S-N curves (Woehler lines) are stored in a file (see under: Database). The material’s allowable stress (σFadm for root and/or σHadm for flank) is defined according to the number of cycles NL .
  • The endurance limit values σFlim and σHlim, that are input directly in the database, are also required for documentation purposes and should be detailed together with the S-N curve (Woehler line) data, in a meaningful combination. We recommend to use for σFlim / σHlim the value σFadm / σHadm if NL=107 .
  • The service life factors, factor YNT and ZNT are defined and reported as follows: YNT = σFadm / σFlim, ZNT = σHadm / σHlim
  • The other factors which influence the permitted material value, such as Ydrel, YRrelT, YX, ZL, ZV, ZR and ZW, are calculated and used in accordance with the selected calculation method (ISO, DIN or AGMA). For this reason, the selected permitted material value σFG or σHG is not exactly equal to the value σFadm / σHadm from the S-N curve (Woehler line).
