中文翻译

保存用户定义的轴承到计算文件中

如果启用此选项，所有用户定义的滚动轴承的数据将一起保存在计算文件中。因此，当此文件在数据库中没有这些滚动轴承的计算机上打开时，仍可以执行此计算。如果数据同时存在于文件和数据库中，数据库中的数据将被使用，并在保存文件时更新到文件中。

English Original

Save user defined bearings in calculation file

If this option is enabled, the data from all user-defined rolling bearings is saved together with the calculation file. As a result, this calculation can still be performed if this file is opened on a computer whose database does not contain these rolling bearings. If this data is present both in the file and in the database, the data in the database is used and updated in the file when the file is saved.
