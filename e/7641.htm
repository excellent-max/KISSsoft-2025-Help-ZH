面向开发者的扩展功能

除了已描述的功能外，还为开发者提供了更多功能。

  • 要打开模板文件，请单击 文件 -> 打开模板。或者，单击 插入 -> 默认模板 以加载模板文件。该文件在模板下以树的形式显示。
  • 要在树视图中添加新元素，可以 复制 并 粘贴 它们。新元素将作为模板文件的副本添加。
  • 您可以使用上下文菜单功能来重命名和删除元素。
  • 属性对话框中的数据可以编辑。可以添加和删除新变量。
  • 隐藏的变量将被显示，并且可以执行所有功能。
  • 要隐藏消息，请选择 附加 -> 抑制消息。

Extended functionality for developers

In addition to the functionality already described, more functions are available for developers.

  • To open a template file, click on File -> Open Templates. Alternatively, click on Insert -> Default templates to load the template file. It is displayed as a tree under Templates.
  • To add new elements in tree view, you can Copy and Paste them. The new elements are added as copies from a template file.
  • You can use context menu functions to rename and delete elements.
  • The data in the Properties dialog can be edited. New variables can be added and deleted
  • Hidden variables will be displayed and all functions can be performed.
  • Hide messages by selecting Extras -> Suppress messages.
