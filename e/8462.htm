中文翻译

轴向模数/端面模数

在此处，您可以单击 计算 > 用法向模数代替轴向模数计算 选项卡中的模块特定设置，以便在以后的计算中使用法向模数 mn 而不是轴向模数。

注意

这会改变齿顶圆和齿根圆（参见"用法向模数代替轴向模数计算"章）的计算方式。

English Original

Axial/transverse module

Here, you can click on Module specific settings in the Calculations > Calculation with normal module instead of with axial module tab, to work with the normal module mn instead of the axial module in future calculations.

Note

This changes the way the tip and root circles(see chapter Calculation with normal module instead of axial module) are calculated.
