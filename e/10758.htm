中文翻译

经典方法

选择 KISSsys 附加项 -> 管理员 并启用管理员后，系统会在 模板 选项卡中显示创建模型所需的所有元素。要创建模型，可以将需要的元素从模板中复制并插入到导航树中。您也可以将元素从模板移动到导航树中来创建元素。使用此经典方法可以创建所有可能的模型。

English Original

Classic method

If you select KISSsys Extras -> Administrator, and enable the Administrator, the system displays all the elements required to create a model, in the Template tab. To create a model, copy the elements you want from the template and insert them in the navigation tree. You can also create elements by moving them from the template to the navigation tree. All possible models can be created using this classical method.
