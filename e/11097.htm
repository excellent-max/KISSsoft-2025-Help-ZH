中文翻译

显示

传动误差单位 此处可选择啮合线长度（传动误差）或从动齿轮的角度（转角误差）。

平滑结果： 此功能使用低通滤波器平滑结果（赫兹压力、齿轮1/2的齿根应力、抗胶合安全系数和抗微点蚀安全系数）。默认情况下未选中此功能，但如果结果受到强烈数值噪声影响，可使用该功能平滑结果。

齿高分析区域： 这定义了用于评估结果的最大齿高区域（赫兹压力、齿轮1/2的齿根应力、抗胶合安全性和抗微点蚀安全性）。此设置生成额外结果，不改变接触分析的结果。

面宽分析区域： 这定义了沿齿宽的最大区域，用于评估结果（赫兹压力、齿轮1/2的齿根应力、抗胶合安全性和抗微点蚀安全性）。此设置生成额外结果，并不改变接触分析的结果。

绘制啮合线路径数据： 如果此选项启用，接触分析的结果将以方形网格形式在3D图中显示。这使数据适合导出为矩阵。

在传动误差图中考虑侧隙： 选择此设置时，将在传动误差中考虑侧隙。这会导致传动误差值的位移，即使振幅保持不变。

English Original

Display

Unit of the transmission error Here, you can select either the length on the length of path of contact (transmission error) or the angle on the driven gear (angle of rotation error).

Smooth results: This function uses a low-pass filter to smooth the results (Hertzian pressure, tooth root stress on gear 1/2, safety against scuffing and safety against micropitting). By default, this function not selected, but it can be used to smooth the results if they are affected by strong numerical noise.

Area analyzed on tooth height: This defines the maximum area along the tooth height for evaluating the results (Hertzian pressure, tooth root stress on gear 1/2, safety against scuffing and safety against micropitting). This setting generates additional results and does not change the results of the contact analysis.

Area analyzed on facewidth: This defines the maximum area along the facewidth for evaluating the results (Hertzian pressure, tooth root stress on gear 1/2, safety against scuffing and safety against micropitting). This setting generates additional results and does not change the results of the contact analysis.

Draw data for path of contact: If this option is enabled, the results of contact analysis are displayed quadratically in the 3D diagrams. This makes the data suitable for export as a matrix.

Take into account backlash in the transmission error graphic: When this setting is selected, the backlash is taken into account in the transmission error. This causes a displacement of the value of the transmission error even though the amplitude remains the same.
