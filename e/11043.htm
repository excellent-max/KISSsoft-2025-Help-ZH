中文翻译

最大解数

如果程序发现的解的数量超过指定的数量，将显示一个警告信息，并在报告中加入适当的说明。

注意

你应该只在所有可能的解都已显示后才进行最终评估。否则，最佳解可能不会显示。

English Original

Maximum no. of solutions

If the program finds more than the specified number of solutions, you see a warning message and an appropriate note is entered in the report.

Note

You should only perform a final evaluation after all the possible solutions have been displayed. Otherwise, you run the risk that the optimum solution will not be displayed.
