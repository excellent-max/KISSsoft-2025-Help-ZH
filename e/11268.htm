案例 I，试验齿轮不变时的试验结果

这类试验结果通常在试验台上测量。试验齿轮的几何形状必须在单独的 KISSsoft .Z12 文件中定义，该文件可在用户界面中选择（试验数据 选项卡）。在这种情况下，只能使用 1 种润滑状态，并且必须在试验文件中定义。

在输入试验结果数据之前，必须为试验齿轮创建并选择一个文件。用户界面中的表格会根据齿轮文件中的设置进行调整。试验文件中失效齿轮的材料特性并不重要，因为这些特性会被基本数据和试验数据选项卡中设置的用户定义值覆盖。失效齿轮所选材料必须为塑料（例如 PA66 (VDI 2736)）。必须为将要啮合的配对齿轮所用材料设置正确的材料特性。

必须为所选试验文件指定一个失效齿轮。如果所选试验文件中的两种材料均为塑料，用户可以选择齿轮 1 或齿轮 2。在其他情况下，系统会自动设置失效齿轮。失效只能发生在齿轮 1 或齿轮 2 上，不能同时发生在两者上。


以下限制适用于试验文件：

  • 必须选择塑料齿轮的计算方法
  • 必须取消选择 计算根部/齿面温度 选项（适用于润滑脂润滑和干运行）
  • 不进行载荷谱计算
  • 至少有 1 个齿轮必须由塑料材料制成
  • 额定值 选项卡必须可见。

要计算允许的齿根和/或齿面强度，必须具备以下试验结果：

  • 失效齿轮的扭矩、转速和失效循环次数。根据 VDI 2736，所有试验都应运行至失效
  • 失效齿轮的环境温度、齿根温度和齿面温度（取决于“失效原因”），或油润滑时的油温。
  • 如果配对齿轮为塑料，且失效原因设置为 齿面，还必须设置配对齿轮的齿面温度。
  • “失效原因”类型可设置为无失效、齿根、齿面或磨损。

试验齿轮许用值表也可以从文件导入。不过，必须使用合适的文件结构（参见示例文件 K17_testResults.dat）。

控制允许的齿根和/或齿面强度计算的其他设置位于计算设置中的试验数据选项卡上。第 1.2 节和第 1.3 节对各个参数有更详细的说明。

English Original

Case I, test results for unchanged test gears

Such test results are usually measured on test rigs. Geometry of the test gears must be defined in a separate KISSsoft .Z12 file, which can be selected on the user interface (Test data tab). In this case, only 1 lubrication regime is possible and must be defined in test file.

Before test result data is entered in the table, a file must be created and selected for the test gear. The table in the user interface is adjusted to suit the test, using the settings in the gear file. The material characteristics of the failed gear in the test file are not important, as they are overwritten with user-defined values set in the Basic data and Test data tabs. The selected material of the failed gear must be a plastic (for example, PA66 (VDI 2736)). The correct material characteristics must be set for the material from which the counter gear that is to be mated is made.

A failed gear must be specified for the selected test file. If both materials from the selected test file are a type of plastic, the user can select either gear 1 or gear 2. In other cases, the failed gear is set automatically. It is only possible to have failure on either gear 1 or gear 2, not on both gears simultaneously.


The following limitations apply for the test files:

  • Calculation method for plastic gears must be selected
  • The Calculate temperatures root/flank option must be deselected (for grease and dry runs)
  • Calculation without load spectrum
  • At least 1 gear must be made of plastic material
  • The Rating tab must be visible.

To calculate the permissible root and/or flank strength, the following test results must be available:

  • Torque, speed and cycles to failure of the failed gear. According to VDI 2736, all the tests should run until failure
  • Environmental, root and flank temperature (dependent on the "failure cause") or oil temperature (for oil lubrication) of the failed gear.
  • If the mating gear is plastic, and the failure cause is set to flank, the mating gear's flank temperature must also be set.
  • The type of "failure cause" can be set to no failure, root, flank or wear.

The test gear allowances table can also be imported from a file. However, you must use a suitable file structure (see example file K17_testResults.dat).

Additional settings that control the calculation of permissible root and/or flank strength are available in the Test data tab in Calculation settings. Sections 1.2 and 1.3 have more detailed explanations of the individual parameters.
