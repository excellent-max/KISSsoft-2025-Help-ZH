向数据库添加新的螺栓类型

KISSsoft 数据库包含以下螺栓类型：

  • 内六角圆柱头螺钉 DIN EN ISO 4762
  • 内六角圆柱头低头螺钉 DIN 7984
  • 六角头带杆部螺钉（A B）DIN EN ISO 4014
  • 六角头全螺纹螺钉（A B）DIN EN ISO 4017
  • 开槽圆柱头螺钉 DIN EN ISO 1207
  • 六角头带杆部螺钉，米制细牙螺纹（A B）DIN EN ISO 8765
  • 六角头全螺纹螺钉，米制细牙螺纹（A B）DIN EN ISO 8676
  • 带法兰六角头螺钉，轻型系列，F 型 DIN EN 1662
  • 带法兰六角头螺钉，轻型系列，U 型 DIN EN 1662
  • 带法兰六角头螺钉，重型系列，F 型 DIN EN 1665
  • 带法兰六角头螺钉，重型系列，U 型 DIN EN 1665
  • 方头螺栓 ASME B18.2.1
  • 六角头螺栓 ASME B18.2.1
  • 重型六角头螺栓 ASME B18.2.1
  • 六角头帽螺钉 ASME B18.2.1
  • 重型六角头帽螺钉 ASME B18.2.1
  • 自定义螺栓几何定义

对于每种螺栓类型，多个表列出了各种螺栓尺寸（= 螺栓系列）。您可以在数据库中找到包含螺栓系列数据的文件名（参见"数据库工具和外部表"章）。

您可以在现有螺栓类型内输入新尺寸，即扩展螺栓系列（参见"扩展现有的螺栓系列"章），或输入新的螺栓类型（参见"创建新的螺栓类型"章）。

Adding new bolt types to the database

The KISSsoft database includes the following bolt types:

  • Hexagon socket head cap screw DIN EN ISO 4762
  • Hexagon socket head cap screw with low head DIN 7984
  • Hexagon headed screw with shank (A B) DIN EN ISO 4014
  • Hexagon headed screw without shank (A B) DIN EN ISO 4017
  • Slotted cheese head screw DIN EN ISO 1207
  • Hexagon headed screw with shank, metric fine thread (A B) DIN EN ISO 8765
  • Hexagon headed screw without shank, metric fine thread (A B) DIN EN ISO 8676
  • Hexagon headed screws with flange, light series, shape F DIN EN 1662
  • Hexagon headed screws with flange, light series, shape U DIN EN 1662
  • Hexagon headed screws with flange, heavy series, shape F DIN EN 1665
  • Hexagon headed screws with flange, heavy series, shape U DIN EN 1665
  • Square bolts ASME B18.2.1
  • Hex bolts ASME B18.2.1
  • Heavy hex bolts ASME B18.2.1
  • Hex cap screws ASME B18.2.1
  • Heavy hex screws ASME B18.2.1
  • Own definition of bolt geometry

For each of these bolt types, a number of tables list the various bolts sizes (= bolts series). You will find the name of the file that contains the bolts series data in the database (see chapter Database Tool and External Tables).

You enter a new size within an existing bolt type i.e. extend the bolt series (see chapter Extending an existing bolt series) or input a new bolt type (see chapter Creating a new bolt type).
