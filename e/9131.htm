中文翻译

目录结构

如果有多个用户，建议将共享数据（数据库、用户定义的报告模板和标准文件）存储在服务器上。这样可以确保在发生更改和升级时，所有用户都能使用一套统一的数据。要进行设置，请将 UDB、EXT 和 TEMPLATE 目录放到所有用户均可访问的服务器上，然后设置相应变量 UDBDIR、EXTDIR 和 TEMPLATEDIR（位于 KISS.ini 文件中，见"[PATH] 中的定义"章）。

如果有多个用户，临时目录则应分别设在各自的本地工作站上，否则不同用户生成的中间结果可能相互覆盖。每套 KISSsoft 安装均使用操作系统中设置的临时用户目录；不过，也可以自定义 CADDIR 和 TEMPDIR 变量，并在 KISS.ini 文件中进行设置（参见“[PATH] 中的定义”一章）。

打开或保存计算文件或报告时，KISSsoft 会优先显示个人用户目录，避免用户反复在系统目录中查找文件。可通过 USERDIR 变量在 KISS.ini 文件中定义该目录（参见“[PATH] 中的定义”一章）。如果已选择当前工作项目（参见“当前工作项目”一章），KISSsoft 会忽略个人用户目录，改为优先显示项目目录。

English Original

Directory structure

If there are several users, it is advisable to store shared data (databases, user-defined report templates and standard files) on a server. This ensures that, if there are changes and upgrades, all users will be able to work with one uniform set of data. To set this up, put the UDB, EXT and TEMPLATE directories on a server that can be accessed by all users, and then set the corresponding variables, UDBDIR, EXTDIR and TEMPLATEDIR, in the KISS.ini (see chapter Definitions in [PATH]) file.

In contrast, if there are several users, the temporary directories should be defined locally on their workstations. Otherwise, the interim results generated for individual users might overwrite each other. For each installation, KISSsoft uses the temporary user directory set in the operating system. The CADDIR and TEMPDIR variables can, however, be tailored in the KISS.ini (see chapter Definitions in [PATH]) file.

If you want to open or save a calculation file or report, KISSsoft displays your own personal user directory as the first choice storage location. This saves you frequent searches in the directories on your system. You can define this user directory via the USERDIR variable in the KISS.ini (see chapter Definitions in [PATH]) file. The user directory will be ignored if you have selected an Active working project (see chapter The active working project). In this case, KISSsoft offers you the project directory as the first choice storage location.
