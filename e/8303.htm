中文翻译

轴元素

要添加新轴，请单击元素框中相应元素的图标（参见"轴编辑器"章）。您还可以在元素树上下文菜单中找到 添加 轴 选项（参见"元素树"章）。元素树末尾会显示一个新条目。在元素树中单击所需的元素，然后在元素编辑器中输入轴的参数（参见"元素编辑器"章）。

English Original

The shaft element

To add a new shaft, click on the can of the appropriate icon in the Element box (see chapter Shaft editor). You will also find the Add shaft option in the Element tree context menu (see chapter Element Tree). A new entry is displayed at the end of the Element Tree. Click on the element you require in the Element Tree and enter parameters for the shaft in the Element editor (see chapter Element Editor).
