与变量对话框的交互

您可以与变量对话框进行交互。输入字段中的更改以及列表中的选择可以触发对用户定义函数的回调。然后，您也可以从该回调例程中更改对话框元素。

为此，请通过变量对话框中的标题输入将局部函数设置为回调：

res = CADH_VarDialog([["Title",PROC(Callback)], Width, Height, Pitch], [dialog element 1], [dialog element 2], etc.);

如果您对对话框进行更改，现在将调用局部回调函数。该函数声明如下：

PARres;

PROCCallback

PARhandle,elemNo,event,eventPar;

IFTYP(elemNo)=STRINGTHEN

IFelemNo='@combo'ANDevent=C:CBN_SELCHANGETHEN

IFeventPar=0THEN//owninput,enableinput

CADH_VarDialogAccess(handle,[['@input1',C:VDLG_ENABLE,TRUE]]);

ELSE//disableinput,setvaluetozero

CADH_VarDialogAccess(handle,[['@input1',C:VDLG_ENABLE,FALSE],

['@input1',c:VDLG_ASSIGN,0]]);

ENDIF

ENDIF

ENDIF

ENDPROC

res=CADH_VarDialog([['Titel',PROC(Callback)],400,4000.4],

[[C:VDLG_Real,'@input1'],'Input1:',2],

[[C:VDLG_StrCom,'@combo'],'Selection:',

['owninput','calculate'],[0],TRUE]);

作为元素编号，既可以传递结果数组中按索引对应的编号，也可以传递元素名称。如示例所示，可以通过为对话框元素传递一个数组来定义名称，该数组的第一个元素中包含类型和名称。

使用此函数从回调例程访问对话框：

English Original

Interactions with variable dialogs

You can interact with variable dialogs. Changes in input fields, and selections in lists, can trigger callbacks to a user-defined function. Then, you can also change dialog elements from this callback routine.

To do this, set a local function as a callback via the title input in the variable dialog:

res = CADH_VarDialog([["Title",PROC(Callback)], Width, Height, Pitch], [dialog element 1], [dialog element 2], etc.);

The local callback function will now be called if you make changes to the dialog. The function is declared as follows:

PARres;

PROCCallback

PARhandle,elemNo,event,eventPar;

IFTYP(elemNo)=STRINGTHEN

IFelemNo='@combo'ANDevent=C:CBN_SELCHANGETHEN

IFeventPar=0THEN//owninput,enableinput

CADH_VarDialogAccess(handle,[['@input1',C:VDLG_ENABLE,TRUE]]);

ELSE//disableinput,setvaluetozero

CADH_VarDialogAccess(handle,[['@input1',C:VDLG_ENABLE,FALSE],

['@input1',c:VDLG_ASSIGN,0]]);

ENDIF

ENDIF

ENDIF

ENDPROC

res=CADH_VarDialog([['Titel',PROC(Callback)],400,4000.4],

[[C:VDLG_Real,'@input1'],'Input1:',2],

[[C:VDLG_StrCom,'@combo'],'Selection:',

['owninput','calculate'],[0],TRUE]);

Either the element number according to the index in the results array is transferred as the element number, or the element name is transferred. As in the example, a name can be defined by transferring an array, with a type and name in its first element, for the dialog element.

Use this function to access the dialog from the callback routine:

CADH_VarDialogAccess(handle, [[elemNo, action, param],[elemNo, action, param],...]
