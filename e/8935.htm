SolidWorks 3D 接口

制造商：KISSsoft AG

SolidWorks 与 KISSsoft 之间的接口通过在 3D CAD 系统中直接集成来创建。通过该接口，所有 KISSsoft 计算模块都可以在 SolidWorks 内部运行。在 KISSsoft 中计算的圆柱齿轮或锥齿轮可直接在 SolidWorks 中生成具有真实齿形的 3D 零件（参见"3D 齿轮生成"章）。用 KISSsoft 计算的轴可生成由圆柱和圆锥元素组成的 3D 零件（参见"生成 3D 轴"章），该零件直接在 SolidWorks 中生成。在 KISSsoft 中，只需单击一次按钮即可启动 SolidWorks。系统会打开一个新零件并生成相应的零件。您可以创建直齿或斜齿的圆柱齿轮（外齿轮或内齿轮）、直齿或斜齿的齿条，或按 DIN 3971 图 1 定义的直齿锥齿轮，以及轴。
您还可以向现有轴添加轮齿（参见"存在现有轴数据时的轮齿"章）。此外，借助该接口，2D 范围内的齿轮制造数据（参见"添加制造数据"章）可以以文本字段的形式自动插入到图纸上。齿轮制造数据附着在相应的凹槽（齿槽）上。

3D interface to SolidWorks

Manufacturer: KISSsoft AG

The interface between SolidWorks and KISSsoft is created by direct integration in the 3D CAD system. Use this to run all KISSsoft calculation modules from within SolidWorks. Cylindrical or bevel gears calculated in KISSsoft can be generated directly in SolidWorks as a 3D part (see chapter Generation of 3D gears) with a real tooth form. Shafts calculated with KISSsoft can be generated as a 3D part comprising cylinder and cone elements (see chapter Generating 3D shafts) directly in SolidWorks. From within KISSsoft, you can start SolidWorks with one click on a button. The system opens a new part, and generates the appropriate part. You can create cylindrical gears with straight or helical teeth, which are outside or inside, racks with straight or helical teeth, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1, and shafts.
You can also add gear teeth to existing shafts (see chapter Gear teeth if existing shaft data is present). In addition, gear manufacturing data in the 2D range (see chapter Adding manufacturing data) can be automatically inserted on the drawing as a text field, with the interface. The gear manufacturing data is attached to the relevant cutout (tooth space).
