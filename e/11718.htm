展开计算

展开分析是为高级滚刀设计开发的工具。使用此功能，可以验证滚刀的当前公差极限和边界，并评估这些值如何影响齿轮制造过程。

展开计算支持三种不同的条件：最小、 指定、最大，提供制造可变性的全面视图。此功能对于在设计阶段早期识别关键公差组合特别有价值，有助于优化刀具性能并提高齿轮质量。

展开分析可用于圆柱齿轮，目前仅能用于滚刀。要激活此选项：

  1. 转到 参考齿廓选项卡
  2. 将刀具类型设置为 滚刀
  3. 根据您的要求配置刀具。

注意：

如果项目包含多个齿轮，请确保为展开分析的每个齿轮分别定义滚刀。

Rollout calculation

Rollout analysis is a tool developed for advanced hob design. Using this function, current tolerance limits and boundaries of a hob can be verified, as well as assessed how these values influence the gear manufacturing process.

The Rollout calculation supports three distinct conditions: minimum, defined, maximum, offering a comprehensive view of manufacturing variability. This functionality is particularly valuable for identifying critical combinations of tolerances early in the design phase, which helps to optimize tool performance and improve gear quality.

Rollout analysis is available for cylindrical gears and can currently only be used for hobbing cutters. To activate this option:

  1. Go to the Reference profile tab
  2. Set the tool type to Hobbing cutter
  3. Configure the tool according to your requirements.

Note:

If a project includes multiple gears, make sure that the hobbing cutter is defined for each gear separately for the Rollout analysis.
