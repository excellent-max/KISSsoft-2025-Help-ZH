中文翻译

服务器功能

服务器具有若干功能，可使用这些功能来启动计算模块、读取或设置值并执行计算。

  • GetModule([in] BSTR module, [in] VARIANT_BOOL interactive)：根据模块标识（如 Z012 或 W010）启动计算模块。interactive 参数指定是否创建带图形用户界面的计算模块。
  • IsModuleValid([out] VARIANT_BOOL isValid)：返回计算模块是否已通过 GetModule 创建且仍然存在。
  • Calculate() 执行活动模块的主要计算。
  • CalculateRetVal([out, retval] VARIANT_BOOL* isOk)：执行当前活动模块的主计算，并返回计算是否成功。
  • SetVar([in] BSTR name, [in] BSTR value)：将变量设置为指定值，数据以文本形式传输。变量名可在报告模板中查找，但不能保证这些变量在未来版本中保持不变。
  • GetVar([in] BSTR name, [out, retval] BSTR* value)：以文本形式返回 KISSsoft 变量。
  • ShowInterface([in] VARIANT_BOOL wait)：显示图形用户界面。wait 参数用于指定函数是否等待对话框关闭。
  • IsActiveInterface([out, retval] VARIANT_BOOL* isActive)：返回 KISSsoft 对话框是否处于活动状态。
  • IsActive([out, retval] VARIANT_BOOL* isActive)：返回是否已加载计算模块。
  • ReleaseModule() 再次释放已加载的模块。每次使用后都要再次释放模块，以减少服务器的负载。
  • LoadFile([in] BSTR file name)：加载指定文件。
  • SaveFile([in] BSTR file name)：将计算保存到指定文件。
  • CheckLicense ([in] name BSTR, [out, retval] VARIANT_BOOL* isOk)：返回许可证是否有效。
  • GetININame([out, retval] BSTR* name)：返回当前加载的 INI 文件名。
  • GetVersionFromFile([in] BSTR filename, [out, retval] BSTR* version)：返回计算文件中 KISSsoft 模块的版本号（如 2.6；版本号取决于所用模块）。
  • GetModulFromFile([in] BSTR filename, [out, retval] BSTR* name)：返回计算文件中的 KISSsoft 模块标识（如 M040）。调用前必须先通过 GetModule 获取计算模块。
  • GetKsoftVersionFromFile([in] BSTR file name, [out, retval] BSTR* kSoftVersion)：返回计算文件中记录的 KISSsoft 版本号（如 03-2011）。
  • GetKsoftVersion([out, retval] BSTR* kSoftVersion)：返回 KISSsoft 已注册且通过 COM 接口启动的版本（如 03-2011）。
  • GetDBName([in] BSTR db_name, [in] BSTR table, [in] SHORT flag, [in] LONG ID, [in] LONG order, [out,retval] BSTR *name)：使用 flag 参数指定输入为 ID（flag = 0）还是结果（flag = 1）。相应的输出为条目的序号和名称，或 ID（材料数据库中的 BEZ_DIN）。发生错误时不显示消息，函数返回 False。
  • GetDBValue([in] BSTR db_name, [in] BSTR table, [in] LONG ID, [in] BSTR fieldname, [out,retval] BSTR *name)：返回指定数据库字段中的值。发生错误时不显示消息，函数返回 False。请注意，轴承制造商未批准使用该函数直接提取轴承数据，因此该函数已被禁用。
  • GetKsoftVersionSettings([out, retval] BSTR* kSoftVersionSettings)：返回用于保存个人设置的临时设置文件夹所对应的 KISSsoft 版本（如 03-2014）。
  • SetSilentMode([in] VARIANT_BOOL silent)：指定是否隐藏消息，以便无需确认系统提示即可执行计算。
  • Report([in] LONG show)：生成报告。show 参数用于指定是否显示报告。报告在 Temp 目录的“KISS_?”子文件夹中创建。

  • SetDebugFile([in] BSTR path)：设置用于错误追踪的调试文件路径和文件名。

  • ReportWithParameters([in] BSTR infile, [in] BSTR outfile, [in] LONG show, [in] LONG type)：使用指定的报告模板（infile），在预定位置以预定名称（outfile）创建报告，并指定文件类型。文件名可以包含路径，也可以不含路径。输入报告模板 infile 时，还应输入文件扩展名（例如 Z012ld0.rpt）。如果没有为该文件输入路径，程序将在默认目录（另见“报告”）中查找。输出文件也必须输入扩展名。如果未指定路径，文件将以 KISS_? 为名称保存到 Temp 目录。文件扩展名应与指定的类型匹配。show 参数用于指定是否显示报告。art（即 type）参数用于指定输出格式：art=0 为带 *1 的 rtf 格式；art=1 为不带 *1 的 rtf 格式；art=2 为带 *1 的 html 格式；art=10 为不带 *1 的 txt 格式；art=20 为不带 *1 的 Unicode txt 格式；art=1000 为带 *1 的 pprpt 格式；art=1001 为不带 *1 的 pprpt 格式。
    • *1 表示考虑数据层级
    • 可能的组合示例：使用默认报告模板 → RTF 格式：ReportWithParameters("C:\Program Files (x86)\KISSsoft 2019\rpt\Z070ld0.rpt","C:\Temp\Z070ld0.rtf", 1, 0)，HTML 格式：Call ksoft.ReportWithParameters("Z070ld0.rpt", "C:\Temp\Z070ld0.html", 1, 2)，PPRPT 格式：ReportWithParameters ("C:\Program Files (x86)\KISSsoft 2019\rpt\Z070ld0.rpt","C:\Temp\Z070ld0.pprpt", 1, 1000)；使用图章报告模板 → TXT 格式：ReportWithParameters("Z10GEAR1d.rpt","C:\Temp\Z010GEAR1d.txt", 1, 10)
  • Message([out] VARIANT *strings, [out] VARIANT *types:, [out] LONG *numElem)：第一个参数以字符串数组形式返回上次计算的消息；第二个参数返回相应的消息类型（error、warning、info）；numElem 返回现有消息的数量。
  • CallFunc([in] BSTR name)：执行特殊计算。可按需索取可用计算的详细清单。
  • CallFuncNParam([in] VARIANT paramArray)：执行特殊计算。可按需索取可用计算的详细清单。
  • SetLanguage([in] LONG index)：设置报告、界面和消息使用的语言（0 = 德语；1 = 英语；2 = 法语；3 = 意大利语；4 = 西班牙语；5 = 俄语；6 = 葡萄牙语；7 = 中文）。
  • GetLanguage ([out, retval] LONG* index)：读取当前设置的语言索引。各索引的定义见 SetLanguage() 函数说明。
English Original

Server functionality

The server has a number of functions that you can use to start a calculation module, read or set values, and perform a calculation.

  • GetModule([in] BSTR module, [in] VARIANT_BOOL interactive) starts a calculation module from the module descriptor (e.g. Z012 or W010). ‘Interactive’ defines whether the calculation module is to be generated with a graphical user interface.
  • IsModuleValid([out] VARIANT_BOOL isValid) returns a value that indicates whether the calculation module has been generated with ‘GetModule’ and is present.
  • Calculate() performs the main calculation for the active module.
  • CalculateRetVal([out, retval] VARIANT_BOOL* isOk) runs the main calculation for the active module, and returns a value to tell you whether the calculation is OK.
  • SetVar([in] BSTR name, [in] BSTR value) is a function with which you can set variables to a required value. This data is transferred as text. You will find the variable names in the report templates, but there is no guarantee that all these variables will remain the same in the future.
  • GetVar([in] BSTR name, [out, retval] BSTR* value) returns a variable from KISSsoft as text.
  • ShowInterface([in] VARIANT_BOOL wait) displays the graphical user interface. Use the 'wait' parameter to specify whether the function is to wait until the dialog is closed.
  • IsActiveInterface([out, retval] VARIANT_BOOL* isActive) shows whether a KISSsoft dialog is active.
  • IsActive([out, retval] VARIANT_BOOL* isActive) shows whether a module has been loaded.
  • ReleaseModule() releases the loaded module again. You must always release a module again, to reduce the load on the server.
  • LoadFile([in] BSTR file name) loads the specified file.
  • SaveFile([in] BSTR file name) saves the calculation in the specified file.
  • CheckLicense ([in] name BSTR, [out, retval] VARIANT_BOOL* isOk) shows whether the license is valid.
  • GetININame([out, retval] BSTR* name) supplies the name of the loaded INI file.
  • GetVersionFromFile([in] BSTR filename, [out, retval] BSTR* version) supplies the version number (e.g. 2.6) of the KISSsoft module in the calculation file (the version number depends on which module is being used).
  • GetModulFromFile([in] BSTR filename, [out, retval] BSTR* name) supplies the KISSsoft module label (e.g. M040) in the calculation file. You must first fetch a calculation module (GetModule).
  • GetKsoftVersionFromFile([in] BSTR file name, [out, retval] BSTR* kSoftVersion) supplies the KISSsoft version number (e.g. 03-2011), given in the calculation file.
  • GetKsoftVersion([out, retval] BSTR* kSoftVersion) supplies the KISSsoft version (e.g. 03-2011) that is registered and was started via the COM interface.
  • GetDBName([in] BSTR db_name, [in] BSTR table, [in] SHORT flag, [in] LONG ID, [in] LONG order, [out,retval] BSTR *name) Use the 'flag' parameter to specify whether the ID (flag = 0) or the result (flag = 1) is to be used as the input. The output is then either the order and the name of the entry or the ID (in material database BEZ_DIN). No message is displayed if an error occurs. A ‘False’ is returned for the function.
  • GetDBValue([in] BSTR db_name, [in] BSTR table, [in] LONG ID, [in] BSTR fieldname, [out,retval] BSTR *name) supplies the value present in this database field. No message is displayed if an error occurs. A ‘False’ is returned for the function. Please note that the bearing manufacturers have not approved this function for directly extracting bearing data, which is why this function is disabled.
  • GetKsoftVersionSettings([out, retval] BSTR* kSoftVersionSettings) supplies the KISSsoft version (e.g. 03-2014) of the temporary settings folder in which the personal settings are stored.
  • SetSilentMode([in] VARIANT_BOOL silent) defines whether messages are to be hidden or not, so that calculations can be performed without you having to confirm system prompts.
  • Report([in] LONG show) writes the report. You can specify whether or not this report is to be displayed. The report is created in the Temp directory in the "KISS_?" sub-folder.

  • SetDebugFile([in] BSTR path) sets the path and file name of a debug file which can be used for error tracking.

  • ReportWithParameters([in] BSTR infile, [in] BSTR outfile, [in] LONG show, [in] LONG type) creates the report using the specified report template (‘infile’) in the predefined place with the predefined name (‘outfile’) and supplies the file type. You can enter file names either with or without the path. When entering the report template (‘infile’), you should also input the file extension (e.g.’Z012ld0.rpt’). If you do not enter a path for this file, the program will search the default directory (see also Reports) for the file. You must also enter the file extension for an output file. If you do not specify the path, the file is saved to the Temp directory with the name ‘KISS_?’. The file extension should match the specified type. Use the ‘show’ parameter to define whether the report is to be displayed, or not. Use the ‘art’ (meaning ‘type’) parameter to define the output format. (art=0 → rtf format with *1 ; art=1 → rtf format without *1 ; art=2 → html format with *1 ; art=10 → txt format without *1 ; art=20 → txt format in Unicode without *1) ; art=1000 → pprpt format with *1 ; art=1001 → pprpt format without *1).
    • *1 = takes into account the data level
    • Examples of possible combinations: With default report templates → RTF format: ReportWithParameters("C:\Program Files (x86)\KISSsoft 2019\rpt\Z070ld0.rpt","C:\Temp\Z070ld0.rtf", 1, 0), HTML format: Call ksoft.ReportWithParameters("Z070ld0.rpt", "C:\Temp\Z070ld0.html", 1, 2), PPRPT format: ReportWithParameters ("C:\Program Files (x86)\KISSsoft 2019\rpt\Z070ld0.rpt","C:\Temp\Z070ld0.pprpt", 1, 1000); with drawing stamp report template → TXT format: ReportWithParameters("Z10GEAR1d.rpt","C:\Temp\Z010GEAR1d.txt", 1, 10)
  • Message([out] VARIANT *strings, [out] VARIANT *types:, [out] LONG *numElem) returns the messages from the last calculation in the first parameter, as an array containing strings. The second parameter contains the particular message type (error, warning, info). The number of existing messages is shown in numElem.
  • CallFunc([in] BSTR name) allows you to perform special calculations. A more detailed list of the available calculations is available on request.
  • CallFuncNParam([in] VARIANT paramArray) allows you to perform special calculations. A more detailed list of the available calculations is available on request.
  • SetLanguage([in] LONG index) specifies the language used for reports, interfaces and messages (0 = German; 1 = English; 2 = French; 3 = Italian; 4 = Spanish; 5 = Russian; 6 = Portuguese; 7 = Chinese).
  • GetLanguage ([out, retval] LONG* index) reads the index of the language that is currently set. Indexes are described in the SetLanguage() function description.
