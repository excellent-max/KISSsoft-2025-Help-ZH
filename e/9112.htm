中文翻译

生成、打开和关闭项目

选择 项目 > 新建 ... 以创建新项目。将打开一个对话框，您可以在其中输入项目名称、项目目录、描述和注释，以及要使用的模板文件目录（参见 定义您自己的模板文件）。新创建的项目被插入到项目树中，并被定义为当前工作项目（参见"单位切换"章）。

如果打开现有项目（项目 > 打开...），该项目也会被插入到项目树中，并被定义为当前工作项目（参见 当前工作项目）。

您可以通过选择项目，然后选择 项目 > 关闭 来关闭项目。您还可以在项目树的上下文菜单（参见 菜单、上下文菜单和工具栏）中找到此操作。项目仍将保留，您可以随时再次打开它。

English Original

Generating, opening and closing projects

Select Project > New ... to create a new project. A dialog opens in which you enter the name of the project, the project directory, descriptions and comments, and also the directory for the template files (see chapter Defining your own template files) that are to be used. The newly created project is inserted into the Project Tree and defined as the Active working project (see chapter Unit switch).

If you open an existing project (Project > Open...) this will also be inserted into the project tree and defined as the Active working project (see chapter The active working project).

You close a project by selecting it and then selecting Project > Close. You will also find this action in the context menu (see chapter Menus, context menus and the tool bar) in the Project Tree. The project will still be retained, and you can open it again at any time.
