扭矩脉动

扭矩脉动是扭矩中的周期性激励，会导致振动和噪声。在许多电机和内燃机设计中通常都能观察到这种效应，它指的是电机轴旋转时输出扭矩的周期性波动。作为另一种激励源，外部施加的扭矩脉动被集成到扩展强迫响应模块中。其主要方法与用于计算齿轮啮合激励的方法非常相似。不过，由扭矩脉动产生的激励会叠加到由传动误差产生的激励上，从而使系统中的强迫响应作为两种激励类型共同作用的结果来计算。

如果选择不平衡质量作为计算类型，扭矩脉动激励输入数据表将处于非活动状态。扭矩脉动输入数据的边界条件必须在此表中指定。单击表格右下角的 + 号以插入新行，用于为每个边界条件输入数据。选择边界条件后，必须定义相应的带扭矩脉动的输入联轴器。在输入下，指定时域或频域的输入类型之一。最后，选择要上传输入扭矩脉动数据的目标输入文件夹。

时域中扭矩脉动输入数据的必要规格：

  • 系统模块的扭矩脉动输入数据必须采用以下文件格式：*.dat、*.txt 或 *.csv。文件必须包含两列扭矩脉动幅值数据。
  • 第一列为相应边界条件下的转角，第二列为扭矩脉动幅值。
  • 扭矩脉动幅值必须在输入联轴器受该扭矩加载的轴的一个（或多个）完整旋转周期内给出。这意味着一个扭矩变化周期的频率必须是相应轴转速的整数倍。
  • 扭矩脉动幅值必须按等间隔转角给出。
  • 扭矩脉动幅值的平均值必须为零；其中的恒定分量（平均值）应已通过系统模块的边界条件作为恒定扭矩输入。

频域中扭矩脉动输入数据的必要规格：

  • 第一行给出激励阶次。
  • 在第二和第三行中输入联轴器转速或恒定扭矩。
  • 然后，输入与每个激励阶次以及范围内的每个转速和扭矩相对应的扭矩脉动幅值。
  • 联轴器转速和恒定扭矩必须按升序排列。
  • 系统模块模型的联轴器转速和恒定扭矩必须在输入数据文件给出的范围内。
  • 系统模块模型的联轴器转速和恒定扭矩必须对应于扭矩脉动幅值的定义值。

English Original

Torque ripple

Torque ripple is a periodic excitation in torque which can result in vibrations and noise. This effect can usually be observed in many electric motor and combustion engine designs, referring to a periodic fluctuation in the output torque as the motor shaft rotates. The externally applied torque ripples, as another source of excitation, are integrated in the extended force response module. The main approach is very similar to the one used to calculate gear mesh excitations. However, the excitations resulting from torque ripple are added to those resulting from the transmission error, so that the forced responses in the system are calculated as the result of both excitation types.

The table for the torque ripple excitation input data is not active if Unbalance masses is selected as the type of calculation. The boundary conditions for the torque ripple input data have to be specified in this table. Click the + sign in the lower right-hand corner of the table to insert new rows for entering the input data for each boundary condition. After selecting the boundary condition, the corresponding input coupling with torque ripple has to be defined. Under Input, specify one of the input types for the time or frequency domain. Finally, select the input folder into which the input torque ripple data is to be uploaded.

Required specifications for the torque ripple input data in the time domain:

  • Torque ripple input data in the system module must have the following file format: *.dat, *.txt or *.csv. The file must contain two columns with the torque ripple amplitudes.
  • The first column must contain the angle of rotation for the corresponding boundary condition. The second column must contain the torque ripple amplitudes.
  • The torque ripple amplitudes must be given for a duration of one (or several) full rotation(s) of the shaft on which the input coupling is loaded by the torque. This implies that the frequency of one torque variation cycle must be an integer factor of the corresponding shaft speed.
  • The torque amplitudes must be reported at equally distanced rotation angles.
  • The mean value of the torque ripple amplitudes must be zero. It means that the constant part (its mean value) must be already given as a constant torque through boundaries in the system module.

Required specifications for the torque ripple input data in the frequency domain:

  • In the first line, the excitation orders are given.
  • Enter the coupling speeds or the constant torques in the second and third lines.
  • Then, enter the torque ripple amplitudes that correspond to each excitation order and to each speed and torque in the ranges.
  • The coupling speeds and constant torques must be ascending.
  • The coupling speeds and constant torques of the system module model must be in the range given in the input data file.
  • The coupling speeds and constant torques of the system module model must correspond to a defined value of the torque ripple amplitudes.
