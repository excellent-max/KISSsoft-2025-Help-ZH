中文翻译

使用实验数据进行计算

使用此选项可定义由实验数据确定的 Haigh 图。如果在 实验数据 字段（用于按 DIN 743 定义的模块特定材料数据）中输入文件名（例如 WMAT-001.dat），则 强度 选项卡中会出现一个选择列表。

  • 不予考虑：数据被忽略。
  • 用于 DIN 743 (KFσ 根据 DIN 743)：数据是从为材料定义的实验数据文件中导入的，并且 KFσ 系数根据 DIN 743 定义。
  • 用于 DIN 743 (KFσ=1)：数据是从为材料定义的实验数据文件中导入的，且 KFσ 系数始终设置为 1。

关于如何定义数据的说明可从 KISSsoft 获取。测得的 Haigh 图并非完全按照 DIN 743 中所描述的方式解读。总体影响系数将Haigh 图分为x 坐标和 y 坐标，使得结果显著降低。

如 DIN 743 中所定义的平均应力影响，随着缺口变尖，其影响会增加，不应减少。此修改确保该影响始终增加。

如果折算平均应力 σmv < 0，则 Wöhler 图的线将延伸到 Haigh 图的负区域，曲线随后在负区域内因压缩屈服点 σDk 而断裂。更多信息，另请参见 DIN 743-1 第 21 页的说明。

English Original

Calculation with experimental data

Use this option to define a Haigh diagram which has been determined from experimental data. If you input a file name (e.g. WMAT-001.dat) in the Experimental data field for module-specific material data as defined in DIN 743, a selection list appears in the Strength tab.

  • Do not take into account: the data is ignored.
  • Use in DIN 743 (KFσ according to DIN 743): the data is imported from the file which was defined for the materials under Experimental data, and the KFσ coefficient is defined according to DIN 743.
  • Use in DIN 743 (KFσ=1): the data is imported from the file which was defined for the materials under Experimental data, and the KFσ coefficient is always set to 1.

Instructions about how to define the data can be requested from KISSsoft. The measured Haigh diagram is not interpreted exactly as described in DIN 743. The overall influence coefficient divides the Haigh diagram into x- and y-coordinates so that the results are much lower.

The influence of mean stress as defined in DIN 743 increases as the notches become sharper, and should not decrease. This modification ensures that this influence always increases.

If the comparative medium stress is σmv <0, the line of the Wöhler diagram is extended into the negative area of the Haigh diagram, and the curve is then broken in the negative area by compression yield point σDk. For more information, see also the description in DIN 743-1, p. 21.
