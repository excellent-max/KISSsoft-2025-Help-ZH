中文翻译

为每个载荷工况单独定义数据

在计算具有载荷谱的轴时，可以通过选择此列表项来启用该选项。

使用此选项可在载荷谱定义中为每个单独的载荷谱工况定义应力比。

该数据可用于根据 FKM 准则，以等效应力校核的形式进行疲劳强度验证。该验证与迄今通常进行的幅值验证具有相同的作用。与此相反，在等效应力校核中，可以为每个载荷工况定义不同的应力比。

为了在验证的载荷侧计入不同应力比的影响，将载荷谱转换为平均应力 Sm = 0 和应力比 R = -1。这样即可根据 FKM 准则，在计入雨流矩阵载荷谱影响的情况下对轴进行强度计算。

English Original

Define data for each load case individually

When calculating a shaft with a load spectrum, you can enable this option by selecting this list item.

Use this option to define the stress ratios for each individual load spectrum case in the load spectrum definition.

This data can be used to perform a proof of fatigue strength as an equivalent stress verification, according to the FKM guideline. This proof performs the same function as the amplitude proof which has normally been performed up to now. In contrast to this, different stress ratios can be defined for each load case in an equivalent stress verification.

To take into account the effect of different stress ratios on the load side of the proof, the load spectrum is converted to the mean stress Sm = 0 and the stress ratio R = -1. This enables a strength calculation to be performed for a shaft, according to the FKM guideline, with the effect of a Rainflow matrix load spectrum.
