与 Solid Edge 的 3D 接口

制造商：KISSsoft AG

此接口实现了 Solid Edge 3D CAD 系统与 KISSsoft 之间的直接集成。使用此接口，KISSsoft 的所有计算模块均可在 Solid Edge 内运行。在 KISSsoft 中计算的圆柱齿轮或锥齿轮可在 Solid Edge 中直接生成具有真实齿形的 3D 零件（参见"3D 齿轮生成"章）。使用 KISSsoft 计算的轴可作为包含圆柱和圆锥元素的 3D 零件直接生成（参见"3D 轴生成"章），可直接在 Solid Edge 中生成。单击按钮即可启动 Solid Edge（从 KISSsoft 内部）。系统会打开一个新零件，并生成相应的零件。您可以创建具有直齿或斜齿的圆柱齿轮（外齿轮或内齿轮）、具有直齿或斜齿的齿条、或按 DIN 3971 图 1 定义的直齿锥齿轮，以及轴。
您还可以向现有轴添加轮齿（参见"存在现有轴数据时的轮齿"章）。此外，通过该接口，2D 范围内的齿轮制造数据（参见"添加制造数据"章）可作为文本字段自动插入到图纸中。齿轮制造数据附加到相应的切除（齿槽）上。

注意：

默认模板文件（例如 metric.prt）用于生成齿轮。要使用用户特定的模板文件，可以定义一个名为 USERPARTTEMPLATE 的变量（位于 [Solid Edge] 节、kiss.ini 文件中），或者覆盖默认模板文件并将其复制到默认路径上的用户特定模板文件文件夹中。如果在 Solid Edge 中为模板设置了用户特定路径，则使用该路径。否则，使用模板文件的默认路径（例如 ...\Solid Edge <version>\Template）。

English Original

3D interface to Solid Edge

Manufacturer: KISSsoft AG

This interface creates the direct integration between the Solid Edge 3D CAD system and KISSsoft. Use this to run all KISSsoft calculation modules from within Solid Edge. Cylindrical or bevel gears calculated in KISSsoft can be generated directly in SolidWorks as a 3D part (see chapter Generation of 3D gears) with a real tooth form. Shafts calculated with KISSsoft can be generated as a 3D part comprising cylinder and cone elements (see chapter Generating 3D shafts) directly in Solid Edge. You can start Solid Edge from within KISSsoft at the click of a button. The system opens a new part, and generates the appropriate part. You can create cylindrical gears with straight or helical teeth, which are outside or inside, racks with straight or helical teeth, or straight-toothed bevel gears, as defined in DIN 3971, Figure 1, and shafts.
You can also add gear teeth to existing shafts (see chapter Gear teeth if existing shaft data is present). In addition, gear manufacturing data in the 2D range (see chapter Adding manufacturing data) can automatically be inserted on the drawing as a text field, with the interface. The gear manufacturing data is attached to the relevant cutout (tooth space).

Note:

The default template file (e.g. metric.prt) is used to generate gears. To use a user-specific template file, either define a variable called USERPARTTEMPLATE in the [Solid Edge] section, in the kiss.ini file, or overwrite the default template file and copy it to the user-specific template files folder on the default path. If a user-specific path has been set for templates in Solid Edge, this path is used. Otherwise, the default path for template files is used (e.g. ...\Solid Edge <version>\Template).
