English Original

Formatting

Both the report template and the report generated from this are text files that are created with the Microsoft Windows font. You should always edit text in MS Windows, otherwise accented characters such as ä, ö, ü, as well as some special characters, may be represented incorrectly.

The following statements and key words are defined in the report format:

  • Texts that are to be output
  • Comments that are not to be output
  • Descriptions and formatting of calculation variables
  • Limited branchings (IF ELSE END)
  • Iterations (FOR-loops)
