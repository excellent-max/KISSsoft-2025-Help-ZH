中文翻译

创建和修改表格

可以使用预定义的表（称为 用户界面）在 KISSsys 模型中创建自己的表。此表存储在模板中的 表格 下。使用此“UserInterface”表，可以添加所有元素的参数以及用户自己的文本。可以更改表名以符合您的需要。

对于每个单元格，无论其中包含什么内容，都可以右键单击鼠标以在上下文菜单中选择“格式”。在其中，可以修改该单元格中的字体、颜色、背景颜色和文本位置。

English Original

Create and modify tables

You can use a predefined table, called UserInterface, to create your own tables in a KISSsys Model. This table is stored in Tables, in the template. Using this "UserInterface" table, you can add all parameters from the elements and your own texts. You can change the table's name to suit your needs.

For each cell, no matter what it contains, you can right-click with the mouse to select Format in the context menu. There, you can modify the font, color, background color, and text position in that cell.
