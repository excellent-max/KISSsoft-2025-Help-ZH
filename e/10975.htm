添加附加选项卡和对话框

附加选项卡和对话框的描述文件存储在 ext/dui（动态用户界面）目录中。KISSsoft 每次启动模块时都会评估此目录中的文件。可给这些文件任意命名，但文件扩展名必须始终为 *.dui。

标签 <module> 告诉 KISSsoft 该描述文件定义的计算模块。对于选项卡，此条目是强制性的。选项卡或对话框的标题由标签 <title> 定义。该标签可以包含实际文本或来自 KISSsoft 词汇表（wpoolUi_.txt）的文本 ID（编号）。

使用标签 <before> 来定义附加选项卡的位置。如果看不到标签 <before>，附加选项卡将放置在标准系统选项卡之后。附加选项卡也可以用于替换标准选项卡。要排除一个选项卡，请设置标签 <exclude>。

附加选项卡示例：

<KISSsoft filetype="userinterface">

<module>Z012</module>

<title>我的标题</title>

<before>Z012_Tolerances</before>

<exclude>Z012_BasicData</exclude>

<element>a</element>

<element>Q</element>

</KISSsoft>


附加选项卡始终显示。设置 <permanent> 标签可定义该选项卡是否可通过计算菜单启用。

<permanent>false</permanent>


附加选项卡始终与系统提供的标准选项卡以相同方式工作。插入 <calculation>、<report> 和 <results> 标签来表示特殊选项卡的行为。<calculation> 标签执行一个 COM 函数，所有通过 COM 接口可用的函数在此处同样可用。报告和结果的相应模板名称见"结果和报告"章。

使用 <setup> 标签将一个 COM 功能分配给附加对话框。当这些对话框运行时，该功能将被执行。

附加描述文件的示例可向 KISSsoft AG 索取。

English Original

Adding additional tabs and dialogs

The description files for additional tabs and dialogs are stored in the ext/dui (dynamic user interface) directory. KISSsoft evaluates the files in this directory every time a module is started. You can give these files any name you want, although the file extension must always be *.dui.

The <module> tag tells KISSsoft which calculation module the description file was defined for. This entry is mandatory for tabs. The titles of the tabs or dialogs are defined by the <title> tab. The tag can contain either an actual text or the ID (number) of a text from the KISSsoft Glossary (wpoolUi_.txt).

Use the <before> tag to define the position of the additional tabs. If you do not see the <before> tag, the additional tab is placed after the standard system tabs. An additional tab can also be used to replace a standard tab. To exclude a tab, set the <exclude> tag.

Example of an additional tab:

<KISSsoft filetype="userinterface">

<module>Z012</module>

<title>My own title</title>

<before>Z012_Tolerances</before>

<exclude>Z012_BasicData</exclude>

<element>a</element>

<element>Q</element>

</KISSsoft>


An additional tab is always displayed. Set the <permanent> tag to define that the tab can be enabled via the Calculations menu.

<permanent>false</permanent>


Additional tabs always work in the same way as the standard tabs supplied with the system. Insert the <calculation>, <report> and <results> tags to represent the behavior of a special tab. The <calculation> tag executes a COM function. All the functions that are available via the COM interface are also available here. The name of the corresponding template is set for the report and the results (see chapter Results and Reports).

Use the <setup> tag to assign a COM function to additional dialogs. This function is executed when those dialogs run.

Examples of additional description files can be requested from KISSsoft AG.
