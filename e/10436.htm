中文翻译

从数据库工具导入和导出数据

数据库工具中每个表的数据集均可导出到文件或从文件导入。这些数据集可作为单个数据集导入或导出，也可从数据集列表中导入。

要导入一个数据集列表，首先将其保存为文件，最好是带有 ".csv" 扩展名的 Excel 表格。表格中的列应与数据库表的列对应。

软件还可以解析保存为文本文件（扩展名为 ".txt"）的列表。列表条目应以“逗号”或“分号”分隔。使用哪种分隔符取决于操作系统配置。

  • 使用“数据集”按钮可从扩展名为 ".kds" 的文件中导入数据集，或将数据集导出到该文件。
  • 使用“列表”按钮可从扩展名为 ".csv" 的文件中导入数据集，或将数据集导出到该文件。

重要说明：

  1. 仅可导出或导入用户定义的数据集（ID >= 20000）
  2. 如果处理单个数据集，现有的 "用户定义的数据集" 可被覆盖。
  3. ".kds" 文件中的列名是大小写敏感的，必须与数据库工具中的列名完全匹配。可导出数据集以验证列名。
  4. 如果导入或导出整个列表，每个数据集将自动分配一个新的 ID。
English Original

Import and export data from the database tool

The datasets from every table in the database tool can be exported to a file or imported from a file. These datasets can be imported or exported as a single dataset or imported from a list of datasets.

To import a list of datasets, first save it in a file, preferably an Excel spreadsheet with the extension ".csv". The entries in the spreadsheet columns should match the database table columns.

The software can also interpret lists that are saved as text files with the ".txt" extension. List entries should be separated by a "comma" or a "semicolon". Which separator is used depends on your operating system configuration.

  • Use the Dataset button to import datasets from a file with the extension ".kds", or export them from one.
  • Use the List button to import datasets from a file with the extension ".csv", or export them from one.

Important notes:

  1. Only "user-defined datasets" (ID >= 20000) can be exported or imported.
  2. An existing "user-defined dataset" can be overwritten if you are processing individual datasets.
  3. The names of the columns in the ".kds" files is case-sensitive and must exactly match the names in the database tool. You could export a dataset to verify the column names.
  4. A new ID will automatically be assigned to every dataset if an entire list is imported or exported.
