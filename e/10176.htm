中文翻译

轴编辑器

轴编辑器以图形方式显示轴系统。在此处的"元素"框中输入元素。如果系统有多个轴，新元素将始终添加到当前活动轴中。当选中某个轴的元素时，该轴即变为活动轴。如果未选中任何元素，则最后一个轴为活动轴。

你可以通过上下文菜单选择选项，在轴编辑器中将图形保存为图片文件并打印它。每个不同的元素也有交互式上下文菜单。

English Original

Shaft editor

The Shaft editor displays the shaft system as a graphic. Enter elements in the Element box here. If your system has several shafts, the new element is always added to the active shaft. A shaft becomes active when one of its elements is selected. If no element has been selected, the last shaft is the active one.

You can select options in the context menu to save the graphic as a picture file, and print it, in the Shaft editor. Each of the different elements also has interactive context menus.
