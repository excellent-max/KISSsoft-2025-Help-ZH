中文翻译

以 CSV 格式保存临时结果，文件扩展名用 .tmp。

结果保存到临时文件（在 TMPDIR 中）。命名规则为 W010-H3_bin_x.tmp，其中“x”是载荷频谱的编号。例如，对于一个具有3个阶段的载荷频谱，会生成 W010-H3_bin_1.tmp、W010-H3_bin_2.tmp 和 W010-H3_bin_3.tmp 文件。

1. 对于滚动轴承
a. 滚动轴承的一般结果（位移、倾斜、反作用力）
b. 每个滚动体的结果
c. 每个切片的结果，如果选择滚子轴承
d. 刚度矩阵


2. 对于轴
a. 弯曲线数据

English Original

Saving temporary results in CSV format with .tmp file extension

Results are saved to temporary files (in the TMPDIR). The naming convention is W010-H3_bin_x.tmp, where "x" is the load spectrum's number. For example, the W010-H3_bin_1.tmp, W010-H3_bin_2.tmp and W010-H3_bin_3.tmp files are created for a load spectrum with 3 stages.

1. For rolling bearings
a. General results of the rolling bearing (displacement, tilting, reaction force)
b. Results for each rolling body
c. Results for each slice, if a roller bearing is selected
d. The stiffness matrix


2. For shafts
a. Data for the bending lines
