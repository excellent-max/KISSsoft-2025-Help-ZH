[VIDEOENCODING] 中的定义

变量名

描述

值

CODEC

指定用于编码视频的视频编解码器。

并非所有操作系统都支持所有可能的值。

0: H.264, 1: H.265 （默认值 = 0）

HARDWAREENCODING

指定是否使用硬件视频编码（如果可用）。

0: No, 1: Yes (default = 1)

MODE

指定编码模式。在某些情况下，如果硬件、操作系统或所选编解码器不支持最初选定的模式，则会使用不同的模式。

0：CBR（固定比特率）

1：无约束 VBR（无最大值的可变比特率）

2：有约束 VBR（有最大值的可变比特率）

3：质量等级（目标质量，不指定比特率）

（默认值 = 3）

WIDTH

指定视频宽度。宽度可以自动定义或固定。

然而，非常小或非常大的值可能导致视频录制失败。

0：使用图形窗口中图形的当前宽度

1-32767：使用此宽度（以像素为单位）

（默认值 = 0）

HEIGHT

指定视频高度。高度可以自动定义或固定。

然而，非常小或非常大的值可能导致视频录制失败。

0：使用图形窗口中图形的当前高度

1-32767：使用此高度（以像素为单位）

（默认值 = 0）

QUALITY #

指定设置 MODE=3 时使用的质量等级。

并非所有编解码器或操作系统都支持所有可能的值。

0-51：使用的质量等级（默认值 = 24）

AVGBITRATE

视频的目标比特率（单位：bit/s）

如果 MODE=0，则指定视频的恒定比特率。

如果 MODE=1/2，则指定视频的平均比特率。

然而，非常小或非常大的值可能导致视频录制失败。

0：使用Kush仪表自动计算比特率

其他值：使用的比特率

（默认值 = 0）

MAXBITRATE

MODE=2 时视频的最大比特率，单位为 bit/s。

该值应大于 AVGBITRATE。但是，非常小或非常大的值可能导致视频录制失败。

0：使用 Kush 仪表自动计算比特率
其他值：要使用的比特率

FPS

指定录制视频的每秒图像数。

然而，非常小或非常大的值可能导致视频录制失败。

建议值：30 或 60（默认值 = 30）

English Original

Definitions in [VIDEOENCODING]

Variable name

Description

Values

CODEC

Specifies the video codec which is to be used to encode videos.

Not all operating systems support all possible values.

0: H.264, 1: H.265 (default = 0)

HARDWAREENCODING

Specifies whether hardware video encoding is to be used, if available.

0: No, 1: Yes (default = 1)

MODE

Specifies the encoding mode. In some circumstances, a different mode will be used if the hardware, operating system or selected codec do not support the initially selected mode.

0: CBR (fixed bitrate)

1: Unconstrained VBR (variable bitrate without maximum)

2: Constrained VBR (variable bitrate with maximum)

3: Quality level (target quality, without specifying the bitrate)

(Default = 3)

WIDTH

Specifies the video width. The width can be either defined automatically or fixed.

However, very small or very large values may cause the video recording to fail.

0: Use the current width of the graphic in the Graphics window

1-32767: Use this width (in pixels)

(Default = 0)

HEIGHT

Specifies the video height. The height can be either defined automatically or fixed.

However, very small or very large values may cause the video recording to fail.

0: Use the current height of the graphic in the Graphics window

1-32767: Use this height (in pixels)

(Default = 0)

QUALITY #

Specifies the quality level to be used if MODE=3 is set.

Not all codecs or operating systems support all possible values.

0-51: The quality level to be used (default = 24)

AVGBITRATE

The video's target bitrate in bit/s.

If MODE=0, this specifies the video's constant bitrate.

If MODE=1/2, this specifies the video's average bitrate.

However, very small or very large values may cause the video recording to fail.

0: The bitrate is calculated automatically using the Kush gauge

Other values: The bitrate to be used

(Default = 0)

MAXBITRATE

The video's maximum bitrate in bit/s, if MODE=2.

This value should be greater than AVGBITRATE. However, very small or very large values may cause the video recording to fail.

0: The bitrate is calculated automatically using the Kush gauge
Other values: The bitrate to be used

FPS

Specifies the number of images per second in the recorded video.

However, very small or very large values may cause the video recording to fail.

Recommended values: 30 or 60 (default = 30)
