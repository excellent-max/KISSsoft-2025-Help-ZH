中文翻译

修改

应用于齿轮的不同修改被定义为数据库类。如果数据库中隐藏了一个数据集，它将不再出现在修改选择列表中。

尽管可将新数据集添加到数据库中，但这些数据集在计算模块中将不可见。

English Original

Modifications

The different modifications applied to gears are defined as database classes. If a dataset is hidden in the database, it will no longer appear in the modifications selection list.

Although you can add new datasets to the database, these will not be visible in the calculation module.
