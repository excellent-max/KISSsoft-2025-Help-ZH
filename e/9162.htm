中文翻译

表格

在某些模块中，数据在表格中显示或输入。与选择输入字段一样，通过双击选择一行。对于表格，附加信息通常显示在工具提示中（参见"工具提示和状态栏"章）。通常，表格后面会有以下按钮，以便您输入数据：

单击添加按钮以向表格中添加一行。

单击删除按钮以从表格中删除所选行

单击清除按钮以删除表格中的所有条目

English Original

Tables

In some modules, data is displayed or entered in a table. You select a row by double-clicking, just like when you select a field for input. For tables, additional information is often displayed in a tooltip (see chapter Tooltips and status bar). In general, the following buttons come after tables so that you can input data:

Click the Add button to add a row to the table.

Click the Remove button to delete the selected row from the table

Click the Clear button to delete all entries in the table
