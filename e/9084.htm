计算结果

KISSsoft 在"结果"窗口中显示计算结果（参见"结果窗口"章）。如果没有显示结果，则说明计算过程中发生了错误。如果发生这种情况，系统消息会出现在消息框中以提醒您注意该错误。状态栏中的指示器（参见"工具提示和状态栏"章）显示结果是否一致，即结果是否与用户界面中的数据相匹配。

English Original

Results of a calculation

KISSsoft displays the results of a calculation in the Results window (see chapter The Results window). If no results are displayed, an error has occurred during the calculation. If this happens, a system message appears in a message box to alert you to the error. An indicator in the status bar (see chapter Tooltips and status bar) shows whether the results are consistent, i.e. whether the results match up with the data in the user interface.
