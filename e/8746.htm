中文翻译

自定义输入

选择此选项可输入您自己的数据。但请注意，齿厚余量、法向或圆周侧隙（每个齿轮）以及公法线长度余量的取值彼此相互依赖。（负的）公法线长度余量对应于法向侧隙。

English Original

Own Input

Select this option to input your own data. However, you should note that the values for tooth thickness allowance, the normal or circumferential backlash (per gear) and the base tangent length allowance all depend on each other. The (negative) base tangent length allowance corresponds to the normal backlash.
