结果

计算完成后，将根据输入的数据生成 2D 图。更详细的分析结果和其他图形数据显示在报告中，该报告在右键单击 kSoftSystem KISSsys 单元并选择 显示报告 时生成。 也可以单击 保存图形 按钮保存 2D 图，以便在后续计算中原样使用（这样每次都会生成新曲线）。同时还会生成包含图中所有数据的表格。不平衡响应分析主要针对参考轴上预定义的参考位置进行。然而，也会为系统中轴计算中定义的所有文档点计算分析结果。这些文档点因此可以作为动态行为的测量点。文档点的结果显示在报告和结果表中。

English Original

Results

Once the calculation is complete, a 2D plot is generated from the data you have entered. More detailed analysis results and other plot data are displayed in the report which is generated when you right-click on the kSoftSystem KISSsys element and then select ShowReport. You can also click on the SavePlot button to save the 2D plot if it is to be used (unchanged) in subsequent calculations (so that a new curve is generated each time). A table with all the data used in the plot is also generated. The unbalance response analysis is primarily performed for the predefined reference position on the reference shaft. However, the analysis results are also calculated for all documentation points that have been defined in the shaft calculations in the system. These documentation points can therefore be used as measuring points for dynamic behavior. The results of the documentation points are displayed both in the report and in the results table.
