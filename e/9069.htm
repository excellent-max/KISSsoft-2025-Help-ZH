变量名

描述

注意

KISSDIR=<INIDIR>

KISSsoft 安装文件夹路径通常由 INIDIR 变量定义。

HELPDIR

用户手册和帮助图的目录

DATADIR

.dat 文件目录

注意： 用户不应在此目录中进行任何升级或更改。请在 DAT 子目录中保存自己的文件，该子目录位于 EXTDIR 目录中。

RPTDIR

报告模板目录（*.rpt）

注意： 用户不应在此目录中进行任何升级或更改。请在 RPT 子目录中保存自己的文件，该子目录位于 EXTDIR 目录中。

USERDIR

打开和保存的默认目录

CADDIR

CAD 导出的默认目录

应位于工作站本地。

%TEMP% 设置临时目录为操作系统默认目录。

TMPDIR

临时文件的目录

应位于工作站本地。

%TEMP% 设置临时目录为操作系统默认目录。

UDBDIR

用户自定义数据库目录（*.udb）

如果多个用户使用该系统，建议将数据库存储在服务器上，以确保在有更改和升级时数据的一致性。

KDBDIR

KISSsoft 数据库目录（*.kdb）

KISSsoft 数据集中包含不可修改的数据。

EXTDIR

用户自定义报告模板和额外 DAT 文件目录

如果有多个用户，建议将此目录存储在服务器上。

TEMPLATEDIR

模板文件目录（STANDARD.*）

如果有多个用户，建议将此目录存储在服务器上。

LICDIR

许可证文件目录

可将此目录安装在服务器上，以便所有用户都能访问新的许可证文件。

注意

用户应具有这些变量所设置目录的写入权限：TMPDIR, CADDIR, USERDIR 和 UDBDIR.

根据配置，您在这些目录中可能没有写权限：C:\ Program Files\ KISSsoft 目录名 或 C:\ Programs\ KISSsoft 目录名。您创建的任何文件随后将重定向到操作系统的内部目录。在这种情况下，请选择具有写入权限的目录。

English Original

Definitions in [PATH]

Variable name

Description

Note

KISSDIR=<INIDIR>

The KISSsoft installation folder path is generally defined with the INIDIR variable.

HELPDIR

Directory for user manual and help figures

DATADIR

Directory for .dat files

Attention: You should not carry out any upgrades or make any changes in this directory. Save your own files in the DAT subdirectory in the EXTDIR directory.

RPTDIR

Directory for report templates (*.rpt)

Attention: You should not carry out any upgrades or make any changes in this directory. Save your own files in the RPT subdirectory in the EXTDIR directory.

USERDIR

Default directory for opening and saving

CADDIR

Default directory for CAD export

Should be located locally on a workstation.

%TEMP% sets the temporary directory to the operating system default.

TMPDIR

Directory for temporary files

Should be located locally on a workstation.

%TEMP% sets the temporary directory to the operating system default.

UDBDIR

Directory for user-defined databases (*.udb)

If several users are using the system, we recommend you store the databases on a server to ensure data uniformity if there are changes and upgrades.

KDBDIR

Directory for KISSsoft's databases (*.kdb)

KISSsoft datasets containing data that cannot be modified.

EXTDIR

Directory for user-defined report templates and additional DAT files

If there are several users, it is advisable to store this directory on a server.

TEMPLATEDIR

Directory for template files (STANDARD.*).

If there are several users, it is advisable to store this directory on a server.

LICDIR

Directory for the license files

You can install this directory on a server so that all users can access the new license files.

Table 2.1: Table of variables used in the PATH environment

Note

You should have write permission for the directories set in these variables: TMPDIR, CADDIR, USERDIR and UDBDIR.

Depending on the configuration, you might not have write permission in these directories: C:\ Program Files\ KISSsoft directory name or C:\ Programs\ KISSsoft directory name. Any files you create are then diverted to the operating system's internal directories. In this case, select directories with write permission.

The UDBDIR, TMPDIR, CADDIR, USERDIR and EXTDIR directories can also be defined in the ‘Directories’ tab in the ‘Program settings’ dialog (Extras>Settings).
