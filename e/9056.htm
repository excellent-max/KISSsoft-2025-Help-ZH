中文翻译

创建数据库条目

如果您在未选中任何行的情况下点击 按钮，显示 条目 窗口（）将打开，其中的输入字段为空。只有 名称 字段包含 _NEW 条目，该条目通常用于标识新的表条目。传输必要数据后，通过点击 OK，然后在数据库工具窗口中点击 保存 来确认您的输入。新条目被分配一个 ≥ 20000 的标识号（ID），然后传输到活动数据集的列表中。点击 编辑 按钮可更改 ID ≥ 20000 的条目。

选中某行后点击 按钮，显示 条目 窗口将打开，输入字段中包含根据表条目预定义的值。后缀 _NEW 会自动附加到名称上，以将其与原始数据集区分开。在其余所有步骤中，您随后按上述方式继续操作。

示例：创建数据库条目
假设您要向 KMAT.F000 表添加一种新的弹簧材料。按照流程所述，您将选择 F000 表，该表属于 KMAT 数据库。在其中点击 按钮，向表添加新条目/新行，然后将新数据传入 显示条目 窗口的输入字段。然而，由于只有少数参数可以在那里自由选择，下一个问题是，屈服点和杨氏模量等其他值在哪里可以更改？答案是：在基础材料输入字段中，即在 KMAT.KISS 表中。在引入新的弹簧材料之前，您必须始终指定一个基础材料。如果该基础材料不存在，则必须先在 KMAT.KISS 表中定义它，然后在 KMAT.F000 中进行缺失的输入。

注意

所有特定于材料的表（如 KMAT.F000 或 KMAT.Z080），除 KMAT.KLUB 之外，在基础材料下拉菜单旁边都有一个复选按钮。如果勾选了复选框，您可以选择关联下拉列表菜单中的替代基础材料。如果复选框为空，则对基础材料菜单的访问将被阻止。此选项有助于防止在分配基础材料时发生不必要的更改。

English Original

Creating a database entry

If you click on the button without having selected a row, the Display entry window () opens and the input fields in it are empty. Only the Name field contains the entry _NEW, which normally identifies the new table entry. After you have transferred the necessary data, confirm your entries by clicking on OK and then Savein the database tool window. The new entry is assigned an identification number (ID) ≥ 20000 and is then transferred into the list of active datasets. Click the Edit button to change entries with an ID of ≥ 20000.

Click the button after having selected a row, the Display entry window opens and contains predefined values in the input fields according to the table entry. The suffix _NEW will automatically be attached to the name, in order to differentiate it from the original dataset. In all remaining steps, you then proceed as described above.

Example: Creating a database entry
Let's assume you want to add a new spring material to the KMAT.F000 table. As described in the procedure, you would select the F000 table from the KMAT database. Click on the button in it, to add a new entry/new row to the table, and then transfer the new data into the input fields in the Display entry window. However, as only a few parameters can be freely selected there, the next question is, where can the other values such as the yield point and Young's modulus be changed? The reply is: in the base material input fields, i.e. in table KMAT.KISS. You must always specify a base material before you can introduce a new spring material. If this is not present, you must first define it in the KMAT.KISS table and then make the missing entries in KMAT.F000.

Note

All material-specific tables such as KMAT.F000 or KMAT.Z080 - with the exception of KMAT.KLUB - have a Check button beside the Base material drop-down menu. If you have marked the checkbox, you have the option of selecting an alternative base material in the associated drop-down list-menu. If the checkbox is empty, access to the menu of the base materials is blocked. This option helps prevent unwanted changes when the base material is being assigned.
