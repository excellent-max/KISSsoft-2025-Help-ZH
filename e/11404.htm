中文翻译

考虑干材料属性

如果使用吸水后其力学性能（杨氏模量、拉伸应力、齿根和齿面疲劳）发生显著变化的材料（如 PA6、PA66 等），请激活此选项以计算干材料的力学性能。如果干材料已有可用数据，可将其添加到相应的 DAT 材料文件 （见图 15.99）。例如，可使用材料文件 Z014-PA66_VDI2736.DAT。

English Original

Consider dry material properties

If materials (such as PA6, PA66, etc.) are used, whose mechanical properties (Young's modulus, tensile stresses, tooth root and flank fatigue) change significantly when they absorb water, activate ﻿this option to calculate the mechanical properties of dry materials. If data is already available for dry materials, it can be added to the corresponding DAT material file (see Figure 15.99). For example, you can use material file Z014-PA66_VDI2736.DAT.
